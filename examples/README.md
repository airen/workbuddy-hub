# 完整使用示例

本目录用于存放「端到端」示例，演示如何组合 hub 中的资产完成真实任务。

> 当前阶段（核心骨架）尚未填充独立示例。可用的「活示例」就是 `skills/`、`experts/`、`teams/` 中的真实资产本身——任选一个目录即可作为同类型资产的参考实现。

建议的示例骨架（后续补充）：

- `examples/single-skill/`：从 `templates/skill/` 生成并填写一个最小可运行技能。
- `examples/single-expert/`：从 `templates/expert/` 生成一个单专家，并演示如何被 WorkBuddy 加载。
- `examples/expert-team/`：从 `templates/team/` 生成一个专家团，演示多角色协作交付。

生成方式见 `templates/README.md` 与 `README.md` 的「日常操作」。
