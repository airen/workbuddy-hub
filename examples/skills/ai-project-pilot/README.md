# ai-project-pilot 使用示例

**类别**：其他 | **版本**：1.0.0

## 场景

要推进一个 AI 项目落地。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `帮我推进这个 AI 助手项目` |
| agent | 加载 `skills/ai-project-pilot/SKILL.md`，四阶段推进：

1. 立项：项目章程、成功标准
2. 计划：WBS、里程碑、资源与风险
3. 执行监控：状态报告、偏差纠正
4. 验收上线：验收记录、运营交接包 |

## 产出

项目章程、WBS、状态报告、验收记录等文档

## 验证

各阶段文档齐全；成功标准可测量

## 资产位置

- 定义：`skills/ai-project-pilot/SKILL.md`
- 元数据：`skills/ai-project-pilot/manifest.yaml`
