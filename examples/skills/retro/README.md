# retro 使用示例

**类别**：开发与工程 | **版本**：1.0.0

## 场景

一次会话结束，想复盘改进。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `复盘一下这次会话` |
| agent | 加载 `skills/retro/SKILL.md`：

1. 回顾会话过程
2. 找出可改进的候选项
3. 输出改进建议 |

## 产出

复盘报告 + 改进候选项

## 验证

候选项具体可执行

## 资产位置

- 定义：`skills/retro/SKILL.md`
- 元数据：`skills/retro/manifest.yaml`
