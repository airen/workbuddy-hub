# teach 使用示例

**类别**：调研与信息检索 | **版本**：1.0.0

## 场景

想系统学习某个主题。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `教我用 TDD` |
| agent | 加载 `skills/teach/SKILL.md`：

1. 创建 MISSION.md 任务书
2. 创建 GLOSSARY.md 术语表
3. 规划学习路径（HTML 课程）
4. 跨会话维护学习记录 |

## 产出

学习材料（MISSION.md, GLOSSARY.md, HTML 课程）

## 验证

学习路径清晰；术语表完整

## 资产位置

- 定义：`skills/teach/SKILL.md`
- 元数据：`skills/teach/manifest.yaml`
