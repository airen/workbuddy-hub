# prototype 使用示例

**类别**：开发与工程 | **版本**：1.0.0

## 场景

不确定设计方案对不对，先做个原型验证。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `搭个原型验证一下这个状态机` |
| agent | 加载 `skills/prototype/SKILL.md`：

1. 判断原型类型：逻辑/状态模型 或 UI 变体
2. 构建一次性原型
3. 跑测试验证边界情况 |

## 产出

原型代码 + 验证结论（可行/需调整/不可行）

## 验证

原型能跑通关键路径；边界情况有答案

## 资产位置

- 定义：`skills/prototype/SKILL.md`
- 元数据：`skills/prototype/manifest.yaml`
