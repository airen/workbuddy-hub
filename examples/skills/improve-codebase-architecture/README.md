# improve-codebase-architecture 使用示例

**类别**：开发与工程 | **版本**：1.0.0

## 场景

觉得架构太浅，想系统化重构。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `帮我看看哪里能重构` |
| agent | 加载 `skills/improve-codebase-architecture/SKILL.md`：

1. 扫描代码库
2. 找出浅模块
3. 生成 HTML 报告
4. 用户选一个模块，深入拷问 |

## 产出

HTML 报告 + 深入讨论记录

## 验证

报告指向具体可重构点

## 资产位置

- 定义：`skills/improve-codebase-architecture/SKILL.md`
- 元数据：`skills/improve-codebase-architecture/manifest.yaml`
