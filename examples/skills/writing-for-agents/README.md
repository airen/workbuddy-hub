# writing-for-agents 使用示例

**类别**：开发与工程 | **版本**：1.0.0

## 场景

要写 skill 或 AGENTS.md 给 agent 用。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `帮我写一份 AGENTS.md` |
| agent | 加载 `skills/writing-for-agents/SKILL.md`：

1. 讲解写作原则（上下文指针、两种负载、完成判据...）
2. 协助用户写出 AGENTS.md |

## 产出

符合 agent 阅读习惯的 AGENTS.md

## 验证

其他 agent 能无歧义理解和使用

## 资产位置

- 定义：`skills/writing-for-agents/SKILL.md`
- 元数据：`skills/writing-for-agents/manifest.yaml`
