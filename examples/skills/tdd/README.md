# tdd 使用示例

**类别**：开发与工程 | **版本**：1.0.0

## 场景

开发新功能或修复 bug 时，希望先写测试。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `写一个 TDD 循环：为 add_item 方法写测试` |
| agent | 加载 `skills/tdd/SKILL.md`，执行红-绿-重构循环：

1. 在接缝上写失败测试
2. 跑测试确认红
3. 写最小实现让测试绿
4. 重构
5. 提交 |

## 产出

测试文件（tests/test_xxx.py）+ 实现代码

## 验证

测试从红变绿，重构后仍绿；git log 可见原子提交

## 资产位置

- 定义：`skills/tdd/SKILL.md`
- 元数据：`skills/tdd/manifest.yaml`
