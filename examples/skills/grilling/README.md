# grilling 使用示例

**类别**：其他 | **版本**：1.0.0

## 场景

方案还没定型，需要有人挑刺。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `帮我拷问一下这个架构设计` |
| agent | 加载 `skills/grilling/SKILL.md`，执行：

1. 画出设计树（所有决策点）
2. 逐分支拷问：为什么用 Redis？缓存失效策略？
3. 逼出每个分支的定论 |

## 产出

设计树，每个分支的定论（已解决或标记为风险）

## 验证

设计树所有分支都有定论；无悬而未决的关键决策

## 资产位置

- 定义：`skills/grilling/SKILL.md`
- 元数据：`skills/grilling/manifest.yaml`
