# spec-driven-dev 使用示例

**类别**：开发与工程 | **版本**：1.0.0
**编排技能**：spec-driven-development

## 场景

需求模糊，需要固化成规格。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `帮我写一份规格说明` |
| agent | 选择专家 "章立言"（`spec-driven-dev`）：

1. 章程 -> 规格 -> 澄清 -> 方案 -> 任务清单 -> 校验 -> 收敛
2. 每步产出对应文档

产出：完整规格包 |

## 产出

规格文档包（章程、规格、任务清单等）

## 验证

规格可执行；验收标准明确

## 资产位置

- 定义：`experts/spec-driven-dev/.codebuddy-plugin/plugin.json`
- 人格：`experts/spec-driven-dev/agents/spec-driven-dev.md`
- 元数据：`experts/spec-driven-dev/manifest.yaml`
