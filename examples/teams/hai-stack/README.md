# hai-stack 使用示例

**类别**：开发与工程 | **版本**：1.0.0
**成员数**：7 | **主理人**：`hai-stack-team-lead`

## 场景

做一次软件迭代。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `帮我迭代这个功能` |
| agent | 选择专家团 "软件迭代专家团"（`hai-stack`）：

1. 判断值不值得做
2. 设计边界
3. TDD 落地
4. 证据确认
5. 文档沉淀

产出：迭代产物 + 文档 |

## 产出

迭代产物 + 技术文档

## 验证

迭代目标达成；文档干净

## 资产位置

- 定义：`teams/hai-stack/settings.json` + `agents/*.md`（7 名成员）
- 元数据：`teams/hai-stack/manifest.yaml`
