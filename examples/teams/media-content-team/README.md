# media-content-team 使用示例

**类别**：内容生产 | **版本**：1.0.0
**成员数**：3 | **主理人**：`media-content-team-team-lead`

## 场景

做小红书和公众号图文。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `帮我写一篇公众号文章` |
| agent | 选择专家团 "自媒体图文产线团"（`media-content-team`）：

1. 热点选题
2. 对标拆解
3. 封面配图
4. 多平台排版

默认只出草稿，不自动群发

产出：图文草稿 |

## 产出

图文草稿（小红书 + 公众号）

## 验证

排版符合平台规范；内容无敏感信息

## 资产位置

- 定义：`teams/media-content-team/settings.json` + `agents/*.md`（3 名成员）
- 元数据：`teams/media-content-team/manifest.yaml`
