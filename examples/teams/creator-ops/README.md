# creator-ops 使用示例

**类别**：内容生产 | **版本**：1.0.0
**成员数**：7 | **主理人**：`creator-ops-team-lead`

## 场景

做自媒体内容生产。

## 对话片段

| 说话者 | 内容 |
|---|---|
| 用户 | `帮我做个小红书爆款笔记` |
| agent | 选择专家团 "自媒体创作专家团"（`creator-ops`）：

六位环节专家接力：
1. 闻先机（选题情报）
2. 毕成章（文案）
3. 颜可观（视觉）
4. 陶成帧（视频）
5. 郑多平（发布）
6. 查有数（数据复盘）

产出：可直接发布的成品 |

## 产出

多平台发布成品 + 数据复盘

## 验证

内容符合平台规范；数据可追踪

## 资产位置

- 定义：`teams/creator-ops/settings.json` + `agents/*.md`（7 名成员）
- 元数据：`teams/creator-ops/manifest.yaml`
