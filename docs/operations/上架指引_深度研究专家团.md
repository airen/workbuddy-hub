## 2. 上传操作

后台路径：**发布管理 → 专家 → 「创建」**

1. 把 `deep-research-crew.zip` 拖进上传区，平台自动解压识别
2. 进入确认信息页，补齐页面上的三项（包内读出来的字段页面上改不了，要改就回文件改后重新打包）：
   - **市场展示分类**：建议勾选含 **AI 创作 / AI 应用** 的分类（可多选）
   - **服务类目**：至少 1 个、最多 5 个，建议「工具-办公」或「工具-效率」
   - **头像**：可沿用包内 `avatars/team.jpg`
3. 核对右侧预览（名称 / 简介 / 7 个成员头像）→ 继续 → 确认汇总 → **提交**

- 提交后等审核：官方口径 **7 个工作日**，实测约 **18 小时**
- 结果在开放平台**通知中心**看
- 通过后状态变「待发布」，**必须再点一次「发布」**才真正上架

## 5. 卡点清单

| 报错 | 原因 | 解法 |
|---|---|---|
| 专家名称「已被占用」 | name 是**全平台全局唯一** | 换名要**成组改**：目录名 + plugin.json 的 `name`/`plugin`/`agentName` + `agents[]` 路径 + 7 个 MD 文件名 + 各自 frontmatter 的 `name` + 8 个头像文件名；改完重新 validate + register + 打包 |
| 驳回：类目与应用类目不符，至少应包含高度生成或 AI 创作类目 | 展示分类没落到 AI 类目 | 上传页**市场展示分类**务必勾选含「AI创作」的分类（可多选） |
| 驳回：企业开发者才支持深度生成/AI 创作类目 | 个人主体可能受该类目限制 | 二选一：① 走企业认证；② 邮件 openworkbuddy@tencent.com 确认个人主体可用类目组合（你上个包遇到过同样提示） |
| 解析失败 / YAML 报错 | frontmatter 字段不全或格式错 | 本包已通过本地校验器与打包器双重校验，无需处理 |

兜底：https://open.workbuddy.cn/docs/expert 、openworkbuddy@tencent.com
