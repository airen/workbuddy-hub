> 索引是唯一入口：不在这里登记的文档，等于不存在。
>
> 维护：跑 `python3 scripts/doc_audit.py <项目根目录>` 可查孤儿文档与断链。

## 状态词说明

| 状态 | 含义 |
|---|---|
| **现行** | 当前有效，按它做 |
| **过期** | 曾经有效，现在不一定——改之前不要引用 |
| **已废弃** | 明确不再有效，文件保留供追溯，需写明被谁取代 |
