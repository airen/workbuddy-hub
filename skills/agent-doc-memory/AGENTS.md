# AGENTS.md — 文档即记忆

> 本文件是 **Codex / Cursor / 其它读取 `AGENTS.md` 的编码 agent** 的等价入口。
> 把它放到项目根目录（或 `~/.codex/AGENTS.md` 作为全局），agent 干活时就会按下面的协议约束自己。
> 完整详解在 `references/`，可直接填的模板在 `templates/`，审计脚本在 `scripts/`。

## 何时启用

**每个任务都启用。** 本技能不是"要做文档时才用"，而是**干活的默认姿势**：

- 用户抱怨你记不住项目：「记不住」「每次都要重新解释」「上次说好的又忘了」「同一个坑踩三次」
- 你要开始一个**跨会话的长期工作**（这次改了，下次还要改）
- 你**做了决策 / 定了约定 / 搞清了某个库 / 写了规格 / 澄清了术语 / 发现文档过期**

不适用：一次性小任务（问概念、跑脚本、改 typo）、外部海量语料的检索（那该用 RAG）。

## 四条铁律

1. **先查后干。** 开工前先读 `INDEX.md`，按索引读出相关文档。**不许凭记忆猜项目约定。**
2. **干完就更新，趁热。** 过期就改、缺了就补、新增就登记，**并同步索引**。
3. **文档是给人看的。** 纯 Markdown、进 git、能 diff、能 review、能分享。
4. **写"为什么"，不写"是什么"。** 价值在动机、代价、边界、教训。

> 反面同样重要：**没有就不写。** 没产生新知识就明确说「本次无文档更新」。

## 六类文档速查

| # | 文档 | 回答的问题 |
|---|---|---|
| ① | `INDEX.md` | 有哪些文档、先读哪个？ |
| ② | `conventions.md` | 在这个项目里活该怎么干？ |
| ③ | `glossary.md` | 这个词在本项目里指什么？ |
| ④ | `specs/` | 要做什么、不做什么、怎么算完成？ |
| ⑤ | `decisions/` | 为什么这么做、放弃了什么？ |
| ⑥ | `research/` | 这个库 / API 怎么用、坑在哪？ |

## 更新触发事件（对照检查，命中就写）

| 触发事件 | 写到哪 | 至少包含 |
|---|---|---|
| 定下 / 改变一条**约定** | `conventions.md` | 规则 + 为什么 + 例外 |
| 做了一个**有取舍的决策** | `decisions/NNNN-*.md` | 备选、选了谁、**代价**、何时重估 |
| 搞清**第三方库 / API / 工具** | `research/<topic>.md` | 结论先行、最小示例、坑与规避 |
| 写了**规格 / 计划**或需求变更 | `specs/<feature>.md` | 目标、不做清单、验收标准 |
| **澄清术语**歧义 | `glossary.md` | 词 + 定义 + **不指什么** |
| 发现**文档过期** | 原文档 | 就地改对或标 `已废弃` |
| 踩坑并找到**根因** | `research/` 或 `decisions/` | 现象、根因、怎么避免复发 |

**不写**：流水账、运行日志、能从代码直接读出的东西、临时调试过程、未定论的想法（除非标 `草稿`）。

## 好文档四条判据

1. **为什么 > 是什么** —— 只写"是什么"的文档没人读第二遍
2. **一份文档一个主题，标题即结论** —— 能被一句话引用才算有用
3. **开头写状态** —— `状态: 现行|过期|已废弃` + `最后更新: YYYY-MM-DD` + `适用范围`
4. **不抄代码，只指位置** —— 抄来的代码第二天就过期

## 反模式（命中任一条 = 走回老路）

- 建向量库 / 嵌入 / 摘要器 / 后台守护进程 → **就是 Markdown 文件**
- 把对话日志原样倒进文档 → 只写提炼后的结论与动机
- 追求"捕获一切" → 只写"下次还需要知道"的
- 文档里复制代码 → 指路径与符号名
- 一次建 50 篇文档 → 从 INDEX + conventions 起步
- 只写"是什么" → 写动机、代价、边界、教训
- 文档和代码各说各话 → 以现实为准立即修文档
- 写完不同步 INDEX → 下次等于没写

## 输出规范

- **开头声明依据**：「按 `decisions/0003`，我们约定……」
- **收尾声明更新**：更新了什么，或「本次无文档更新」
- **就地修改**已有文档，不要追加"补充说明（二）"，让 git 历史承载演变
- **索引是唯一入口**：新建 / 删除文档必须同步 `INDEX.md`
- 落盘到项目 `docs/`（项目已有文档目录就跟随），不要写到临时位置
- 语言跟随用户
