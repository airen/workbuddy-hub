## 二、里程碑与关口

| 关口 | 通过标准（可量化） | 计划日期 | 实际日期 | 状态 |
|---|---|---|---|---|
| **可行性验证** | 数据和方案能支撑目标（结论：能/不能） | | | |
| **原型验证** | 固定评测集达到门槛（准确率 ≥ ___%） | | | |

| **上线准备** | 质量、监控与回滚就绪（checklist 全过） | | | |

> 关口没过，**不进入下一阶段**。要带病前进，走变更。
