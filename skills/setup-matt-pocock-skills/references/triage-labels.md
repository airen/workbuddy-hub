# 分诊标签（Triage Labels）

这些技能用五个标准分诊角色说话。本文件把这些角色映射到这个仓库 issue 追踪器里实际使用的标签字符串。

| mattpocock/skills 里的标签 | 我们追踪器里的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全指定，可供一个 AFK 代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不会被处理 |

当某个技能提到一个角色时（例如「apply the AFK-ready triage label」），使用本表中对应的标签字符串。

把右侧一列改成你实际使用的词汇。
