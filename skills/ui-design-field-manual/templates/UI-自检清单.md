# UI 交付前自检清单

> 用法：界面代码写完、**在告诉用户"做好了"之前**，逐条核对。
> 不合格的项**当场改掉**，并在回复里用一句话说明改了什么。
> 涉及具体数值时对照 [../references/08-engineering-parameters.md](../references/08-engineering-parameters.md)。

## A. 骨架（规则 01–02）—— 最重要，先过这关

- [ ] **A1** 基调四项（字体 / 色彩 / 圆角 / 措辞）已确定，全站一致
- [ ] **A2** 把界面调成灰度，仍能一眼看出**标题 / 正文 / 辅助**三级层次
- [ ] **A3** 把界面调成灰度，仍能看出**哪个是主要操作**
- [ ] **A4** 没有用渐变 / 发光 / 玻璃拟态去弥补层级缺失

> A2、A3 任意一条不过 → **回到第 1–3 步重搭骨架**，不要继续往下改颜色。

---

## B. 视觉层级（规则 03–06）

- [ ] **B1** 文字层级靠**字重 + 颜色**，不只靠字号
- [ ] **B2** 文字颜色 ≤ 3 种，字重 ≤ 2 种（不含标题的 700）
- [ ] **B3** 没有低于 400 的字重；辅助文字没有"又小又灰"双重削弱
- [ ] **B4** 页面**只有一个**"最重"的元素（主要操作）
- [ ] **B5** 按钮分级：主要实心 / 次要线框或浅底 / 辅助文本链接
- [ ] **B6** 破坏性操作（删除等）不是常驻高饱和红按钮
- [ ] **B7** 数据展示区删掉了"标签: 值"式冗余标签（规格表 / 看板除外）

---

## C. 空间与布局（规则 07–10）

- [ ] **C1** 所有间距都取自刻度（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64），无 `13px` 这类随手值
- [ ] **C2** **组间距 ≥ 组内距的 2 倍**（推荐 3–4 倍）
- [ ] **C3** 卡片内边距：桌面 ≥ 24px / 移动 ≥ 16px
- [ ] **C4** 内容有**最大宽度约束**，没有因为导航栏全宽就把所有区块撑满
- [ ] **C5** 表单 / 正文容器有 `max-width`
- [ ] **C6** 移动端字号不是机械等比缩放（大标题收得更狠）

---

## D. 文本与排版（规则 11–12）

- [ ] **D1** 没有全局写死 `line-height: 1.5`，行高按层级给值
- [ ] **D2** 大标题行高 **1.1–1.2**，正文 1.5–1.6（中文正文 1.6–1.75）
- [ ] **D3** 正文段落行长在 **45–75 字符**区间（`max-width: 65ch` 左右）
- [ ] **D4** 一行内混排不同字号时使用 **`align-items: baseline`**，不是 `center`
- [ ] **D5** 中文断行已控制：数字与单位（`38 秒`）、不可拆的词包了不换行；行末没有只剩一两个字
- [ ] **D6** 中文正文实际字号在区间内（阅读型 16–18px / 产品界面 14–16px / 高密度工具 13–14px）

---

## E. 色彩与无障碍（规则 13–15）

- [ ] **E1** 有完整色阶：中性 8–10 档 + 主色 5–10 档 + 语义色各若干档
- [ ] **E2** 彩色小标签（Badge / 状态）用**浅底深字**，不是深底白字
- [ ] **E3** 状态信息（涨跌 / 成功失败）有**颜色 + 图标双通道**
- [ ] **E4** 正文对比度 ≥ **4.5:1**；大字号与图形 ≥ **3:1**
- [ ] **E5** 没有仅靠颜色传达关键信息的地方
- [ ] **E6** 配色两问自检已过：去掉发光与模糊后仍成立；能说出一个用类似配色的成功产品

---

## F. 质感与图片（规则 16–18）

- [ ] **F1** 强调色边框（Accent Border）用了，但不超过 2–3 处
- [ ] **F2** 图片上的文字有**蒙版 / 降对比 / 单色叠底**保证稳定对比度（灰度下仍可读）
- [ ] **F3** 图标没有被强行放大（保持原尺寸 + 浅底容器）
- [ ] **F4** 没有把完整网页截图缩小塞进小卡片

---

## G. 细节与状态（规则 19–20）

- [ ] **G1** 分区优先用**背景色差 / 留白 / 阴影**，边框是最后手段
- [ ] **G2** 没有"每个区块都套 1px 灰线"的网格感
- [ ] **G3** **空状态**已设计：图标 + 说明 + 明确 CTA
- [ ] **G4** 空状态下**隐藏**了无意义的标签页 / 筛选器 / 排序 / 批量操作
- [ ] **G5** **加载态**有骨架屏或 spinner（不白屏闪烁）
- [ ] **G6** **错误态**说明原因并给重试入口
- [ ] **G7** 圆角半径 ≤ 2 种
- [ ] **G8** 没有发光阴影 / 多层彩色阴影

---

## H. 方向与内容（规则 21–23）

- [ ] **H1** 模糊词已翻译成可观察的决定；「高级 / 大气 / 有质感」这类词没有留在设计理由里
- [ ] **H2** 首屏骨架已明确选定并画过线框；**不是**"左边大标题 + 按钮，右边一张装在圆角卡片里的产品界面"
- [ ] **H3** 内容型页面（后台 / 工具 / 画廊 / 商店 / 信息流）的首屏**就是第一排内容**；导航 + 标题 + 筛选不超过两行，没有首屏口号
- [ ] **H4** 示例数据不是整数指标、不是张三李四、不是每条都"2 小时前"
- [ ] **H5** 按钮文案说的是**具体动作**（「保存草稿」「周二发送」），不是「提交 / 确定 / 了解更多」
- [ ] **H6** 页面上的多个演示共用**同一个虚构场景**，互相呼应
- [ ] **H7** 画面上没有「示例」「示意图」「未接入」「仅保存在本机」这类**制作说明**

---

## I. 图标、动效与评审（规则 24–26）

- [ ] **I1** 图标不是 Lucide / Heroicons 的默认样式（或已明确沿用项目现有图标库，且描边与端点统一）
- [ ] **I2** 图标描边粗细与同尺寸正文字重匹配（细字 1–1.5px，粗黑体 2px+ 或实心）
- [ ] **I3** 图标尺寸约为字号的 1–1.25 倍，按**视觉中心**与文字对齐
- [ ] **I4** 陌生图标配了可见文字；纯图标按钮有可访问名称
- [ ] **I5** **三处基本动效**已做：主操作反馈、一处状态切换的来路、首次进入的出场
- [ ] **I6** 动效时长在区间内（按下 150–300ms / 整页切换 350–500ms）；过冲幅度跟面积走（大面积 ≤2%，小物件 10–20%）
- [ ] **I7** 动效有证据：3–5 秒录屏，或开始 / 中间 / 结束三帧
- [ ] **I8** 开启「减少动态效果」走查过，所有状态直接到位
- [ ] **I9** 已做一次**减法**：一页只有一个主角，逐区块删过一轮不影响理解的文字
- [ ] **I10** 已跑**独立评审**（或明确标注「未独立评审」）；评分附带具体差距，且只做一轮

---

## J. 一致性清扫

- [ ] **J1** 所有颜色取自令牌，没有散落的十六进制硬编码
- [ ] **J2** 同类组件（所有卡片 / 所有按钮）样式完全一致
- [ ] **J3** 若支持深色模式：背景非纯黑、主色提亮、对比度重算、阴影换边框
