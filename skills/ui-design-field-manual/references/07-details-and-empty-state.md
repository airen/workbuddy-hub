# 07 ｜ 细节打磨：克制用线与做好空状态设计

> 覆盖 **规则 19–20**。这一章解决"界面像 Excel、新用户进来一脸懵"。

---

## 规则 19：慎用边框

当需要区分两个相邻元素或列表时，**请先克制住自己，别急着画上一条 1px 的灰色边框**。

边框固然是区分元素的有效手段，但**滥用边框会让整个界面布满网格线，切得细碎拥挤，宛如一张噪点爆炸的 Excel 电子表格**。

### 画线之前，先试这三种更高级柔和的替代手段

| 替代手段 | 做法 |
|---|---|
| **利用背景色差** | 页面大底用微灰（如 `#f8fafc`），卡片用纯白（`#ffffff`）——两者仅凭底色微差就能自然区隔，**根本无需多画边框** |
| **拉开留白间距** | 直接拉大两组元素之间的距离，**留白本身就是最好的分割线** |
| **巧用微弱阴影** | 让卡片轻微浮起，边缘的柔和阴影自然勾勒出轮廓 |

### 准则

> 核心**不是绝对禁用边框，而是"克制"**——如果背景差或留白已经足够说明归属，就果断删掉多余的线条。

### 工程落地

```html
<!-- ❌ 到处画线 -->
<div class="bg-white border border-gray-200">
  <div class="border-b border-gray-200 p-4">…</div>
  <div class="border-b border-gray-200 p-4">…</div>
</div>

<!-- ✅ 背景色差 + 留白 -->
<div class="bg-slate-50 p-6">
  <div class="bg-white rounded-xl p-6 mb-4 shadow-sm">…</div>
  <div class="bg-white rounded-xl p-6 shadow-sm">…</div>
</div>
```

**什么时候边框是对的**：表格数据行、需要精确对齐的输入框、需要明确可点击区域的次要按钮。**除此之外，默认先想"能不能不用线"。**

- ❌ 优化前：习惯性给每个区块和列表套用 1px 灰色实线边框，线条密集切割碎裂
- ✅ 优化后：彻底移除多余边框，仅凭柔和的背景底色微差与自然留白分区，清爽利落

## 规则 20：别忽视了"空状态"的设计

想象一下：你为一款新功能花大量心血，用完美的模拟数据拼出精美酷炫的界面。功能上线后，一位满怀期待的新用户点了进来——**结果由于没有数据，他看到的只是一个孤零零的空白卡片或光秃秃的表格线框，甚至不知道该点哪里。**

> **如果你的功能依赖用户生成内容，那么"空状态"就应该被优先设计，而不是事后才想起的补救措施。**

### 优秀的空状态要做到两点

| # | 要求 | 做法 |
|---|---|---|
| **1** | **提供清晰的行动号召（CTA）** | 加入友好的**插画或图标**吸引注意力，并**突出核心操作按钮**（如"创建你的第一个项目"），明确告诉用户下一步该做什么 |
| **2** | **隐藏无关的空壳控件** | 在用户创建第一条内容之前，把**标签页、多维筛选器、排序按钮**等毫无用处的辅助控件**暂时隐藏**，避免界面显得凄凉简陋 |

> **空状态是用户与新功能的第一次接触**，让它变得生动友好、目标明确，才能激发用户探索的动力。

### 工程落地

```html
<!-- ❌ 冷冰冰的空提示 -->
<p class="text-gray-400">No contacts found</p>

<!-- ✅ 友好插画 + 温暖文案 + 醒目 CTA -->
<div class="flex flex-col items-center justify-center py-16 text-center">
  <div class="w-20 h-20 rounded-2xl bg-brand-50 grid place-items-center mb-4">
    <svg class="w-8 h-8 text-brand-500">…</svg>
  </div>
  <h3 class="text-lg font-semibold text-slate-900">还没有联系人</h3>
  <p class="text-sm text-slate-500 mt-1 max-w-sm">
    添加第一位联系人，开始管理你的客户关系。
  </p>
  <button class="mt-6 bg-slate-900 text-white px-5 py-2.5 rounded-lg">
    + 添加联系人
  </button>
</div>
<!-- 注意：此时不渲染 标签页 / 筛选器 / 排序按钮 -->
```

### 空状态设计清单

- [ ] 有**图标或插画**（不要只有一行灰字）
- [ ] 有**一句解释**（为什么这里是空的）
- [ ] 有**一个明确的主 CTA**（且它是页面上唯一的高亮按钮）
- [ ] **隐藏**了没有意义的标签页 / 筛选器 / 排序 / 批量操作
- [ ] 视觉上仍然"有设计感"，不是空白占位

**同理还要检查另外两个状态**（AI 生成界面最常见的遗漏）：

| 状态 | 要求 |
|---|---|
| **加载中** | 骨架屏或 spinner，不要白屏闪一下 |
| **出错** | 说明发生了什么 + 给出重试入口，不要只显示 `Error` |

- ❌ 优化前：冷冰冰的 "No contacts found"，用户面对空白无所适从、甚至以为系统卡死
- ✅ 优化后：友好插画配温暖文案，辅以醒目的 "+ Add contact" 行动按钮，清晰指引下一步

---

## 本章速记

1. **边框是最后手段**：先试背景色差 → 留白 → 阴影
2. **空状态优先设计**：给 CTA + 隐藏空壳控件
3. 别忘了**加载态**与**错误态**，三者缺一不可
