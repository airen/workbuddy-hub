# 06 ｜ 质感与图片：合理利用阴影与处理背景反差

> 覆盖 **规则 16–18**。这一章解决"页面太平淡、图片上文字看不清、图标被拉变形"。

---

## 规则 16：用强调色边框为设计添彩

如果你不是平面设计师，该如何给界面**增添一抹亮色**，让它也能像那些拥有精美摄影或多彩插图的设计一样充满吸引力？

有一个**简单却效果显著**的技巧：在那些平淡乏味的界面元素上，添加一道**彩色的强调色边框（Accent Border）**。

### 用在哪里

| 位置 | 效果 |
|---|---|
| 卡片顶部一条彩色条 | 打破大面积白，给平庸卡片视觉重心 |
| 当前选中的导航项 | 高亮当前位置 |
| 提示信息框的侧边一道亮线 | 区分信息类型 |
| 整个页面布局的顶部 | 品牌识别 |

> **在界面上加一个彩色矩形，并不需要什么专业的设计天分**，但这个小小的举动，却能打破单调的大面积白色，为平庸的卡片赋予**视觉重心与层次感**，让作品瞬间看起来更有"设计感"。

### 工程落地

```html
<!-- ❌ 平淡白卡片 -->
<div class="bg-white rounded-xl p-6 shadow-sm">…</div>

<!-- ✅ 顶部一道强调色条 -->
<div class="bg-white rounded-xl shadow-sm overflow-hidden">
  <div class="h-1.5 bg-brand-500"></div>
  <div class="p-6">…</div>
</div>
```

**注意克制**：一个页面里强调色条不宜超过 2–3 处，否则反而变成新的噪音。

- ❌ 优化前：平淡乏味的常规白卡片，缺乏视觉重心与活力
- ✅ 优化后：仅在卡片顶部添加一道亮丽的彩色强调色边框，瞬间增添视觉吸引力与设计感

## 规则 17：图片上的文字，需要稳定的对比度

你是否曾有过这种经历：想在首页那张醒目的**主视觉图（Hero Image）**上放一行文字标题，结果**试遍各种颜色，文字却怎么都看不清**——白色文字在亮处隐形，黑色文字在暗部融为一体。

### 问题不在文字，在背景

**真实的摄影照片具有极复杂的动态光影反差**，单靠调整文字的字号或颜色，**根本无法在每个像素点上都维持稳定的对比度**。

### 解决关键：把治理重心转移到背景上

| 手法 | 做法 |
|---|---|
| **叠加半透明深色蒙版** | 在图片和浅色文字之间垫一层半透明黑色遮罩（`rgba(0,0,0,.4~.6)`），压暗背景高光 |
| **降低图片对比度** | 直接抚平背景图原有的剧烈明暗反差 |
| **叠加品牌单色** | 对图片去色并使用"正片叠底"（Multiply）混合模式，既解决辨识度，又让画面与品牌色调高度和谐 |
| **添加柔和的文字光晕阴影** | 加大文字阴影的**模糊半径**，**不设置偏移**，在文字轮廓边缘局部提升反差 |

### 工程落地

```html
<!-- ✅ 蒙版方案：最通用 -->
<div class="relative">
  <img src="hero.jpg" alt="" class="w-full h-80 object-cover">
  <div class="absolute inset-0 bg-black/50"></div>       <!-- 半透明蒙版 -->
  <h1 class="absolute inset-0 grid place-items-center text-white
             text-4xl font-bold [text-shadow:0_0_24px_rgba(0,0,0,.45)]">
    标题文字
  </h1>
</div>
```

```css
/* 方案二：降低图片对比度 */
.hero-img { filter: contrast(.85) brightness(.9); }

/* 方案三：品牌单色正片叠底 */
.hero-img { filter: grayscale(1) contrast(1.1); mix-blend-mode: multiply; }
```

**判据**：把图片转成灰度，文字仍然清晰可读 → 合格。

- ❌ 优化前：文字直接覆盖在光影复杂的背景照片上，高光暗部交错导致文字看不清
- ✅ 优化后：在背景图上叠加一层半透明深色蒙版，抚平光影反差，文字边缘清晰利落

## 规则 18：万物皆有其适用尺寸：切勿随意缩放

我们都知道把**位图放大**不可取，图片会立刻模糊失真。但在缩放**矢量图标和截图**时，也常踩入另一个陷阱。

### 陷阱一：把小图标放大

在落地页需要一个大尺寸图标，很多人的第一反应是**直接把 24px 的 SVG 放大到 64px**——"反正矢量图放大不糊嘛"。

**但专为小尺寸设计的图标，线条在放大后会显得极其笨拙粗壮、缺乏细节，比例严重失调。**

> **正确做法**：让小图标保持其 **24px 的自然大小**，**外层包裹一个带浅背景色的圆形或圆角矩形容器**来填充空间——既撑起了大布局，又保持了精致感。

### 陷阱二：把大截图缩小

展示产品后台时，**切勿把一张完整的大网页截图强行缩小 70% 塞进小卡片**，文字会变成看不清的蚂蚁线。

> **更聪明的做法**：只截取**核心交互局部**，或者绘制一个略去细枝末节的**简化 UI 示意图**。

### 工程落地

```html
<!-- ❌ 把小图标强行拉大 -->
<svg class="w-16 h-16">…</svg>

<!-- ✅ 保持原尺寸 + 容器填充 -->
<div class="w-16 h-16 rounded-2xl bg-brand-50 grid place-items-center">
  <svg class="w-6 h-6 text-brand-600">…</svg>
</div>
```

| 元素 | 做法 |
|---|---|
| 24px 图标需要大尺寸展示 | 图标不放大，外包 48–64px 浅底容器 |
| 需要展示完整界面截图 | 只截核心区域，或用简化示意图 |
| 需要放大 Logo | 用 SVG 原尺寸 + 容器，不缩放路径 |
| 需要放大照片 | 用更高分辨率原图，不拉伸小图 |

> **万物皆有其适用尺寸，不要盲目等比拉伸。**

- ❌ 优化前：以为矢量图放大不失真，直接把 24px 小图标强行拉大到 48px，比例失调且笨拙粗壮
- ✅ 优化后：保持小图标自然尺寸，外包一层带浅底色的圆形容器填充空间，比例协调精致

## 本章速记

1. 一道**强调色边框**，最小代价换最大设计感（但别超过 2–3 处）
2. 图片上的文字看不清 → **治背景**：蒙版 / 降对比 / 单色叠底 + 光晕阴影
3. 图标**不放大**（外包容器），截图**不缩小**（截局部）
