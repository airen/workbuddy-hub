# 08 ｜ 工程落地参数：设计令牌与数值刻度

> 这一章把 26 条军规变成**可直接抄进代码的数值**。写界面代码前先读一遍，把令牌落到项目里，后面所有组件都从这里取值——**不要在每个组件里现编数值**。

---

## 一、间距刻度（Spacing Scale）

**基准 4px**，主刻度用 8px 的倍数。**禁止出现 `13px`、`17px` 这种随手值。**

| 令牌 | 值 | 用途 |
|---|---|---|
| `--space-1` | 4px | 图标与文字间距、紧密元素 |
| `--space-2` | 8px | **组内距**（标签 ↔ 输入框） |
| `--space-3` | 12px | 紧凑组内距 |
| `--space-4` | 16px | 卡片内边距（移动端）、常规组内距 |
| `--space-6` | 24px | **卡片内边距（桌面端）** |
| `--space-8` | 32px | **组间距**（字段组 ↔ 字段组） |
| `--space-12` | 48px | 区块间距 |
| `--space-16` | 64px | 大区块 / 段落间距 |
| `--space-24` | 96px | 页面主区块分隔 |
| `--space-32` | 128px | Hero / 大留白 |

> **规则 09 的落地**：组内距用 8–12px，组间距用 32–48px，比例 **3–4 倍**。

## 二、字号与行高配对表（Type Scale）

**行高与字号成反比**（规则 11）。

| 角色 | 字号（桌面） | 字号（移动） | 行高 | 字重 |
|---|---|---|---|---|
| Display / Hero | 56–64px | 32–36px | **1.1** | 700 |
| H1 | 40px | 28–32px | **1.15** | 700 |
| H2 | 32px | 24px | **1.25** | 600 |
| H3 | 24px | 20px | **1.3** | 600 |
| H4 | 20px | 18px | 1.4 | 600 |
| 正文 Large | 18px | 16px | 1.6 | 400 |
| **正文 Base** | **16px** | **15–16px** | **1.55** | 400 |
| 小字 / 说明 | 14px | 14px | 1.5 | 400 |
| 标签 / 时间戳 | 12–13px | 12px | 1.4 | 500 |

**硬约束**：

- **字重不低于 400**（规则 03）
- 大标题行高 **1.1–1.2**，正文 **1.5–1.6**，宽段落可到 **1.8**
- 移动端字号不是等比缩放：**字号越大，缩得越狠**（规则 10）

### 文字颜色层级（三种颜色 + 两种字重）

| 角色 | 颜色（浅色模式） | 字重 |
|---|---|---|
| 主内容 / 标题 | `#0f172a`（slate-900） | 600–700 |
| 正文 / 次要 | `#475569`（slate-600） | 400–500 |
| 辅助说明 | `#94a3b8`（slate-400） | 400 |

### 品牌主色（10 档）

**用法约定**：

| 档位 | 用途 |
|---|---|
| 50 / 100 | 轻量背景（浅底深字） |
| 500 / 600 | 按钮、激活态 |
| 700 / 800 | 浅色背景上的彩色文字 |

### 语义色（各 5–10 档）

| 语义 | 浅底 | 深字 | 强调 |
|---|---|---|---|
| 成功 / 正向 | `emerald-50` | `emerald-700` | `emerald-500` |
| 警告 / 提示 | `amber-50` | `amber-800` | `amber-500` |
| 错误 / 破坏 | `red-50` | `red-700` | `red-600` |
| 信息 / 新功能 | `blue-50` | `blue-700` | `blue-500` |

> **规则 14 落地**：彩色小标签一律用「浅底（50 档）+ 深字（700 档）」。

## 五、对比度校验（规则 14 / 15）

| 内容 | 最低对比度 |
|---|---|
| 正文（< 18px） | **4.5:1** |
| 大字号（≥ 18px 粗体 或 ≥ 24px） | 3:1 |
| 图标 / 图形 / 边框 | 3:1 |

**校验方法**：

```js
// WCAG 相对亮度对比度
function contrast(hex1, hex2) {
  const lum = (hex) => {
    const [r, g, b] = hex.match(/\w\w/g).map((c) => {
      const v = parseInt(c, 16) / 255;
      return v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4;
    });
    return 0.2126 * r + 0.7152 * g + 0.0722 * b;
  };
  const [a, b] = [lum(hex1), lum(hex2)].sort((x, y) => y - x);
  return (a + 0.05) / (b + 0.05);
}
// 例：contrast('#475569', '#ffffff') → 7.4  ✅
```

## 六、圆角、阴影、边框

### 圆角（与基调一致，规则 01）

| 令牌 | 值 | 气质 |
|---|---|---|
| `--radius-sm` | 4px | 严肃、正式 |
| `--radius-md` | 8px | 中性 |
| `--radius-lg` | 12px | 中性偏亲和 |
| `--radius-xl` | 16px | 亲和、现代 |
| `--radius-2xl` | 20–24px | 活泼、俏皮 |
| `--radius-full` | 9999px | 胶囊 / 头像 |

> **一个页面里最多用 2 种圆角半径**（如 `lg` 给卡片、`md` 给按钮）。出现 4 种就是没定基调。

### 阴影（克制，规则 19）

```css
--shadow-sm: 0 1px 2px rgba(15,23,42,.05);                    /* 卡片默认 */
--shadow-md: 0 4px 12px -2px rgba(15,23,42,.08);              /* 悬浮卡片 */
--shadow-lg: 0 12px 32px -8px rgba(15,23,42,.14);             /* 弹窗 / 下拉 */
```

> **禁止**发光阴影（`box-shadow: 0 0 30px #a855f7`）与多层彩色阴影——那是 AI 塑料风的标志。

### 边框

```css
--border-subtle: 1px solid #e2e8f0;   /* 仅在必要时 */
```

> **规则 19 落地**：优先用背景色差（页面 `#f8fafc` / 卡片 `#ffffff`）与留白分区，边框是最后手段。

## 八、深色模式注意

1. **不要简单反转**：深色模式不是把 `#fff` 换成 `#000`。背景用 `#0f172a`（不是纯黑），卡片用 `#1e293b`。
2. **降低饱和**：深色背景上的主色要提亮（用 400 档而非 600 档），否则显得脏。
3. **阴影失效**：深色下阴影不可见，改用**边框 + 背景层级差**表达浮起。
4. **纯白文字刺眼**：正文用 `#cbd5e1`，标题用 `#f1f5f9`，不用 `#ffffff`。
5. **对比度重算**：浅色模式下的"浅底深字"标签，深色模式要反过来变成"深底浅字"。

## 九、落地检查清单

- [ ] 间距只用刻度值（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64…），无随手值
- [ ] 组间距 ≥ 组内距的 2 倍
- [ ] 行高按层级给值，没有全局 `line-height: 1.5`
- [ ] 文字只有 2–3 种颜色、2 种字重
- [ ] 内容宽度有约束，正文 `max-width: 65ch` 左右
- [ ] 彩色标签用浅底深字
- [ ] 状态信息有颜色 + 图标双通道
- [ ] 圆角半径 ≤ 2 种
- [ ] 没有发光阴影
- [ ] 对比度正文 ≥ 4.5:1
