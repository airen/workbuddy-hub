# Jev 判断体系解读

Jev 是 TypeSafe AI 的 "System One" 模型。jev-seo 向它提**类型化问题**并**保留概率答案**——每个答案带置信概率；落在决定性区间之外的答案在所有报告中标 `to verify`（待验证）。

上游参考：jev-seo `references/` 下的「Jev 问题注册表」含完整问题措辞与决定性阈值；问题措辞与阈值经 A/B 测试选定（决定性页面答案率从 47% 提升至 80%）。**主页类型由代码设定，从不询问 Jev。**

## 页面级问题（13 个，上游已公开的 9 个）

| 问题 | 回答用途 | 整改联动 |
|---|---|---|
| 页面类型（page type） | 判断这是首页/产品页/文章/分类页… | 结构化数据选型的基础 |
| 搜索意图（search intent） | 这页在抢哪类查询 | 与 title/meta 一致性核对 |
| 重要性（importance） | 对站点的权重 | 整改排期参考 |
| 有帮助性（helpfulness） | 内容是否真解决问题 | 低 → 补经验/数据/示例 |
| 特异性（specificity） | 是否具体还是泛泛而谈 | 低 → 换具体数字/步骤/场景 |
| 信任度（trust） | E-E-A-T 信号 | 低 → 署名/资质/来源/联系方式 |
| 可引用性（citability） | 能否被整段引用（AI/摘要场景） | 低 → 结论前置、段落自足 |
| 标题与 meta 匹配度 | title/description 是否如实概括 | 不匹配 → 重写 |
| 竞争同一搜索的页面对等 | 站内自相残杀检测 | 命中 → 合并页面 + 301 |

> 其余问题措辞以上游 Jev 问题注册表为准；实际审计中，每页判断连同概率出现在 Excel 的「原始 Jev 判断」表与 PDF 的 Jev 卡片里。

## 站点级问题（5 个）

覆盖站点整体判断（如站点类型与定位、整体内容质量倾向等），结论用于站点级整改方向。具体输出看报告站点级摘要。

## 竞争页面对（competing page pairs）

站内多页争同一搜索词的成对检测——这是**关键词自相残杀**的机器证据。处理：合并成一页最全的、其余 301；或在 Search Console 对比两页实际表现再定。

## `--full` 追加判断

- 关键词相关性；
- 其他品牌检查（other-brand checks）；
- 每个关键词的最佳页面（best page per keyword）。

## 解读纪律

1. **看概率。** 概率低的结论（决定性区间外）标 `to verify`，人工看 SERP 复核后再动手；
2. **一致性证据。** 同 59 页跑两次分数平均差 ≤ 0.03、页面类型一致 44/44——工具稳定，但稳定不等于正确；
3. **盲审口径。** 上游用第二模型盲审 Jev 的 decisive 答案：有帮助性/特异性 28/29、直入主题 23/23、下一步 16/16、关键词相关性 27/30——证明的是**一致性与合理性**，不是「人类正确」；
4. **Jev 阈值尚未针对人类标签调优**，引用时如实说明。

## 内容整改联动（速查）

| 信号 | 动作 |
|---|---|
| helpfulness 低 | 补真实经验、数据、示例；删套话 |
| specificity 低 | 具体数字、步骤、场景替换泛化表述 |
| trust 低 | 作者署名、资质、来源、联系方式、更新日期 |
| citability 低 | 结论前置；每段自足可被整段引用 |
| title/meta 不匹配 | 重写使其如实概括页面内容 |
| 竞争页面对命中 | 合并 + 301，或按 Search Console 数据定夺 |
