# 主题与配色生成

用一段文字描述品牌感觉，生成配色和主题，再落到 Tailwind 或 CSS 变量里。

## 适用场景

- 新产品要一套主题
- 老项目颜色各做各的，需要统一
- 需要暗色版本
- 已有品牌色，需要推导出完整色阶与语义色

## 输入

- 品牌感觉的描述（一句话，含行业、气质、偏好）
- 已有的品牌色（有的话，作为锚点）
- 落地形式：CSS 变量 / Tailwind 配置 / 设计令牌文件

## 执行步骤

### 步骤 1 — 从描述里提取三个关键词

例："稳重的金融产品、强调信任、使用深色点缀"

提取：**稳重**（气质）→ 低饱和、大间距；**信任**（情绪）→ 蓝色系、克制；**深色点缀**（手法）→ 暗色作为强调而非主体。

### 步骤 2 — 定色相与饱和策略

| 气质 | 策略 |
|---|---|
| 稳重 / 专业 | 低饱和、蓝或青色系、减少渐变 |
| 活泼 / 消费 | 高饱和、暖色系、允许渐变 |
| 高端 / 克制 | 接近中性色、大面积留白、单一强调色 |
| 技术 / 开发者 | 深色底、高对比、单一荧光强调色 |

### 步骤 3 — 生成色阶

每个角色色生成一组阶梯（通常 50–950），并明确用途：

| 角色 | 用途 |
|---|---|
| 主色 primary | 主行动、选中态、链接 |
| 中性色 neutral | 背景、边框、正文、次级文字 |
| 成功 success | 成功提示、正向状态 |
| 警告 warning | 需要注意但不阻断 |
| 危险 danger | 错误、破坏性操作 |

**强调色只用一种。**两种强调色会让用户分不清哪个更重要。

### 步骤 4 — 出明暗两套

每套都定义：背景（底 / 面 / 浮层）、文字（主 / 次 / 弱）、边框、主色在两种底上的可用变体。

暗色不是把亮色反转：暗底上的饱和色会显得更亮，主色需要降饱和或提亮一档。

### 步骤 5 — 定字体与间距阶梯

- 字体：正文一套、标题一套（可与正文同源），给出字重范围与回退字体
- 字号：给出 5～6 档阶梯（如 12 / 14 / 16 / 20 / 24 / 32）
- 间距：给出阶梯（如 4 / 8 / 12 / 16 / 24 / 32 / 48）
- 圆角：给出 3 档（小 / 中 / 大）

### 步骤 6 — 落到代码

输出 CSS 变量（或 Tailwind 配置）：

```css
:root {
  --color-primary-500: #…;
  --color-neutral-900: #…;
  --radius-md: …;
  --space-4: …;
}
```

暗色用 `[data-theme="dark"]` 或 `prefers-color-scheme` 覆盖同一批变量名。

### 步骤 7 — 对比度核对

逐项确认：正文 / 次级文字 / 主色上的文字，在明暗两套里分别达标。**不达标就调，不要写"大致没问题"。**

## 输出

- 配色系统（角色色 + 色阶 + 用途说明）
- 明暗两套变量代码
- 字体、字号、间距、圆角阶梯
- 对比度核对结果（哪些过了、哪些没过、怎么调）

## 反模式

- **只看主色好不好看**：中性色决定页面 80% 的面积，它比主色更重要
- **两种强调色**：用户分不清重点
- **暗色靠反转亮色**：暗底上饱和色会过亮，需要单独调
- **不核对对比度**：暗色主题下正文不达标是常见事故
- **只给色值不给用途**：拿到手的人会随便用
- **忽略字体回退**：目标环境没有该字体时排版会塌
