## 纪律

1. **单风格原则**：一页一个风格；两个风格的需求拆成两页，不在一套 UI 里混搭。
2. **令牌优先**：色值、字体、间距从 `<slug>.tokens.md` 取，不现场编。
3. **无障碍是地板不是装饰**：每份规则都要求 WCAG 2.2 AA、键盘优先、可见焦点态；美学与可访问性冲突时，可访问性赢。
4. **规则可执行**：每条 do 都配一个 don't；QA 清单要能进 code review。
