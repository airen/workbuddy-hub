# 社媒配图与海报

把文字要求变成能直接发出去的图。

## 适用场景

- 社媒配图（小红书封面、公众号头图、X 配图）
- 活动海报、封面图
- 需要一套风格统一的系列图
- 已有文案，需要配图

## 输入

- 文案与主题（要传达什么）
- 投放平台与尺寸要求
- 品牌规范（有的话）
- 素材：是否能用 AI 出图，是否有可用的真实图片

## 执行步骤

### 步骤 1 — 先确认平台与尺寸

不同平台的阅读场景完全不同，先定尺寸再设计：

| 场景 | 常见比例 | 注意 |
|---|---|---|
| 小红书封面 | 3:4 | 竖版，标题要大，缩略状态也能读 |
| 公众号头图 | 2.35:1 | 横版，两侧可能被裁，核心信息居中 |
| X / 微博配图 | 16:9 | 信息流里会缩小，字要少 |
| 海报 / 印刷 | A 系列或自定义 | 需要更高分辨率 |

**尺寸没确认就出图，等于白做。**

### 步骤 2 — 定一句话主张

一张图只说一件事。把文案压成一句能在 2 秒内读完的主标题，其余都是辅助。

主标题超过 12 个字，在缩略图上会糊成一片。

### 步骤 3 — 排版定骨架

- 主标题区（最大字号，占比最高）
- 视觉焦点区（图 / 图形 / 人物）
- 辅助信息区（副标题、时间、落款）
- 品牌区（logo、账号名，位置固定）

先画分区，再填内容。分区时留出安全边距，避免平台裁切切掉关键信息。

### 步骤 4 — 套用品牌规范

颜色、字体、圆角、logo 位置按 `brand-guidelines` 里的规范执行。没有规范时，至少保证同一系列图之间一致。

### 步骤 5 — 出图与检查

出图后逐项检查：

- [ ] 缩略到 1/4 大小，主标题还读得清吗
- [ ] 平台裁切后（如公众号头图两侧）核心信息还在吗
- [ ] 文字与背景对比度够吗（尤其是压在图片上的文字）
- [ ] 系列图之间：字号、配色、留白是否一致
- [ ] 有没有用错字体或未经授权的素材

### 步骤 6 — 交付与归档

给出最终文件（按平台命名），并记录这套图用的字号、配色、版式参数，方便下次复用。

## 输出

- 成品图文件（按平台尺寸分别输出）
- 版式参数记录（字号、配色、边距）
- 缩略与裁切检查结果

## 反模式

- **不分平台出一套图**：缩略后主标题糊掉，等于白做
- **一张图塞三件事**：信息流里没人会停下来读
- **文字直接压在复杂图片上**：对比度不可控，加蒙版或纯色底
- **系列图各做各的**：品牌感会在第三张开始崩
- **用未授权素材**：商用场景下是硬风险
- **不检查缩略效果**：设计师看到的是原图，用户看到的是缩略图

## 参考

- 需要真实质感图片时用 `image-generation`；出图后用 `image-optimizer` 压体积。
