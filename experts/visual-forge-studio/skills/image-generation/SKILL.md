# 图片生成

调用图片生成能力，产出接近照片质感的图像或本地脚本生成的头像与图标。

## 适用场景

- 内容需要真实质感的配图或素材
- 需要头像、图标这类小尺寸图形（可本地脚本生成）
- 需要多个候选方案供挑选
- 已有描述，需要把它变成图

## 输入

- 要什么图（主体、场景、风格、用途）
- 用途与投放场景（决定尺寸、是否商用）
- 约束：品牌色、是否允许 AI 生成、是否需要真实人物

## 执行步骤

### 步骤 1 — 先确认权利与合规

动手前先过这一关——1～3 要问清答案，4～5 是无条件执行的规则，答不上来就不要往下走：

1. **能不能用 AI 生成的图**：投放平台或客户是否接受
2. **是否涉及真实人物**：真人肖像必须本人授权，AI 生成的类真人图也要标明
3. **是否商用**：商用场景下的模型许可与素材授权要确认
4. **不生成这些（无条件）**：能识别出是某个真实人物的形象（除非能出示本人授权凭据，「第三方说有授权」不算）；未成年人形象；性暗示、暴力或违法内容；他人商标、受版权保护的卡通形象与作品；可用于冒充证件、签名、票据的图像。这几类不解释、不询问、不做
5. **用户提供的图片不外传**：用户给的私有图片（尤其含人脸、证件、住址、个人信息）上传外部模型前必须取得**明确同意**，并说明会发往哪个服务、可能留存多久。拿不到同意就改用本地方式或不做

**涉及人物肖像与版权的部分，宁可不做，不要猜。**

### 步骤 2 — 写清楚主体与场景

生成效果差，八成是描述太笼统。描述至少包含：

```
主体：<是什么，什么材质 / 品类>
场景：<在哪，周围环境>
光线：<自然光 / 棚拍 / 逆光>
构图：<特写 / 平视 / 俯拍，留白位置>
风格：<写实 / 插画 / 极简>
色彩：<主色调，是否要贴近品牌色>
```

### 步骤 3 — 出多个候选，不要只出一张

同一描述出 3～4 个候选，再挑。**只出一张等于把选择权交给了随机种子。**

### 步骤 4 — 挑选并核对

按这三项挑：

- 主体是否准确（有没有多出或缺少元素、变形）
- 是否符合品牌气质（配色、光线、质感）
- 是否有明显缺陷（多余的手指、错乱的文字、扭曲的结构）

图上有文字时要特别检查：生成模型经常写错字。

### 步骤 5 — 后续处理与归档

- 按用途裁切尺寸，走 `image-optimizer` 压体积
- 记录：用的什么描述、哪个候选、最终参数，方便复现
- **标明来源**：交付说明里注明这是 AI 生成，并写明**所用能力 / 模型及其许可条款**；生成参数与生成时间在文件中一并记录，便于复现与后续商用取证

## 输出

- 成品图文件（含候选与最终选择）
- 生成描述记录（便于复现）
- 权利与合规说明（是否 AI 生成、授权情况）

## 反模式

- **不确认肖像与版权就生成**：商用后是硬风险
- **描述只写"好看的图"**：产出完全不可控
- **只出一张就交**：等于让随机种子做决定
- **不检查图上的文字**：生成模型写错别字是常态
- **不注明 AI 生成**：平台与读者有权要求标明
- **生成完不压体积**：直接把几 MB 的原图放上网页
