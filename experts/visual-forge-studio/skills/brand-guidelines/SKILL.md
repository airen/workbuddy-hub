# 品牌一致性

让后续制作的组件遵循既定品牌规范，减少颜色、字体和视觉风格各做各的情况。

## 适用场景

- 已有品牌规范，需要让产出遵守它
- 一堆视觉产物风格漂移，需要一次一致性检查
- 多人 / 多次产出，需要一条可对照的基线
- 新成员接手，需要一份明确的规范清单

## 输入

- 品牌规范（已有的话：配色、字体、logo、语气）
- 待检查的产物（页面、图片、组件）
- 没有规范时的替代：从现有最成熟的一份产物里反推

## 执行步骤

### 步骤 1 — 建立（或读取）规范基线

规范至少包含七项，缺哪补哪：

| 项 | 内容 |
|---|---|
| 主色与强调色 | 色值 + 允许的用法 + 禁止的用法 |
| 中性色 | 背景 / 文字 / 边框各级色值 |
| 语义色 | 成功、警告、危险 |
| 字体 | 正文字体、标题字体、字重范围、回退字体 |
| 圆角 | 小 / 中 / 大三档取值 |
| 间距 | 阶梯取值 |
| logo | 位置、安全边距、最小尺寸、不可用方式 |

没有现成规范时，从**现有最成熟的那份产物**里反推，并标注"反推而来，待确认"。

### 步骤 2 — 把规范写成可对照的清单

不要写"风格要统一"这种无法核对的话。写成可逐项打勾的条目：

```
- [ ] 主色只出现在主行动与选中态
- [ ] 正文颜色使用 neutral-800（暗色主题用 neutral-100）
- [ ] 圆角只使用 4 / 8 / 16 三档
```

### 步骤 3 — 逐项检查产物

按清单过一遍每个产物，记录偏差。偏差按两级分：

- **违反**：用了规范外的颜色 / 字体 / 圆角，或 logo 用法错误 → 必须改
- **漂移**：不违规但与规范气质不符（如用了渐变而规范是克制风格）→ 建议改

### 步骤 4 — 定位偏差来源

偏差通常来自三类：

1. **随手取值**：临时加了一个"看起来更合适"的颜色
2. **复制粘贴**：从别的页面拷过来，带上了那边的风格
3. **规范缺失**：规范里根本没定义这种情况（如加载态、空状态）

第三类要**回头补规范**，不是临时决定。

### 步骤 5 — 修正并沉淀

修掉违反项；把新遇到的情况补进规范（新版本 + 变更说明）。

## 输出

- 规范基线（七项齐全，或标注缺失项）
- 检查清单与逐项结论
- 偏差列表（位置 + 级别 + 改法）
- 规范补充建议

## 反模式

- **规范写"风格要统一"**：无法核对，等于没写
- **只查颜色不查字体和圆角**：漂移往往发生在这两处
- **偏差不分级**：全部标成必须改，规范会被绕过
- **遇到规范没定义的情况就临时决定**：下次还会再遇到
- **规范写完不维护**：半年后它已经和现实脱节
- **logo 用法不写禁止项**：最常见的违规就是拉伸、改色、加阴影
