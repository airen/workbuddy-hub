# CRO Playbook · 转化优化实战手册

> 配合 `conversion-optimization` 技能使用。把访客变成注册、付费用户的通用打法。

## 一、漏斗诊断表（五段）

| 阶段 | 关键问题 | 常见流失原因 | 主攻动作 |
|---|---|---|---|
| 访客 → 注册 | 为什么现在不注册？ | 价值不清、不信任、步骤多 | 首页 CRO、砍字段 |
| 注册 → 激活 | 注册完为什么不用？ | 不知道干嘛、没引导、空状态 | onboarding 路径、示例数据 |
| 激活 → 付费墙 | 为什么不愿付费？ | 价值没被验证、价格没锚点 | 免费额度、付费墙文案 |
| 付费墙 → 付费 | 为什么卡在最后一关？ | 价格高、没保障、决策慢 | 担保、案例、限时 |
| 付费 → 续费 | 为什么不续？ | 没用出习惯、没见效 | 留存循环（见 growth-retention） |

**优先改"掉得最狠 + 最容易改"的 1–2 段**，别一次性动全部。

## 二、首页 / 落地页 12 问

1. 首屏 5 秒内，新访客能说出"这是什么、对我有什么用"吗？
2. 价值主张是不是"对 ICP 说话"，还是"对同行炫技"？
3. 主 CTA 是不是只有一个、动作清晰（"下一步做什么"）？
4. 有没有用 ICP 的语言，还是通用套话（"赋能""一站式"）？
5. 信任证据够吗（案例、数字、客户 logo、评价）？
6. 首屏有没有图 / 视频让人"秒懂"？
7. 移动端首屏是不是也成立？
8. 页面加载是不是够快（>3s 掉一大半）？
9. 注册入口是不是到处都在（不止页脚）？
10. 文案有没有"具体"到能让人信（"省 3 小时/天" vs "提升效率"）？
11. 有没有社会证明 / 实时数据（"已有 12,000 团队在用"）？
12. 页面有没有一个清晰的"读完后该做什么"？

## 三、注册流程瘦身清单

- 字段能不能从 N 砍到 ≤3（邮箱 + 密码 + 名字）？
- 能不能社交登录 / 邮箱一键？
- 错误提示是不是"人话"且指出怎么改？
- 注册后是不是立刻进"激活路径"，而不是扔给空白后台？
- 有没有进度提示（"第 2/3 步"）？

## 四、激活路径模板（从注册到第一次价值）

```
注册 → 引导一步动作（导入 / 建第一个项目 / 看 demo）
     → 给示例数据 / 模板，降低"从零开始"的恐惧
     → 首个工作完成时的"啊哈"提示 + 下一步建议
     → 7 天内关键行为触发（邮件 / 站内信）
```

## 五、弹窗红线（不惹人烦）

- 时机：滚动 ≥50% 或退出意图，**别一进页面就弹**。
- 文案：给价值（"要这份清单吗？"），不是"订阅我们的新闻"。
- 关闭：X 明显、点击遮罩也能关、别做假关闭。
- 频次：同一用户 30 天内最多弹 1 次。

## 六、付费墙两种摆法（A/B）

- **A · 功能分层**：免费给核心、付费解高级；墙内写"升级解锁 X"。
- **B · 用量锚点**：免费给 N 次，超出提示"已用完，升级继续"。

两种都配一句价值锚："升级后，你的团队能 ______。"
