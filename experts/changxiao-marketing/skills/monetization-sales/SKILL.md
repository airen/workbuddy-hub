# 变现与销售（定价 / 发布 / RevOps / 销售赋能）

对应原库 `monetization-sales` 模块：**把增长变成收入和可持续的生意**。涵盖 launch（发布）、pricing（定价）、revops（收入运营）、sales-enablement（销售赋能）。交付的是**定价画布 + 发布清单 + 销售素材**。

> 前置：`product-marketing` 定下的 ICP 付费意愿，是定价的根基；`conversion-optimization` 决定付费墙怎么接。没定先回去补。

## 适用场景

- "我们的定价应该怎么定"
- "新产品要发布了，给个清单"
- "销售团队需要一套说辞和素材"
- "怎么把免费用户转成付费"

## 输入

- 产品成本结构与目标毛利（没有就说"假设"）
- 竞品定价（用户说得出，或推断）
- ICP 的付费意愿与预算（来自 product-marketing）
- 现有价格 / 转化数据

## 执行步骤

### 1. 定价画布
读取 `references/pricing-canvas.md`，填：价值锚 → 分层（免费/Pro/团队/企业）→ 每层解锁什么 → 锚点怎么摆 → 年付折扣。
给 2–3 套定价结构方案 + 各自的适用场景与风险。

### 2. 发布清单
读取 `references/launch-checklist.md`，给一份分阶段发布清单：
- 预热（名单 / 预告 / 等待列表）
- 发布日（渠道 / 动作 / 衡量）
- 发布后（跟进 / 复盘）
标注"哪些现在就能做、哪些要等素材/决策"。

### 3. 销售赋能
给一套销售素材：
- **一句话价值主张**（销售开口用）
- ** objection 应对表**（常见拒绝 + 怎么回）
- **demo 脚本**（3 分钟讲清价值）
- **报价单模板**

### 4. RevOps 基础
给最小收入运营口径：线索 → 商机 → 成交 → 续费，每个阶段一个核心指标 + 负责人（角色）。

## 输出

- 一份**定价画布**（2–3 套方案 + 风险）
- 一份**发布清单**（预热/发布日/发布后）
- 一套**销售赋能素材**（主张/应对/demo/报价）
- 一套**RevOps 口径**（线索→续费指标）

## 边界

- 不替用户拍板"定哪个价"——给方案 + 风险 + 实验建议（小流量测价），让用户定。
- 财务模型（LTV/CAC 精算）是深水区，给基础公式 + 假设，精确测算靠财务/数据。
- 销售话术要合规，不夸大、不虚假承诺。
