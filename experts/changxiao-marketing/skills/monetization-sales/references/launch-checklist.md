# Launch Checklist · 发布清单

> 配合 `monetization-sales` 使用。分阶段，标 ✓ / 待办 / 假设。

## 一、预热期（发布前 2–4 周）
- [ ] 建等待列表 / 落地页收集意向
- [ ] 给老用户 / 名单发预告（钩子，不剧透全貌）
- [ ] 准备 1–2 篇"为什么做这个"的故事文
- [ ] 找 3–5 个内测用户攒早期评价

## 二、发布日
- [ ] 主渠道齐发（官网 / 社媒 / 邮件 / 社群）
- [ ] 首页 / 落地页切到新版本（回 `conversion-optimization`）
- [ ] 准备"发布说明"图文，讲清价值
- [ ] 团队在线答疑（社群 / 评论区）
- [ ] 埋好衡量（流量 / 注册 / 付费，回 `ads-measurement`）

## 三、发布后（1–2 周）
- [ ] 首日 / 首周数据复盘（哪渠道带来最多注册）
- [ ] 给未转化意向用户发跟进（价值提醒）
- [ ] 收集首批反馈，列"下周要修的 3 件事"
- [ ] 把成功案例写成素材（回 `copywriting-content` / 销售赋能）

## 销售赋能素材包
- [ ] 一句话价值主张（销售开口）
- [ ] Objection 应对表（"太贵了"→…；"再用用看"→…）
- [ ] 3 分钟 demo 脚本
- [ ] 报价单模板（含分层 + 年付折扣）

> 发布不是终点——发布后 2 周的动作，往往决定这批流量能不能留下来变收入。
