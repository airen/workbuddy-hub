# 定位画布（Positioning Canvas）

把"产品卖给谁、解决什么问题、与别人有何不同"用一句话模板写清楚。填好下面 6 个字段，就能拼出一句可用的定位陈述。

## 模板

```
[产品名] 是为 [目标受众] 设计的 [品类]，
它帮用户在 [场景] 解决 [核心问题]，
得到 [核心收益]，
不像 [替代方案] 那样 [短板]，
因为 [差异化能力 / 证据]。
```

## 6 个字段

| 字段 | 怎么填 | 避坑 |
|---|---|---|
| **目标受众**（for） | 一类具体的人/角色/公司类型；不要写"所有需要 XXX 的人" | 越具体越好；先想"我们最赚钱/最满意的客户是谁" |
| **品类**（is a） | 用用户脑子里的品类词（如"在线表格""AI 写作助手""项目管理工具"） | 别造新词；用用户已经搜索/说出口的词 |
| **场景/任务**（when） | 在什么具体场景下用 | 用动词开头："写周报""汇报项目""整理发票" |
| **核心问题**（that） | 用户在该场景下最痛的 1 件事 | 别列 5 件，挑最痛的那件；不痛就换场景 |
| **核心收益**（you get） | 解决了之后得到的具体好处（量化最好） | "省 5 小时"比"高效"好；"自动存档"比"安全"好 |
| **差异化 / 证据**（unlike / because） | 与最常见的替代方案比，你凭什么能做到 | 要可验证的差异（技术/数据/流程），不要"我们更用心" |

## 例子

| 字段 | 内容 |
|---|---|
| 产品名 | 长销 |
| 目标受众 | 独立开发者和小型 SaaS 团队的 marketing lead |
| 品类 | 一站式的 AI 营销助手 |
| 场景 | 每周要发周报、跑 SEO、改首页、写邮件 |
| 核心问题 | 营销技能多且散，每次都得从零想 |
| 核心收益 | 一句话就能出审计/文案/邮件方案，省下每周 5 小时 |
| 替代方案 | 单独用 ChatGPT 写文案 + 手动跑 SEO 工具 + 自己学邮件营销 |
| 差异化 | 50 项营销技能按 7 大类内化，能跨技能组合（文案+SEO+CRO 一条龙），不止单点工具 |

→ 拼成定位陈述：
> 长销是为独立开发者和小型 SaaS 团队的 marketing lead 设计的一站式 AI 营销助手，帮用户在每周的周报、SEO、首页、邮件场景下，解决"营销技能多且散、每次都得从零想"的问题，得到"一句话就能出审计/文案/邮件方案、省下每周 5 小时"的收益，不像"单独用 ChatGPT 写文案 + 手动跑 SEO 工具 + 自己学邮件营销"那样需要拼凑，因为长销已把 50 项技能按 7 大类内化、能跨技能组合。

## 自检三问

1. **受众画像** 看到这句话，3 秒内能说"这说的就是我的痛"吗？
2. **价值主张** 说出来不会被同行笑"和隔壁那家没区别"吗？
3. **差异化** 有可验证的证据（数据/技术/案例）支撑吗？

任意一条不过，回到画布改对应字段。
