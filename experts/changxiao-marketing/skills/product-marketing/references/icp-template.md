# ICP 画像模板（Ideal Customer Profile）

理想客户画像——比"目标用户"更具体的"我们最想卖给的那个人"。下游所有营销动作（文案/SEO/投放/转化）都围着 ICP 转。

## 用法

- 填 1–2 份主 ICP（最多 3 份）
- 每份 ICP 用一段叙事 + 一组属性表
- 不要写成"所有人"——越具体，越好写文案、越好选关键词、越好挑投放渠道

## 模板

```
### ICP 1：[一句话角色名，如"国内中型 SaaS 的市场负责人"]

[一段叙事：她是谁，在什么样的公司，今天一天怎么过，为什么会留意到我们。]

#### 基本信息
- 行业 / 公司规模 / 所在城市：
- 职位 / 汇报对象 / 团队规模：
- 个人收入与公司预算大致区间：

#### 痛点（按重要性排）
1. （最痛）

#### 触发事件（什么场景下开始找解决方案）
- 例：上周被老板骂了一次转化率
- 例：新产品上线没流量
- 例：Q3 续费率掉了

#### 决策链路
- 谁发起 / 谁评估 / 谁拍板 / 谁付款：
- 评估标准（按权重排）：
  1.
  2.
  3.

#### 信息获取渠道
- 平时读什么：公众号 / 播客 / newsletter / 行业报告
- 搜索习惯：用哪些关键词搜
- 社交平台：朋友圈 / 微博 / X / 小红书 / LinkedIn
- 同行群：哪些群里

#### 一句心声
> "如果有人能帮我 [做某事]，我愿意 [付出的代价]。"
```

## 例子

```
### ICP 1：国内 20–80 人 SaaS 的市场负责人

小敏，30 出头，国内一家做团队协作 SaaS 的市场负责人。团队 3 个人，
老板每两周要她出一次"转化漏斗数据 + 下一步计划"。她每天要写推文、
改落地页、跟销售对线索质量。预算不多，得每一分都花在刀刃上。

#### 基本信息
- 行业 / 规模 / 城市：协作 SaaS / 20–80 人 / 北京/杭州/深圳
- 职位 / 汇报对象 / 团队：市场负责人，向 VP 汇报，团队 3 人
- 预算区间：每月 5–15 万营销预算

#### 痛点
1. 转化数据看不清，不知道改动到底有没有用
2. 落地页改了好几版，老板还是嫌"不够说服人"
3. 内容产出跟不上，公众号周更都难

#### 触发事件
- 上个月投放 ROI 被 CFO 当众点名
- 老板说"我们官网首页不行，必须改"

#### 决策链路
- 发起/评估：小敏自己
- 拍板：VP 营销
- 付款：小敏批预算
- 评估标准：①能不能真提升转化 ②团队能不能快速上手 ③性价比

#### 信息获取渠道
- 读：晚点 LatePost、刀法研究所、人人都是产品经理
- 搜索：百度/微信搜"SaaS 落地页 转化率 优化"
- 社交：朋友圈、知乎、LinkedIn
- 群：几个增长圈、SaaS 同行群

#### 一句心声
> "如果有人能帮我在一周内把首页改完、且我看得懂改了啥、为啥能涨转化，我愿意按月付费。"
```

## 写好 ICP 后的下一步

把这张图当作"下游技能的默认读者"：
- 写文案 → 用 ICP 的语言、踩 ICP 的痛点
- 选 SEO 关键词 → 用 ICP 的搜索习惯
- 选投放渠道 → 用 ICP 的信息获取渠道
- 设计转化漏斗 → 用 ICP 的决策链路

如果一份 ICP 写完之后下游技能依然"不知道怎么写"，说明 ICP 还没具体到能指导行动——回到模板再补一刀。
