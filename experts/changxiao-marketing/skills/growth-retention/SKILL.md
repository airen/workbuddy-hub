# 增长与留存（推荐循环 / 免费工具 / 流失预防 / 联运）

对应原库 `growth-retention` 模块：**增长不是一次性拉新，是让用户在的产品里转起来、还带朋友来**。涵盖 referrals（推荐）、free-tools（免费工具）、churn-prevention（流失预防）、co-marketing（联运）。交付的是**能落地的循环设计 + 清单**。

> 前置：`product-marketing` 定下的 ICP 痛点，决定"什么能让人留下、什么值得推荐"。没定先回去补。

## 适用场景

- "怎么让用户帮我拉新"
- "用户用几次就不用了，怎么预防流失"
- "做个免费工具能不能带流量"
- "能不能找别的品牌一起推"

## 输入

- 产品形态（SaaS / 工具 / 社区 / 实物）
- 用户当前使用频率与流失观察（没有就说"假设"）
- 有没有可分享的内容 / 资产

## 执行步骤

### 1. 留存循环诊断
读取 `references/retention-loops.md`，按"触发 → 行动 → 奖励 → 投入"四步看用户现在卡在哪：
- 用户有没有"每周都回来"的理由（习惯钩子）？
- 流失前有没有预警信号（登录变少、功能不用）？

### 2. 推荐方案
读取 `references/referral-program.md`，给一套"双边激励"设计：
- 邀请人得到什么、被邀人得到什么（两边都得有动力）
- 触发点放在哪（完成某个啊哈时刻后）
- 文案成稿（邀请话术、落地页）

### 3. 免费工具
给 1–2 个"轻量、能病毒传播"的免费工具方向（计算器 / 模板 / 测评），说明怎么引流回主产品。

### 4. 流失预防
- 预警：定义流失信号 + 触发干预（邮件 / 站内）。
- 召回：给 3 段式召回序列（提醒价值 → 给新东西 → 最后通牒优惠）。

### 5. 联运（co-marketing）
给 1 个"互补不竞争"的联运方向（联合直播 / 互荐 / 合写内容），含分工与价值交换。

## 输出

- 一份**留存循环诊断**（卡在哪一步）
- 一套**推荐方案**（双边激励 + 触发点 + 文案）
- **免费工具**方向（1–2 个）
- **流失预防**清单（预警 + 召回序列）
- **联运**方向（1 个）

## 边界

- 不替用户决定"给多少奖励"这种成本决策——给方案 + 风险，让用户拍板。
- 推荐机制要防刷（双边都给真实价值，不是纯利诱），避免违规。
- 实际跑增长实验靠产品 / 数据工具，本技能给"怎么设计"。
