# Retention Loops · 留存循环设计

> 配合 `growth-retention` 使用。用户"转起来"才留得住。

## 循环四步
1. **触发（Trigger）**：什么让用户回来？（日历提醒 / 新内容 / 社交通知 / 习惯钩子）
2. **行动（Action）**：回来做哪一件最小动作？（打卡 / 看一条 / 发一条）
3. **奖励（Reward）**：做完得到什么？（数据进展 / 社交反馈 / 内容解锁）
4. **投入（Investment）**：用户往里存了什么？（资料 / 关注 / 作品，越存越离不开）

> 四步闭环 = 习惯。断在任一步，用户就溜了。

## 诊断：卡在哪一步
| 断点 | 表现 | 修补 |
|---|---|---|
| 触发弱 | 用户忘了你 | 加提醒 / 周期内容 / 社交钩子 |
| 行动重 | 回来也不知道干啥 | 给"下一步"单动作引导 |
| 奖励淡 | 做了没感觉 | 让进展可见（进度条 / 数字） |
| 投入少 | 随时能走没成本 | 让用户存内容 / 关系 / 设置 |

## 习惯钩子示例
- 内容类：每周一发给你的"本周精选"
- 工具类：你的数据每天自动更新，回来看变化
- 社区类：有人 @你 / 评论你，不回不行
- SaaS 类：把工作流嵌进团队日常，离开要迁移成本
