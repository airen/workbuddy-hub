# A/B Test Plan · A-B 测试计划模板

> 配合 `ads-measurement` 使用。一次只验一个变量。

## 测试计划结构

```
1. 假设：把 [变量 A] 改成 [变量 B]，预期 [指标] 提升 [X%]。
2. 变量：只动一个（标题 / 受众 / 落地页首屏 / CTA 文案）。
3. 分组：对照组（原版）vs 实验组（新版），流量 50/50。
4. 样本量：预估需要 [N] 次转化才有意义（太小别下结论）。
5. 周期：至少跑 [X] 天 / 直到达到样本量（别中途看一眼就停）。
6. 判定：到达样本量后，[指标] 提升且置信度 ≥ 95% 才算赢。
7. 护栏：若实验组核心指标跌超 [X%]，立即回滚。
```

## 常见可验变量（优先级）
1. 广告标题 / 主图（影响 CTR，最容易验）
2. 落地页主 CTA 文案（影响 CVR）
3. 受众定向（影响 CAC）
4. 落地页首屏价值主张（影响整体转化）

## 判定线示例
- 赢：实验组 CTR 1.8% vs 对照 1.2%，样本足、置信 ≥95% → 全量。
- 平：差异 <5% 且不显著 → 维持原版，换变量再试。
- 输：实验组明显更差 → 回滚，记录"这条路不通"。

> 别一次开 10 个测试——资源分散，哪个都测不准。
