# 视觉层级与扫读动线

> 读者在信息流里给你的时间大约是 **1.5 秒**。层级没做对，他就划走了。

## 一、一页三层级

任何一页只允许三个层级：

```
第 1 层：主标题        ← 一眼看到，决定要不要继续看
第 2 层：次级信息      ← 支撑主标题，决定要不要细读
第 3 层：正文 / 说明   ← 提供细节
```

**超过三层 = 失焦。**

排查方法：眯眼看这张图，问自己「第一眼看到什么、第二眼看到什么」。如果答不上来，或答案有三个以上，就是层级失焦。

## 二、拉开层级的手段（按优先级）

1. **字号**（最有效）
2. **字重**
3. **留白**（周围的空间）
4. **颜色**（强调色）
5. **字体**（衬线 vs 无衬线）

⚠️ **不要靠装饰拉开层级**（阴影、边框、色块）。装饰是最后手段，且很容易变成噪声。

## 三、扫读动线

中文读者扫读是 **Z 字 / F 字**：

```
起点 →→→→→→→→
↓
→→→→ 终点
```

**用法**：
- 最重要的信息放**左上**（起点）
- 行动指引放**右下或底部**（终点）
- 不要把人眼需要"回跳"的信息放在左下

### 封面（第 1 页）

- 钩子放**上半 2/3**（X 会裁切预览，小红书首图也会被信息流裁）
- 作者署名放**右上角**（默认位置，没有就留空）
- 页码放**底部**

### 内页

- 标题在上，正文在下
- 一页只讲一个判断——判断句放最显眼位置

## 四、层级的视觉证据

| 元素 | 相对正文 | 手段 |
|---|---|---|
| 主标题 | 字号 × 2.5–3.5 | 字号 + 字重 |
| 次级 | 字号 × 1.3–1.5 | 字号 + 字重 |
| 正文 | 1.0 | — |
| 注脚 | 字号 × 0.7 | 字号 + 浅色 |

**差距必须"看得见"。** 48 / 40 / 34 这种差距是看不见的。

## 五、常见的层级失焦

| 症状 | 原因 | 修法 |
|---|---|---|
| 「说不上哪里不对，就是不舒服」 | 字号阶梯太密 | 拉开到 ≥ 1.35 倍 |
| 「看完不知道重点」 | 一页多个判断 | 拆页 |
| 「很乱」 | 元素不对齐任何轴 | 统一左对齐到网格 |
| 「很挤」 | 行高太小 + 间距太小 | 行高 ≥ 1.6，间距用刻度 |
| 「很空」 | 内容不足 78% | 补内容或标记留白 |
| 「廉价」 | 大字号 + 高字重 | 越大越细 |
| 「花」 | 强调色用了多处 | 收敛到一处 |
| 「吵」 | 装饰太多 | 删掉阴影/边框/色块，靠留白 |

## 六、每页的检查问题

排完一页，问四个问题：

1. **这一页的核心判断是什么？** 答不出来 → 这页不该存在
2. **一眼看到的是什么？** 如果不是核心判断 → 层级错了
3. **砍掉哪一半，信息还不丢？** 砍得掉 → 就该砍
4. **读者会在哪里停下？** 如果答案是"不会停" → 钩子不够

## 七、整套图的节奏

不要每页都一样。至少每 2–3 页换一次节奏：

```
封面（冲击） → 观点（密） → 时间线（疏） → 金句（极疏） → 数据（密） → 清单（中） → 收束（疏）
```

**密 → 疏 → 密** 的呼吸感，是整套图读得下去的关键。
