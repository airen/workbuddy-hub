# 配色与对比度

> 配色的第一原则不是"好看"，是**可读**。第二原则是**克制**。

## 一、只从主题预设里选

本专家有 10 套主题（见引擎技能的 `references/theme-presets.md`）。**不允许自定义 hex。**

理由：自由选色是这类工具最常见的翻车原因。用户选出来的颜色往往在浅底上读不了，或者整套图色调打架。

**能做的是**：
- 从 10 套里挑一套
- 在系统允许的范围内切换（Editorial ↔ Swiss 要换模板）
- 需要"更亮一点"时，换主题，不要改 hex

## 二、对比度阈值（WCAG AA）

| 内容 | 最低对比度 |
|---|---|
| 正文（< 40 px） | **4.5 : 1** |
| 大标题（≥ 40 px） | **3 : 1** |
| 次级文字、注脚 | **4.5 : 1** |
| 压在色块上的文字 | **4.5 : 1** |

### 已知的坑

| 组合 | 对比度 | 判定 |
|---|---|---|
| `lemon`（#E8C400）当**文字**压在浅底上 | 1.7 : 1 | ❌ **禁止** |
| `lime`（#A8CC1E）当**文字**压在浅底上 | 1.9 : 1 | ❌ **禁止** |
| `dune` 强调色当小字 | 3.6 : 1 | ⚠️ 仅 ≥ 40 px 可用 |

**规则**：黄色、绿色（`lemon` / `lime`）的锚点色**永远当色块**，配黑字；
永远不要用黄色或绿色的字压在浅色底上。

## 三、强调色的使用纪律

**全页只用一处，或一个区域。**

```
✅ 一个小标签用强调色
✅ 一条短线用强调色
✅ 一个色带（.band）用强调色
✅ 一个关键词用强调色
❌ 每段都加一个彩色方块
❌ 整句变色
❌ 标题 + 标签 + 短线 + 数字 全用强调色
```

**锚点色之所以有效，是因为它是唯一的。** 用两次就失效了。

## 四、色相数量

- **一套图**：1 个底色 + 1 个主文字色 + 1 个次级文字色 + 1 个强调色。**就这些。**
- 数据可视化里可以引入第二色（`--ink` 与 `--accent` 交替），但不要引入第三个色相。
- ❌ 不要彩虹色。

## 五、暗色主题（`midnight`）

- 正文与标题色**自动反转**，不要手动再改。
- 暗底上文字边缘显得更细，正文可提一档（30 → 32 px）。
- 强调色是暖金，压在暗底上可读；**不要用它做大量文字**。
- 需要图源时，选低调、低饱和、暗调的照片。

## 六、不要写死颜色

```css
/* ✅ 走变量 */
.h-display { color: var(--ink); }
.tag { background: var(--accent); color: var(--accent-ink); }

/* ❌ 写死 */
.h-display { color: #1a1a1a; }
.tag { background: #c0392b; }
.card { border: 1px solid rgba(0,0,0,.12); }
```

写死颜色的后果：换主题时露馅——底色变了，写死的文字色没变。

**唯一允许的例外**：图片上的白色文字（`#fff`），因为它的对比对象是照片而不是主题色。

## 七、图片上的文字

- 满铺图上压字，**先加局部渐变遮罩**（scrim），不要默认全图加深色遮罩。
- 遮罩方向与文字位置相反：文字在下方 → 遮罩从下往上加深。
- 遮罩最深处不透明度 **0.7 – 0.8**，再深就看不见图了。
- 白字压图时，字号建议 ≥ 52 px，字重 400–600。

## 八、快速自查

- [ ] 颜色全部走 CSS 变量，没有写死 hex
- [ ] 正文对比度 ≥ 4.5:1
- [ ] 没有黄/绿字压在浅底上
- [ ] 强调色全页只用一处或一个区域
- [ ] 一套图只用一个主题
- [ ] 暗色主题下正文字号提了一档
- [ ] 图片上的文字有 scrim，且文字避开了主体
