# 网格、留白与垂直节奏

> 「留白」不是"剩下的地方"，是**主动设计出来的空间**。

## 一、页边距

| 画板 | 边距 |
|---|---|
| 1080×1440（3:4） | **72 – 88 px** |
| 1080×1080（1:1） | **68 – 80 px** |
| 2100×900（21:9） | **72 – 96 px** |
| 1080 长图 | 水平 **84 px** / 垂直 **120 px** |

**四边相等或上下略大于左右**。不要左右 80、上下 40——那叫"贴边"。

⚠️ **长图是唯一水平/垂直不等的一档**：长图动辄 2400–8000 px 高，垂直留白按比例算几乎看不见，所以固定给足 120 px，保证上下裁切、二次排版、拼接成 PDF 时都有余量。水平仍按 84 px，与 3:4 的 76 px 同一量级。口径以 `tuwen-engine/references/platform-specs.md` 为准。

**安全区**：小红书详情页底部约 160 px 有 UI 遮挡，顶部 80 px 建议留白。关键信息不放最底部 160 px。

## 二、网格

### 3:4 画板

- 内容区宽 928 px（1080 − 76 × 2）
- **6 栏网格**，栏宽 ≈ 138 px，槽宽 28 px
- 常用切分：`1fr 1fr`（两栏）、`1fr 1fr 1fr`（三栏）、`88px 1fr`（编号 + 内容）

### 对齐纪律

- **所有元素对齐到某一条轴**。左对齐是默认；不要一段左对齐、一段居中。
- 例外：封面标题可以居中，但**整页都要居中**。
- 卡片网格里，卡片高度对齐（`align-items: stretch`）。

## 三、垂直节奏（间距）

用**一套间距刻度**，不要随手写 `margin: 23px`。

```
8 / 16 / 24 / 32 / 48 / 64 / 96 / 128
```

| 关系 | 间距 |
|---|---|
| 同级元素之间 | 24 – 34 px |
| 标题与其正文 | 20 – 32 px |
| 板块之间 | 48 – 72 px |
| 内容区与页脚 | 44 – 56 px |

**相关的东西靠近，不相关的东西拉开**——这是"分组"的本质。

## 四、留白的三种用法

1. **分组**：组内间距 < 组间间距，自然形成分组
2. **聚焦**：标题上方留大空，视线自然下压到标题
3. **呼吸**：密集内容后留一段空白，让眼睛休息

## 五、密度底线

1080×1440 画板，**内容应覆盖画布高度 ≥ 78%**。

- 低于 78%：要么补内容，要么**主动标记为有意留白**
- 高于 100%：溢出，必须砍内容

> 在模板里用 `<div class="allow-void" data-void="理由"></div>` 标记有意留白，
> 质检脚本会识别它，不会误报「底部空洞」。

## 六、垂直节奏的检查

把画板从上到下切 4 条 360 px 的横带：

- 每条带里**要么有内容，要么有明确的留白理由**
- 连续两条空带 = 页面下半部浪费了

## 七、常见错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 边距 < 64 px | 贴边，局促 | 提到 72–88 |
| 上下边距远小于左右 | 版心偏移 | 上下 ≥ 左右 |
| 间距随手写（23/37/41） | 节奏乱 | 用 8 的倍数刻度 |
| 元素不对齐任何轴 | 网格崩塌 | 统一左对齐 |
| 下半页全空 | 浪费画板 | 补内容或标记留白 |
| 卡片高度不齐 | 参差 | `align-items: stretch` |
| 内容贴到页脚 | 碰撞 | 主体区留 44–56 px 下边距 |
