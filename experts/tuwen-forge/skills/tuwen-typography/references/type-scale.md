# 字号阶梯与字重搭配

> 版式「专业」和「业余」最大的差别，往往不是配色，而是**字号阶梯是不是干净**。

## 一、字号阶梯：相邻档差 ≥ 1.35 倍

**1080×1440 画板（3:4）**

| 层级 | 字号 | 用途 |
|---|---|---|
| display | **96 – 118 px** | 封面主标题、单页大字观点 |
| xl | **72 – 88 px** | 内页主标题 |
| lg | **52 – 62 px** | 次级标题、板块标题 |
| md | **38 – 46 px** | 小标题、卡片标题、清单项 |
| body | **30 – 36 px** | 正文 |
| body-2 | **26 – 30 px** | 次级正文、说明 |
| caption | **20 – 24 px** | 来源、注脚、页码 |

**1080×1080（1:1）与 2100×900（21:9）** 按同一比例缩放，但 21:9 的竖向预算小，标题一般用 xl 而非 display。

### 阶梯必须"稀疏"

```
✅ 好：118 / 76 / 52 / 34 / 30 / 22
❌ 差：48 / 44 / 40 / 36 / 32 / 28
```

相邻档差 < 1.35 倍时，读者看不出层级，只觉得"乱"。**宁可少一档，不要挤两档。**

## 二、越大越细（Swiss 的铁律，Editorial 同向）

字号上去，字重必须下来。这是**专业排版最反直觉、也最重要**的一条。

| 字号 | 字重 | 说明 |
|---|---|---|
| 96 – 118 px | **300** | 极细，靠尺寸而不是靠重量抓眼 |
| 72 – 88 px | **300 – 400** | |
| 52 – 62 px | **500** | |
| 38 – 46 px | **600** | |
| 30 – 36 px | **400** | 正文用常规字重 |
| 26 – 30 px | 400 | |
| 20 – 24 px | 400 – 500 | |

**Editorial 例外**：衬线标题（宋/明朝体）本身笔画细，可以用 **600–700** 加粗，因为衬线的横竖对比提供了结构。但**不要用到 900**。

### 为什么

大字号 + 高字重 = 一块黑砖。视觉上笨重、拥挤，还显得廉价。
大字号 + 细字重 = 呼吸感、精致、有设计感。**这正是 Swiss 之所以看起来高级的原因。**

## 三、对比度：字号对比要"极致"

```
✅ Swiss 典型：112 / 28 / 22     （对比 4 倍）
✅ Editorial：96 / 34 / 22       （对比 2.8 倍）
❌ 温吞：48 / 40 / 34 / 30       （看不出重点）
```

**一页最多三个层级。** 主标题 + 次级 + 正文。再多就失焦。

## 四、行高与字号的搭配

| 字号 | 推荐行高 |
|---|---|
| ≥ 72 px | 1.05 – 1.2 |
| 40 – 71 px | 1.2 – 1.35 |
| 24 – 38 px | 1.6 – 1.9 |

**大标题行高收紧、正文行高放松**——这是通用规律。

## 五、一套图的阶梯必须完全一致

同一套图里，第 2 页的"内页主标题"和第 7 页的"内页主标题"**必须是同一个字号**。

- ❌ 这页 72、那页 68 —— 读者说不出哪里不对，但会觉得"不专业"
- ✅ 用 CSS 类（`.h-xl`）而不是行内 `style="font-size:68px"`

## 六、常见错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 大标题用 800/900 | 黑砖，笨重 | 降到 300–500 |
| 字号阶梯太密（48/44/40） | 看不出层级 | 拉开到 ≥ 1.35 倍 |
| 一页四个以上层级 | 失焦 | 合并到 3 个 |
| 同一角色在不同页字号不同 | 套图不统一 | 用 CSS 类统一 |
| 正文 28 px 还加 `letter-spacing` | 散架 | 去掉字距 |
| 大标题用 `font-weight:bold` | 不可控 | 显式写 300/400/500 |

## 七、快速定档流程

1. 先定**正文**字号（30–36 px，按内容量与可读性）
2. 正文 × 1.4 ≈ 次级标题 → 取整到阶梯（40–46）
3. 次级 × 1.4 ≈ 主标题 → 取整到阶梯（56–64）
4. 需要封面冲击力时再上一档（96–118）
5. 所有字号**从阶梯里取值**，不要临时拍脑袋
