# 中文排版 · CJK 硬约束

> 中文排版的坑和西文完全不同。这一份是**照着做就行**的清单。

## 一、字体栈（macOS 优先）

```css
--font-serif: "Songti SC","STSong","Noto Serif SC","Source Han Serif SC",Georgia,serif;
--font-sans:  "PingFang SC","Hiragino Sans GB","Helvetica Neue","Noto Sans SC",system-ui,sans-serif;
--font-mono:  "SF Mono","Menlo","JetBrains Mono",monospace;
```

- **不要用 `"Microsoft YaHei"` 打头**——macOS 上没有，会掉到下一个。
- **不要用网络字体**，除非已下载到本地并用 `@font-face` 引入。渲染时联网不可靠。
- **渲染前必须 `await document.fonts.ready`**，否则会截到「字体还没换过来」的图。
- **缺字必须显式失败**：出现 `□` 说明字体栈没覆盖到，不许交付。

## 二、字符宽度估算（排之前算得出来）

| 字符类型 | 宽度（相对字号） |
|---|---|
| 中文汉字、全角标点 | **1.0 ×** |
| 拉丁字母（平均） | 0.55 × |
| 阿拉伯数字 | 0.55 × |
| 半角标点、空格 | 0.3 × |

**用法**：一行能放几个中文字 ≈ `内容宽度 ÷ 字号`。

例：1080 宽画板、左右边距各 76 px → 内容宽 928 px；正文 34 px → 每行约 **27 个中文字**。
写文案前先按这个算，就不会排完才发现溢出。

## 三、标点

- **一律全角**：`，。、；：？！（）「」《》——`
- **不要用半角 `, . ? !`** 混在中文里（除非是英文句子的一部分）。
- **引号**：中文用 `「」` 或 `""`（弯引号），不要用直引号 `"`。
- **破折号**：中文用 `——`（两个全角横线），不要用 `-` 或 `--`。

### 避头尾（标点不出现在行首）

行首禁止：`，。、；：？！）』」》`
行尾禁止：`（『「《`

CSS 目前没有可靠的自动避头尾。**做法**：
1. 用 `<br>` 手动控制换行位置；
2. 或在标点前加 `\u200B`（零宽空格）诱导断行；
3. 或调整文案长度避开。

> ⚠️ `line-break: strict` / `word-break: keep-all` 在 Chrome 里对中文标点控制不完整，**不要依赖它**。

## 四、中英混排

- **中英之间留 1/4 空隙**。CSS 没有自动实现，**手动加空格**最稳：`AI 能一键出图`、`用 HTML/CSS 排版`。
- 中文与数字之间同理：`改一版要 1 秒`，不是 `改一版要1秒`。
- **不要把英文单词拆行**。给英文加 `white-space: nowrap` 或调整文案。
- 技术术语保留原文：`API`、`CSS Grid`、`Playwright` 不要翻译。

## 五、行高

| 内容 | 行高 |
|---|---|
| 大标题（≥ 72 px） | 1.05 – 1.2 |
| 中标题（40–71 px） | 1.2 – 1.35 |
| 正文（24–38 px） | **1.6 – 1.9** |
| 说明 / 注脚 | 1.5 – 1.65 |

**中文行高要比西文更大**。西文 1.4 舒服，中文 1.4 会显得挤——因为汉字是方块，没有上下伸展的字母笔画提供视觉呼吸。

## 六、字距（letter-spacing）

| 场景 | 字距 |
|---|---|
| 大标题（≥ 72 px） | `-0.02em ~ -0.005em`（收紧） |
| 正文 | `0`（不要加） |
| 小标签 / eyebrow | `0.12em ~ 0.22em`（拉开） |
| 全大写英文 | `0.08em ~ 0.14em` |

**正文绝对不要加字距**——中文加字距会变成「散架」。

## 七、孤字成行

一行末尾只剩一个字（或一个标点），叫孤字。修法：

1. 缩短或加长文案（首选）
2. 用 `<br>` 重排
3. 微调 `letter-spacing`（±0.01em，只在大标题上）

## 八、竖排

**不要做竖排。** 除非用户明确要求，且你愿意承担标点位置、英文数字方向、行序等一整串问题。本专家默认只做横排。

## 九、快速自查

- [ ] 字体栈里有 `"PingFang SC"` 与 `"Songti SC"`
- [ ] 标点全角，引号是 `「」` 或弯引号
- [ ] 没有标点出现在行首
- [ ] 中英/中数之间有空格
- [ ] 正文行高 ≥ 1.6
- [ ] 正文没有加字距
- [ ] 没有孤字成行
- [ ] 渲染前 `await document.fonts.ready`
- [ ] 图上没有 `□`
