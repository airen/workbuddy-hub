# 中文排版与版式美学

这份技能回答一个问题：**同样的内容，怎么排才读得舒服、看得专业。**

它不是审美偏好清单，而是可执行的硬规则——每条都能落到一个具体数值或一个具体做法上。

## 什么时候加载

- 用户问「字号多大合适」「留白多少」「配色怎么定」「层级不清楚」
- 你已经选好版式骨架，要填具体数值
- 渲染出来的图「说不上哪里不对，但就是不舒服」
- 交付前做视觉自检

## 五条最高频的硬约束

先记住这五条，能挡掉 80% 的「不舒服」：

1. **正文不小于 24 px**（1080 宽画板）。低于此值手机上读不了。
2. **越大越细**。字号上去，字重必须下来。大标题用 300–400，不要用 700–900。
3. **一页最多三个层级**。主标题 / 次级 / 正文。超过三个，读者会失焦。
4. **中英之间留 1/4 空隙**。`AI能` → `AI 能`。
5. **中文标点用全角，且不出现在行首**。句号、逗号、顿号、问号都算。

## 两套系统的排版差异

| | Editorial | Swiss |
|---|---|---|
| 字族 | 衬线标题 + 无衬线正文 | 无衬线全家桶 |
| 层级手段 | 字号 + **字体对比** + 留白 | 字号 + **字重对比** + 网格 |
| 行高 | 标题 1.15–1.3，正文 1.7–1.9 | 标题 1.05–1.25，正文 1.6–1.8 |
| 边距 | ≥ 72 px，慷慨 | ≥ 64 px，精确对齐网格 |
| 装饰 | 短线、色块 | 发丝线、直角、色带 |
| 禁忌 | 阴影、圆角卡片 | 圆角、阴影、第二个强调色 |

选错系统时，先换系统再调数值。**在错误的系统里微调参数，是浪费。**

## 排完自检

- [ ] 字号阶梯只有 3–4 档，且相邻档差 ≥ 1.35 倍（48/40 这种太密）
- [ ] 大标题字重 ≤ 500（Editorial 可到 700，但需衬线支撑）
- [ ] 正文行高 ≥ 1.6
- [ ] 边距 ≥ 64 px
- [ ] 中英之间有 1/4 空隙
- [ ] 标点全角、不在行首
- [ ] 正文与底色对比度 ≥ 4.5:1
- [ ] 强调色全页只用一处或一个区域
- [ ] 没有孤字成行
