# 事实核验与原创性

> 排版可以让内容更好看，也可能让错误更可信。**这是这份工作最大的伦理风险。**

## 一、绝对不能做的事

| 禁止 | 说明 |
|---|---|
| **编造数字** | 素材里没有的数据，不许"估算一个合理的" |
| **编造结论** | 不许把「可能」写成「就是」 |
| **编造人名/机构/时间** | 不许为了"具体"而虚构出处 |
| **编造引语** | 不许把观点包装成某人的原话 |
| **篡改原意** | 压缩不等于改意思 |
| **伪造署名** | 用户没给署名就留空，不许编一个 |

## 二、可以做的事

| 可以做 | 说明 |
|---|---|
| 重组结构 | 按认知顺序重排，是策划的核心工作 |
| 提炼判断 | 从素材里抽出可争辩的句子 |
| 压缩措辞 | 删冗余，不改语义 |
| 补过渡句 | 页与页之间的衔接词 |
| 补通用常识 | 如「中文标点用全角」——但不要伪装成素材里的内容 |
| 提出结构建议 | 「建议补一节数据」而不是自己编数据 |

## 三、核验流程

交付前，把图里的每一个**可验证事实**过一遍：

- [ ] **数字**：每一个数字都能在素材里找到出处
- [ ] **结论**：强度与素材一致（素材说「可能」，图里不能写「一定」）
- [ ] **人名 / 机构 / 时间**：都有出处
- [ ] **引语**：是原话，不是转述后加引号
- [ ] **因果**：没有把相关写成因果

## 四、发现素材不足时怎么办

**如实报告，不要补空。**

```
✅ 「第 4 页原计划做「竞品价格对比」，但素材里只有两家的数据，
    且口径不一致。我暂时没有做这页，建议补充数据后再加上。」

❌ 自己编三个价格填上去。
```

**宁可少一页，不要编一个数。**

## 五、原创性与第三方内容

- **引用他人观点**：标注出处（作者 / 来源 / 年份）。
- **引用他人版式**：版式**思想**可以学，**代码一律自己写**。
  - MIT / Apache 等宽松许可的项目，可借鉴并保留许可声明
  - **AGPL 项目的代码一行都不能搬**（传染性强，见包内 `LICENSE` 的边界说明）
- **引用他人图片**：必须确认授权，并写进 `SOURCES.md`。
  - 可用：Unsplash / Pexels 等明确可商用的图源（仍需按各自协议署名）
  - 不可用：来源不明的网图、带水印的图、他人作品截图

## 六、AI 生成内容的标注

如果内容里包含 AI 辅助生成的文案（例如用户只给了一个主题，你补写了结构），
**交付说明里要如实说明**：

```
本套图文的结构与过渡文案由我补充；核心观点来自用户提供的素材。
```

不要假装全部来自用户素材。

## 七、敏感内容

遇到以下内容，**先提示用户，不要直接做**：

- 医疗、用药、诊断相关
- 法律、税务、投资建议
- 涉及具体个人的负面评价
- 未公开的公司内部数据

提示话术：

```
这套内容涉及【医疗建议】。我可以帮你排版，但内容准确性需要专业审核。
建议在图上或说明里加上「非专业建议，仅供参考」。
```

## 八、核验自检

- [ ] 每个数字都有出处
- [ ] 结论强度与素材一致
- [ ] 没有编造的人名 / 机构 / 时间
- [ ] 引语是原话
- [ ] 图片授权已确认，`SOURCES.md` 已写
- [ ] 补写的结构已在交付说明里声明
- [ ] 敏感内容已提示用户
