# 拆页：从内容到一套图

> 拆页的目标不是「把内容平均分」，而是**让每一页都有一个能被单独记住的判断**。

## 一、核心判据：一页一个核心判断

一页合格的标志是：**你能用一句话说出这页在讲什么，且这句话是一个判断，不是一个话题。**

| 页 | 是判断吗 | 判定 |
|---|---|---|
| 「确定性渲染」 | ❌ 是话题 | 不合格 |
| 「确定性，是唯一能被质检的东西」 | ✅ 是判断 | 合格 |
| 「排版工具对比」 | ❌ 是话题 | 不合格 |
| 「要一次性的成品，生图更快」 | ✅ 是判断 | 合格 |

## 二、拆页流程（四步）

### 第 1 步：抽判断

把素材读一遍，划出所有**可争辩的句子**。可争辩 = 有人可能不同意。

- 「AI 出图很快」→ 不可争辩（是事实描述）
- 「AI 出图的字不能用」→ 可争辩（有人会不同意）

### 第 2 步：合并同类

把讲同一件事的判断合并成一个。合并后如果一句话说不清，说明该拆。

### 第 3 步：排序

按**认知顺序**排，不是按素材顺序：

```
先给结论？ → 适合观点型（钩子先行）
先给现象？ → 适合分析型（层层推进）
先给故事？ → 适合叙事型（代入感）
```

### 第 4 步：配支撑

每个判断配一种支撑形式：

| 判断类型 | 最好的支撑形式 | 对应版式 |
|---|---|---|
| 有数据 | 数据卡 / 柱图 / 横条 | M07 / M12 / S09 / S10 |
| 有时间 | 时间线 | M09 / S07 |
| 有对比 | 对比页 / 矩阵 | M08 / S05 |
| 有步骤 | 流程 / 清单 | M10 / M06 / S06 |
| 有引用 | 引言页 | M05 / M11 |
| 只有论述 | 单栏 / 分栏正文 | M02 / M03 |

**判断和支撑形式必须匹配。** 用清单去讲一个需要对比的判断，就会别扭。

## 三、页数预算

| 内容量 | 页数 |
|---|---|
| 1 个判断，无支撑 | **1 页**（单图，不做整套） |
| 3 个判断 + 支撑 | 5 页（封面 + 3 + 收束） |
| 5 个判断 + 支撑 | 7–8 页 |
| 8 个以上判断 | **拆上下篇**，或改做长图 |
| 内容超过 12 页 | 长图 / 上下篇 / 砍 |

**硬上限 12 页。** 小红书一次最多 18 张，但超过 9 张完读率明显下滑。

## 四、拆 / 并的判据

### 该拆的信号

- 一页里有两个「最」字
- 一句话说不清这页在讲什么
- 需要缩字号才能塞下
- 正文超过 5 段

### 该并的信号

- 某页只有 1–2 行字（内容覆盖 < 78%）
- 两页讲的是同一件事的两个侧面
- 连续三页都是清单，读者会疲劳

## 五、默认的整套结构

### 干货型（Swiss）

```
01 封面（钩子）
02 章节页（编号 + 大标题）
03–06 判断页（一页一判断）
07 清单页（划重点）
08 收束页（行动）
```

### 叙事型（Editorial）

```
01 封面（钩子）
02 观点（定调）
03 时间线 / 过程
04 金句（情绪高点）
05 数据（证据）
06 观点（反转）
07 网格（并列要点）
08 收束（划重点）
```

## 六、节奏：不要每页都一样

| 页 | 密度 | 目的 |
|---|---|---|
| 封面 | 疏 | 冲击 |
| 判断页 | 密 | 信息 |
| 金句页 | **极疏** | 呼吸、情绪 |
| 数据页 | 密 | 证据 |
| 清单页 | 中 | 收拢 |
| 收束 | 疏 | 行动 |

**密 → 疏 → 密** 的呼吸感，是整套图读得下去的关键。

## 七、拆页自检

- [ ] 每页能用一句话说出核心判断
- [ ] 每句话都是**可争辩**的，不是话题
- [ ] 判断与支撑形式匹配
- [ ] 页数在 5–9 之间
- [ ] 没有哪页内容覆盖 < 78%
- [ ] 没有连续三页同一种版式
- [ ] 封面与收束各一页
