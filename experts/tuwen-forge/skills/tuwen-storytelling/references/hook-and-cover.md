# 封面钩子与标题

> 封面的唯一任务：**让人点进来。** 它不是内容摘要，是钩子。

## 一、封面必须独立成立

检验方法：**只看封面，不看正文，你能说出这套图在讲什么吗？**

- ❌ 「第一部分」「导读」——没有信息量
- ❌ 「关于 AI 出图的一些思考」——太泛，没有立场
- ✅ 「AI 能一键出图，为什么图文还没死？」——有冲突、有悬念、有立场

## 二、四种可用的钩子类型

| 类型 | 结构 | 例子 |
|---|---|---|
| **反差** | A 很强大，但 B 仍然成立 | AI 能一键出图，为什么图文还没死？ |
| **数字** | 具体数量 + 结果 | 5 个让写作效率翻倍的 AI 习惯 |
| **否定常识** | 你以为 X，其实是 Y | 别再追求「高级感」了，那是廉价感的来源 |
| **身份认同** | 给某类人贴标签 | 做内容的，都该会一点排版 |

**反差**与**否定常识**的点击率通常最高，但也最需要内容撑得住。

## 三、标题写法

- **长度**：12–20 个中文字（两行以内，每行 ≤ 9 字）
- **断行**：用 `<br>` 手动断，不要让它自己折
- **标点**：可以用一个问号或冒号制造停顿；不要用感叹号（廉价）
- **不要**用「浅谈」「略论」「关于…的思考」这类学术套话

### 断行示范

```
AI 能一键出图，
为什么图文还没死？          ← 两行，节奏对

AI 能一键出图，为什么
图文还没死？                ← 断在错的地方
```

## 四、封面上的其他元素

| 元素 | 位置 | 说明 |
|---|---|---|
| 小标签（eyebrow / tag） | 左上 | 栏目名、系列名，2–6 字 |
| 主标题 | 上半 2/3 | 钩子 |
| 副标题 | 主标题下 | 补充或设悬念，≤ 16 字 |
| 作者署名 | 右上或页脚 | 没有就留空，**不要编** |
| 页码 | 页脚 | `01 / 08` |

## 五、安全区（重要）

- **小红书**：底部 160 px 有 UI 遮挡，钩子不要放最底部
- **X**：时间线预览会裁切，关键信息放**上半 2/3**
- **公众号 21:9**：会被按**中心 1:1** 裁切，标题必须在中间

## 六、给 3 个备选标题

交付时给主标题 + 2 个备选，并说明各自赌的是什么：

```
主选：AI 能一键出图，为什么图文还没死？   （赌反差，最稳）
备选 A：我为什么放弃了 AI 生图              （赌身份认同，第一人称更亲切）
备选 B：图文的底线不是好看，是可控          （赌否定常识，更尖锐但受众窄）
```

## 七、封面自检

- [ ] 只看封面能说出在讲什么
- [ ] 有立场，不是中性摘要
- [ ] 标题 ≤ 20 字，断行正确
- [ ] 钩子在上半 2/3
- [ ] 没有感叹号、没有学术套话
- [ ] 有 2 个备选标题

## 八、收束页（最后一页）

收束页的任务是**把动作交出去**。三种收法：

| 收法 | 适合 | 结构 |
|---|---|---|
| **划重点** | 干货型内容 | 编号清单复述 3–5 条 |
| **收藏引导** | 工具/方法型 | 「收藏这套方法，下次直接用」 |
| **互动提问** | 观点型内容 | 「你最常用哪一个？评论区聊聊」 |

**收束页不要引入新信息。** 它的作用是让读者记住并行动。
