# 叙事节奏（导演视角）

> 排版是"怎么放"，叙事是"什么顺序放"。**顺序错了，每一页都对，整套还是难看下去。**

## 一、四种叙事骨架

### 1. 起承转合（通用）

```
起：一个大家都认同的现象
承：这个现象背后有什么
转：但是——反直觉的一点（**信息密度最高的一页**）
合：所以该怎么做
```

「转」是整套图的灵魂。**没有「转」，就是平铺直叙的说明书。**

### 2. 层层递进（分析型）

```
现象 → 原因 → 更深层的原因 → 结论
```

适合：工具测评、方法论、数据解读。

### 3. 时间线（叙事型）

```
起因 → 过程（2–3 个节点）→ 转折 → 现在
```

适合：经历、复盘、案例。

### 4. 反差结构（观点型）

```
大家以为 A → 其实不是 → 真相是 B → B 为什么成立 → 怎么做
```

适合：否定常识类内容。**点击率高，但要求论据硬。**

## 二、情绪曲线

一套好图有情绪起伏，不是平的：

```
情绪
 ↑
 │        ╭─╮            ╭─╮
 │   ╭───╯   ╰──╮    ╭──╯   ╰─╮
 │ ╭─╯           ╰──╯         ╰─╮
 └────────────────────────────────→ 页
   1   2   3   4   5   6   7   8
  封  现象 冲突 证据 反转 方法 清单 收束
```

**每 2–3 页要有一次起伏。** 平的情绪曲线 = 读者中途划走。

### 制造起伏的手法

| 手法 | 效果 |
|---|---|
| 从密突然变疏（留白） | 制造停顿 |
| 从陈述变成问句 | 制造悬念 |
| 从客观变成第一人称 | 拉近距离 |
| 数字突然出现 | 制造确定感 |
| 一句话单独成页 | 制造重量 |

## 三、页与页的衔接

每页的结尾要为下一页**留一个口子**：

- ❌ 「第一点是…」（然后第二页又说「第二点是…」）——机械
- ✅ 第 3 页末：「但这里有个问题」→ 第 4 页：「这个问题就是…」

**衔接词库**：但 / 然而 / 所以 / 于是 / 直到 / 结果 / 真正的问题是

## 四、单页内部的节奏

一页内部也有节奏，通常是：

```
标题（重） → 留白 → 正文（轻） → 强调块（重）
```

不要把一页排成"一块铁板"——从头到尾一样的密度。

## 五、导演思维：谁是主角

把整套图当一部短片：

| 角色 | 对应 |
|---|---|
| 主角 | 用户/读者的痛点 |
| 反派 | 那个让读者难受的现状 |
| 转折 | 你的方法 / 洞察 |
| 结局 | 读者能得到什么 |

**如果整套图里没有"反派"，就没有张力。** 反派可以是：低效的工作流、被忽视的常识、一个流行的错误做法。

## 六、节奏自检

- [ ] 有「转」——一个反直觉的点
- [ ] 每 2–3 页有一次情绪起伏
- [ ] 页与页之间有衔接，不是并列罗列
- [ ] 有一套图内部的"反派"
- [ ] 至少有一页是"极疏"的（金句 / 大字）
- [ ] 收束页不引入新信息
