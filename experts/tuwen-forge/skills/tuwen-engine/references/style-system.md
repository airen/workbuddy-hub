# 风格系统 · 两套视觉系统与反模式

> 这是**硬规则**，不是建议。两套系统**不允许混搭**。选错系统的代价，比排版粗糙更大。

## 一、两套系统，一句话区分

| 系统 | 一句话 | 情绪目标 |
|---|---|---|
| **Editorial 编辑杂志风** | 内容在**讲故事** | 沉静、可信、有呼吸 |
| **Swiss 瑞士国际主义** | 内容在**讲道理 / 摆事实** | 理性、锐利、可扫读 |

判定顺序：先看内容**有没有时间线 / 人物 / 场景 / 情绪**——有 → Editorial；只看**数据 / 参数 / 步骤 / 对比**——Swiss。两者都有时，看**用户最想让人记住什么**。

## 二、Editorial 编辑杂志风

**血统**：Monocle / Kinfolk / Cereal 一类独立杂志的版面。

### 硬规则

1. **衬线标题 + 无衬线正文**（或全衬线）。标题用系统可用的宋/明朝体栈。
2. **纸感底色**，不是纯白。底色永远带一点暖或冷，纯白 `#fff` 不用。
3. **留白是主角**。页边距 ≥ 72 px，段落间距 ≥ 字号 × 1.2。
4. **克制的强调**：强调色只用于**一处**——一个小标签、一条短线、一个关键词。不要整句变色。
5. **行高宽松**：标题 1.15–1.3，正文 1.7–1.9。
6. **不用阴影、不用圆角卡片**。层级靠字号、字体、留白撑起。

### 反模式

- ❌ 标题加粗到 900 还加描边 → 失去克制
- ❌ 每段都加一个彩色小方块 → 装饰堆砌
- ❌ 正文用 1.3 行高 → 挤，读不下去
- ❌ 底色用纯白 + 高饱和强调色 → 变成促销海报，不是杂志
- ❌ 一页塞三种以上字号层级 → 层级失焦

## 三、Swiss 瑞士国际主义

**血统**：Massimo Vignelli、Helvetica、瑞士网格系统。

### 硬规则

1. **无衬线全家桶**。标题与正文同一字族，靠**字重与字号**拉开层级。
2. **严格网格**。内容对齐到 12 栏或 6 栏网格，元素之间有明确的对齐轴。
3. **单一锚点色**。整页只有一个强调色（`--accent`），其余是黑、白、灰。
4. **直角、发丝线**。分隔线 1–2 px，不用圆角、不用阴影。
5. **越大越细**（核心规则）：字号上去，字重必须下来。
   - 大标题 96–120 px → `font-weight: 300–400`
   - 中标题 48–64 px → `font-weight: 500`
   - 小标题 28–36 px → `font-weight: 600`
   - 正文 24–30 px → `font-weight: 400`
   **违反这条是 Swiss 最典型的翻车。**
6. **字号对比极致**。不要 48 / 40 / 32 这种"温吞"的阶梯；要 112 / 28 / 22。

### 反模式

- ❌ 大标题用 800 字重 → 违反「越大越细」，页面变笨重
- ❌ 一页用两个强调色 → 锚点失效
- ❌ 元素不对齐到任何轴 → 网格崩塌
- ❌ 加圆角卡片和投影 → 变成通用 UI，不是 Swiss
- ❌ 字号阶梯太密（48/44/40）→ 看不出层级

## 四、共同的硬规则（两套都要守）

1. **一页一个核心判断。** 一页想讲两件事，就拆两页。
2. **正文最小 24 px**。低于此值手机上读不了。
3. **对比度**：正文与底色的对比度 ≥ 4.5:1（WCAG AA）。大标题可放宽到 3:1。
4. **一页最多 3 个层级**：主标题 / 次级 / 正文。超过 3 个，读者会失焦。
5. **不用纯黑 `#000` 与纯白 `#fff` 对撞**。用带一点色相的近黑与近白，眼睛更舒服。
6. **中文标点用全角**，中英之间留 1/4 空隙（用 CSS `letter-spacing` 或手动加空格）。
7. **页码与署名放页脚**，字号 18–22 px，颜色比正文浅一档。

## 六、切换风格的成本

- 从 Editorial 换到 Swiss，**不是换 CSS 变量**，是**换种子模板**（`template-editorial.html` ↔ `template-swiss.html`）。版式骨架也要重选。
- 同系统内换主题，**只改 `data-theme`**，零成本。
- 交付说明里要写清：是换了系统，还是只换了主题。
