# 版式骨架 · 28 个

> **先选后改，不要发明不存在的页面。** 选版式时必须能回答：为什么是它、为什么不是相邻那两个。
>
> 「文案上限」是硬预算——超了必须砍文案或换版式，**不许缩字号**。

## 通用规则

1. **一页一个核心判断。**
2. **最小密度**：1080×1440 画板，内容应覆盖画布高度的 **≥ 70%**。低于此值要么补内容，要么主动留白并在 `data-void="reason"` 里写明理由。
3. **页脚固定**：页码 `NN / MM` 与署名放底部同一行，字号 18–22 px。
4. **封面与收束页**是固定角色，每套图各一张。

## 成套的默认骨架序列

**叙事型（Editorial）**
```
M01 封面 → M02 观点 → M09 时间线 → M05 金句 → M07 数据 → M15 观点 → M14 网格 → M06 清单（划重点）
```

**说理型（Swiss）**
```
S01 封面 → S02 章节 → S08 定义 → S10 对比 → S09 数据 → S11 清单 → S12 收束
```

**公众号封面对**
```
.poster.wide（S01 或 M01 的宽版）+ .poster.square（同版式的方形版）
```

**中文长图**
```
封面板块 → 3–8 个 .block 板块 → 收束板块
```

## 长图的板块骨架（`.block`）

长图不用上面 28 个，用**板块**组合：

| 板块 | 用途 |
|---|---|
| `.block-cover` | 顶部标题区（标题 + 副题 + 元信息） |
| `.block-stats` | 数据行（3–5 个指标并排） |
| `.block-section` | 正文板块（小节标题 + 内容） |
| `.block-table` | 表格板块 |
| `.block-timeline` | 纵向时间线 |
| `.block-list` | 清单板块 |
| `.block-cta` | 底部收束 |

板块之间用 1 px 分隔线或 48–72 px 留白呼吸。每个板块高度 400–900 px。

## 反模式

- ❌ 一页塞两个核心判断 → 拆页
- ❌ 用了不存在的版式 → 从 28 个里挑最近的再改
- ❌ 缩字号硬塞 → 砍文案或换版式
- ❌ 整套图版式全一样 → 读者疲劳；至少每 2–3 页换一次节奏
- ❌ 封面不独立成立 → 封面必须自带钩子
- ❌ 长图切页 → 长图是一张
