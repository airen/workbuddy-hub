# 平台规范 · 尺寸 · 安全区 · 命名

> 画板尺寸以 **CSS px = 输出 px** 计（默认 `--scale 1`）。想更高分辨率再加 `--scale 2`。
> 所有尺寸都是**像素**，不是毫米、不是比例。

## 一、画板尺寸

| class | 尺寸 | 出口 | 说明 |
|---|---|---|---|
| `.poster` | **1080 × 1440** | 小红书 / X 单图与整套 | 3:4 竖版，主战场 |
| `.poster.square` | **1080 × 1080** | 公众号 1:1 分享卡 / 朋友圈封面 | 方形 |
| `.poster.wide` | **2100 × 900** | 公众号 21:9 头图 | 超宽，注意中心裁切 |
| `.poster.long` | **1080 × auto** | 中文高密度长图 | 高度自适应，建议 2400–8000 |

> 三套种子模板（Editorial / Swiss / 长图）已逐项实现这四个尺寸，`render.cjs` 实测输出与上表一致。
> `.poster.long` 高度自适应，**不受渲染视口（2200×1600）限制**——实测 6412 px @1x、12824 px @2x 完整出图，不会被裁掉。

## 二、平台细节

### 小红书 / RedNote

- **比例 3:4**，1080 × 1440。这是信息流里展示面积最大的比例。
- **一次 1–18 张**；超过 9 张完读率明显下滑。
- **第 1 张是封面**，决定点击率。封面必须能独立成立（脱离正文也看得懂）。
- **安全区**：详情页底部有文案与操作栏，**最底部 160 px 不放关键信息**；顶部 80 px 建议留白。
- **正文最小字号 24 px**（手机上约等于 12 pt，是能舒服读的下限）。

### X（原 Twitter）

- 同样吃 **3:4**。X 在时间线里按原比例展示，但**超过一定高度会被裁切预览**——所以关键信息放**上半 2/3**。
- X 对中文长文的阅读习惯更偏「一张图一个点」，页数可比小红书更少。

### 微信公众号

- **封面对**：`21:9` 头图（2100 × 900）+ `1:1` 分享卡（1080 × 1080），**两张必须同主题、同字体、同强调色**。
- ⚠️ **21:9 头图会被朋友圈/会话列表按中心 1:1 裁切**。所以 21:9 的**中心 1080×900 区域必须能独立成立**——标题主体放中间，不要把关键信息放到左右两端。
- 1:1 分享卡同样有**中心圆形头像遮挡**风险，关键元素避开正中偏下。
- 正文配图宽度 1080 即可，高度自由。

### 朋友圈 / 视频号封面

- 用 `.poster.square`（1:1）。视频号封面偏 16:9 或 3:4，按需加 `.poster.wide`。

### 中文长图（信息图）

- 宽固定 **1080**，高度自适应。**不切页**，靠 `.block` 板块分层。
- 建议高度 2400–8000。超过 8000 考虑拆成 2–3 张。
- 阅读动线是**纵向扫读**：每 600–900 px 一个板块，板块间用分隔线或留白呼吸。
- 长图**不受 3:4 安全区约束**，但顶部 120 px 与底部 120 px 仍建议留白（便于裁切与二次使用）。本包三套模板的 `.poster.long` 已按此设置：**垂直 120 px / 水平 84 px**（见 `tuwen-typography/references/grid-and-spacing.md`）。

## 三、导出倍率

| 场景 | `--scale` | 输出尺寸 |
|---|---|---|
| 默认交付 | `1` | 与画板一致（1080×1440） |
| 需要印刷 / 大屏 | `2` | 双倍（2160×2880） |

**默认用 1。** 平台最终都会压缩，2x 只增加体积。只有印刷、投屏、或要二次裁切时才用 2。

## 四、目录与命名

```
tuwen/<主题-slug>/
├── index.html          ← 单文件，含全部画板
├── SOURCES.md          ← 用了网络图源时必写
└── output/
    ├── 01-cover.png
    ├── 02-….png
    └── 08-cta.png
```

- `<主题-slug>`：内容主题的英文/拼音短横线形式，如 `ai-typography`、`weekly-review`。
- PNG 文件名由画板的 `data-name` 属性决定：`<section class="poster" data-name="01-cover">` → `01-cover.png`。
- **`data-name` 用 `NN-slug` 格式**，两位数字保证排序正确。
- 没有 `data-name` 时按出现顺序编号 `01.png`、`02.png`。
- 公众号封面对建议命名 `01-wechat-wide` 与 `02-wechat-square`。

## 五、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用 1080×1350（4:5）当小红书尺寸 | 比例不对，被平台裁切 | 用 3:4 = 1080×1440 |
| 21:9 头图把标题放左端 | 被中心裁切后标题消失 | 标题居中，左右各留 400 px |
| 长图切成一页页 | 阅读动线断裂 | 长图是一张，靠板块分层 |
| 封面依赖正文才看得懂 | 点击率低 | 封面自带钩子，独立成立 |
| 用 `--scale 2` 交付小红书 | 文件大 4 倍，平台照样压 | 默认 `--scale 1` |
