# 主题预设 · 10 套色票

> **不允许自定义 hex。** 只能从下面 10 套里挑。保护美学稳定性比给用户自由更重要——
> 自由选色是这类工具最常见的翻车原因。

## 变量契约

每个主题只改这几个 CSS 变量，模板里全部走 `var(...)`：

| 变量 | 含义 |
|---|---|
| `--paper` | 底色（画板背景） |
| `--ink` | 主文字色 |
| `--ink-2` | 次级文字色（页脚、说明、署名） |
| `--accent` | 强调色（全页**只用一处**或一个区域） |
| `--accent-ink` | 压在 `--accent` 色块上的文字色 |
| `--rule` | 分隔线 / 发丝线颜色 |
| `--tint` | **仅长图模板需要**：`.callout` 强调块的底色。取「纸色降约 10 级」（`midnight` 是深色主题，方向相反，比纸色提亮）。**缺这个变量会让 `.callout` 背景透明**——所以 10 套主题在 `template-longform.html` 里都定义了它 |

切换方式：`<section class="poster" data-theme="kraft">`。

**三套种子模板都已内置全部 10 套主题**，可以直接换 `data-theme` 试色。改主题后必须跑
`verify.cjs`，并在交付说明里核对对比度（见下节自查表）。

## 对比度自查（交付前必看）

下表为**实测值**（WCAG 相对亮度公式，2026-10-12 用脚本对 10 套色票逐一算过）。
判定口径：**正常字号（< 24px）需 ≥ 4.5:1；大字号（≥ 24px，或 ≥ 18.66px 粗体）需 ≥ 3:1**。
本项目正文为 30–34px，因此绝大多数场景按「大字号」判；但 `.caption`（22–24px）
与任何小于 24px 的文字必须按 4.5:1 判。

| 组合 | 实测对比度 | 判定 |
|---|---|---|
| `--ink` on `--paper`（10 套全部） | 11.98:1（kraft）– 17.52:1（lime） | ✅ 远超 AA |
| `--ink-2` on `--paper`（10 套全部） | 4.73:1（kraft）– 6.14:1（midnight） | ✅ 过 AA |
| `--accent-ink` on `--accent`（8 套） | 5.13:1（kraft）– 11.08:1（lemon） | ✅ 过 AA |
| `--accent-ink` on `--accent`：**`dune` 3.52 / `amber` 3.68** | 3.5:1 – 3.7:1 | ⚠️ **仅大字号**（≥ 24px）；小于 24px 禁用 |
| **`--accent` 作为文字压在 `--paper` 上** | | |
| **`lemon` 1.57 / `lime` 1.72** | < 1.8:1 | ❌ **禁止** |
| **`dune` 2.95 / `amber` 3.35 / `kraft` 4.05** | 2.9:1 – 4.1:1 | ⚠️ 仅大字号，且建议只用在 ≥ 40px |
| `ink` 5.77 / `pine` 5.37 / `porcelain` 6.55 / `midnight` 7.91 / `klein` 9.69 | 5.4:1 – 9.7:1 | ✅ 可以 |

⚠️ **容易踩的坑**：`kraft` / `amber` / `dune` 这三套的锚点色**当文字用是偏弱的**
（4.05 / 3.35 / 2.95），只有放大到 40px 以上才稳。它们更适合当**色块**用
（色块内文字用 `--accent-ink`，`kraft` 5.13、`dune` 3.52、`amber` 3.68 —— 后者两套
同样只在大字号下成立）。**要稳妥就把 `klein` / `midnight` / `porcelain` 留给正文强调。**

**结论**：
- `lemon` 与 `lime` 的锚点色**永远当色块用**（黄底黑字 / 绿底黑字），
  永远不要用黄色或绿色的字压在浅色底上。
- `dune` / `amber` 的锚点色**不要用来承载小于 24px 的文字**（色块内也一样）。
- 任何小于 24px 的文字，只放在 `--paper` 上、用 `--ink` 或 `--ink-2`。

## 换主题的正确姿势

```html
<!-- ✅ 只改这一个属性 -->
<section class="poster" data-theme="klein" data-name="01-cover">…</section>
<section class="poster" data-theme="klein" data-name="02-…">…</section>
```

```css
/* ✅ 模板里所有颜色都走变量 */
.h-display { color: var(--ink); }
.tag { background: var(--accent); color: var(--accent-ink); }
```

- ❌ 不要写死 `#333`、`#eee`、`rgba(0,0,0,.5)` 这类硬编码颜色——换主题时会露馅。
- ❌ 不要在同一套图里用两个主题。
- ✅ 整套图**必须同主题**；封面对的两张也必须同主题。

## 暗色主题的特殊处理

`midnight` 是唯一的暗色主题。使用时注意：

- 正文与标题色**自动反转**（`--ink` 是浅色），不要手动再改。
- 强调色 `#C9A24A` 是暖金，压在暗底上可读；但**不要用它做大量文字**。
- 暗色底的**文字边缘会显得更细**，正文可考虑把字号提一档（30 → 32）。
- 需要图源时，暗色主题更适合**低调、低饱和、暗调**的照片。
