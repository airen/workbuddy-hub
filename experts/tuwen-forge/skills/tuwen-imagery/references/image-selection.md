# 选图与图源

> 一张对的图，胜过三张"还行"的图。**宁可留白，不要凑图。**

## 一、取图优先级（不可跳级）

```
1. 用户提供的图            ← 永远优先
2. 网络可商用图源          ← 需署名、需落本地
3. 纯排版图形              ← SVG / 色块 / 网格 / 线条
4. ❌ 生图模型             ← 本专家禁止
```

## 二、什么时候真的需要图

| 内容类型 | 需要图吗 | 说明 |
|---|---|---|
| 数据、指标、对比 | ❌ 不需要 | 用图表，图会干扰 |
| 方法论、步骤、清单 | ❌ 不需要 | 用排版撑起 |
| 观点、评论、判断 | ⚠️ 通常不需要 | 纯排版更有力量 |
| 旅行、生活、美食 | ✅ 需要 | 氛围是内容的一部分 |
| 产品测评、工具介绍 | ⚠️ 截图优于照片 | 见 `screenshot-treatment.md` |
| 人物故事、访谈 | ✅ 需要 | 但肖像权需确认 |

**判据**：这张图**承载信息**吗？还是只是"看起来不空"？
只为了不空 → **不加图，改做纯排版**。

## 三、网络图源协议

### 可用图源（按推荐顺序）

| 图源 | 授权 | 备注 |
|---|---|---|
| Unsplash | 免费商用，无需署名（建议署名） | 质量高，适合 Editorial |
| Pexels | 免费商用，无需署名（建议署名） | 覆盖广 |
| Flickr CC | 按具体 CC 协议 | **必须逐张确认**协议类型 |
| Wallhaven | 按具体协议 | 游戏原画、壁纸类 |

### 不可用

- 来源不明的网图
- 带水印的图
- 他人作品截图（除非是测评对象且属于合理使用）
- 搜索引擎图片结果里的图（除非能追到原始授权）

### 取图后的必做动作

1. **下载到本地**：`<任务目录>/assets/img/01-xxx.jpg`
   - 渲染时联网不可靠，**必须落本地**
2. **压缩到合适尺寸**：宽度 1600–2200 px，JPEG q85 左右
   - 1080 宽画板用不到 4000 px 的原图
3. **写 `SOURCES.md`**：

```markdown
# 图片来源

| 文件 | 来源 | 作者 | 授权 | 链接 |
|---|---|---|---|---|
| img/01-coffee.jpg | Unsplash | Jane Doe | Unsplash License | https://unsplash.com/photos/xxx |
| img/02-desk.jpg | Pexels | John Roe | Pexels License | https://www.pexels.com/photo/xxx |
```

4. **问用户要不要在图上标来源**（默认不标，但 `SOURCES.md` 必须有）

## 四、离线环境怎么办

如果渲染环境不能联网：

- **不要让 HTML 引用远程 URL**（渲染时会白块）
- 用本机已有的图，或**改做纯排版路线**
- 如实告诉用户：「当前环境不能取网图，我改用了纯排版方案」

## 五、选图标准

一张合格的配图要满足：

- [ ] **分辨率够**：宽度 ≥ 1600 px，不模糊
- [ ] **有明确的安静区**（quiet zone）：能放字的地方
- [ ] **主体不在正中央**：中央压字会盖住主体
- [ ] **色调与主题一致**：`midnight` 主题配暗调图，`kraft` 配暖调图
- [ ] **没有文字**：图里已有文字会和你的排版打架
- [ ] **授权明确**

## 六、图片处理（PIL / ImageMagick 都可）

```bash
# 缩放 + 压缩（示例：PIL）
python3 -c "
from PIL import Image
im = Image.open('raw.jpg'); im.thumbnail((1800, 1800))
im.convert('RGB').save('assets/img/01.jpg', quality=85, optimize=True)
"
```

**不要用 4000×3000 的原图**——包体积会爆炸，渲染也慢。

## 七、自检

- [ ] 用户图优先，没有被网图替换
- [ ] 网图已落本地，HTML 不引用远程 URL
- [ ] `SOURCES.md` 已写，授权已确认
- [ ] 图片已压缩到 1600–2200 px
- [ ] 每张图都有可用的 quiet zone
- [ ] 没有为了"不空"而加无关图
