# 摄影构图与主体判断

> 你不需要会拍照，但需要**看得出一张照片能不能用**。

## 一、三分法（最实用的一条）

把画面横竖各切三等分，四条线的四个交点是"视觉重点"。

```
┌─────┬─────┬─────┐
│     │     │     │
├─────┼─────┼─────┤
│     │     │     │   ← 主体放在交点上
├─────┼─────┼─────┤
│     │     │     │
└─────┴─────┴─────┘
```

**用法**：主体在交点附近 → 画面有呼吸感，且**中心区域空出来可以压字**。
主体在正中央 → 画面呆板，且压字会盖住主体。

## 二、主体判断

看到一张图，先问：**主体是什么，它在哪个区域？**

| 主体 | 常见位置 | 压字区 |
|---|---|---|
| 人物肖像 | 中心偏下 | 顶部 / 上方 1/3 |
| 食物特写 | 中心 | 上方或下方（避开盘子） |
| 风景 | 上下分带 | 天空带或水面带 |
| 产品 | 中心 | 左侧或右侧 |
| 建筑 | 中心或偏上 | 下方地面带 |

**先把主体标出来，再决定字放哪。** 不要反过来。

## 三、quiet zone（安静区）

quiet zone 是画面里**没有细节、没有高对比、可以压字**的区域。

找 quiet zone 的方法：

1. 眯眼看图——大块"糊"的区域就是安静区
2. 通常出现在：纯色天空、水面、虚化的背景、大面积的墙面
3. **不要**压在：人脸、眼睛、文字、产品 logo、高对比纹理上

### quiet zone 不足时

- 换一张图（首选）
- 裁切，把安静区裁到可用的比例
- 给该区域加**局部** scrim（见 `text-over-image.md`）
- 放弃压字，改成"上图下文"的分栏版式

## 四、裁切与比例

目标画板是 **3:4（1080×1440）**。

| 原图比例 | 处理 |
|---|---|
| 3:4 | 直接用 |
| 4:3 / 3:2 | 裁两侧或上下，保留主体 |
| 16:9 | 裁两侧（保留中间）或改做 21:9 头图 |
| 1:1 | 上下补背景，或裁成 3:4 |
| 9:16 竖图 | 裁上下 |

CSS 裁切：

```css
.image-led .bg{
  background-image:url("assets/img/01.jpg");
  background-size:cover;
  background-position:center 30%;   /* 关键：调整纵向焦点 */
}
```

`background-position` 的第二个值决定纵向裁切位置——**人物照通常用 `center 25%` 保证头不被裁掉**。

## 五、色调与主题匹配

| 主题 | 适合的图 |
|---|---|
| `ink` 墨纸 / `kraft` 牛皮 / `dune` 沙丘 | 暖调、低饱和、自然光 |
| `porcelain` 青花 | 冷调、干净、科技感 |
| `pine` 松墨 | 绿色、自然、户外 |
| `midnight` 夜墨 | 暗调、高对比、夜景 |
| Swiss 4 套 | 几何感、产品图、截图、纯色背景 |

**色调不匹配时**：宁可换图，不要加滤镜（CSS 滤镜会让图看起来"脏"）。

## 六、图片质量判断

| 症状 | 判定 |
|---|---|
| 放大后边缘模糊 | ❌ 分辨率不足 |
| 有明显的 JPEG 块状噪点 | ⚠️ 压缩过度 |
| 有日期水印 / 平台 logo | ❌ 不可用 |
| 有明显的手机 HDR 过度痕迹 | ⚠️ 谨慎 |
| 画面里有文字招牌 | ❌ 会与排版打架 |

## 七、多图时的一致性

一套图里用多张照片时：

- **色调要一致**（不要一张暖一张冷）
- **主体位置要一致**（都偏左或都偏右，形成节奏）
- **数量克制**：一套 5–9 页的图，用图不超过 3 页

**图和排版要交替，不要连续三页都是满铺图。**

## 八、自检

- [ ] 主体位置已标出，字没有压在主体上
- [ ] 有可用的 quiet zone
- [ ] 裁切后主体完整（`background-position` 已调）
- [ ] 色调与主题匹配
- [ ] 分辨率 ≥ 1600 px，无模糊
- [ ] 图里没有文字/水印
- [ ] 多图时色调与主体位置一致
