# 图像与摄影构图

这份技能回答一个问题：**什么时候该用图，用什么样的图，以及怎么让文字和图不打架。**

⚠️ 前提：**本专家不使用生图模型。** 需要图像时只有三条路：
**用户提供的图 → 网络可商用图源 → 纯排版图形（SVG / 色块 / 网格）。**

## 什么时候加载

- 用户提供了一张或多张照片
- 内容需要"氛围"（旅行、生活、美食、产品）
- 要做满铺图封面（`M16` / image-led）
- 要放产品截图或工具界面
- 用户问"要不要加插画"

## 三条铁律

1. **用户图优先。** 用户给了图就用用户的图，不要换成网图。
2. **没有图也能做。** 纯排版路线（色块 / 网格 / 线条 / SVG）在多数内容类型下**已经足够**，且风格最稳。
3. **文字必须避开主体。** 人脸、产品、文字密集区上不许压字。

## 判断流程

```
内容需要"氛围"吗？
├─ 不需要（数据、方法、观点） → 纯排版路线，不加图
└─ 需要
   ├─ 用户提供了图？ → 用用户的图，走 text-over-image 规则
   └─ 没有 → 问用户三选一（自己拍 / 从可商用图源取 / 改做纯排版）
```

**"问一次，不二次劝导"。** 用户选了就不再多说。

## 常见错误

- ❌ 为了"丰富"硬塞一张无关的图 → 不如留白
- ❌ 全图加深色遮罩压字 → 图看不见了
- ❌ 文字压在人脸上 → 外行感
- ❌ 网图不落本地、不写来源 → 离线渲染失败 / 侵权
- ❌ 用生图模型补图 → 违反本专家的定义性约束
