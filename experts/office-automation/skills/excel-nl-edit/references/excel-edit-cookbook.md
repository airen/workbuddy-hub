# 自然语言改 Excel · 食谱手册（excel-edit-cookbook）

把用户用大白话提的表格需求，翻译成可以落地的操作。WorkBuddy 里用**表格处理技能**（新建/编辑 .xlsx）执行；MS-Office-AI 项目则是"在 Excel 内接 Gemini 用自然语言更新单元格"的思路，这里先内化成本地可跑的版本。

> 用法：用户说一句 → 在左侧找最接近的意图 → 按右侧做法用表格工具改好 → 回给用户"这次改了哪些单元格/列"。

## 一、读与看

| 自然语言 | 操作意图 | 怎么做 |
|---|---|---|
| "看看这张表有哪些列、多少行" | 结构概览 | 读取首行表头 + 行数，列出字段与类型 |
| "哪一列是金额？单位是什么" | 字段确认 | 定位列、抽样看取值，确认单位/格式 |
| "把前 10 行给我看看" | 抽样预览 | 取前 N 行返回 |

## 二、算与填

| 自然语言 | 操作意图 | 怎么做 |
|---|---|---|
| "加一列'总额'，等于数量×单价" | 新增计算列 | 插入列，公式 `=数量*单价` 或批量计算后落值 |
| "把金额都四舍五入保留两位小数" | 数值格式化/计算 | 套用 `ROUND` 或格式化为 2 位小数 |
| "算每类的总和/平均" | 分组聚合 | 按类别 `SUM/AVERAGE`，或用透视思路输出汇总 |
| "加一列'占比'，等于该项/总计" | 占比计算 | 算总计后逐行 `=项/总计` |
| "把'日期'拆成 年/月/日 三列" | 拆分列 | 按分隔或格式提取 |

## 三、改与清

| 自然语言 | 操作意图 | 怎么做 |
|---|---|---|
| "把'状态'里空的都填成'待处理'" | 空值填充 | 定位空单元格，批量写入默认值 |
| "删掉重复的行" | 去重 | 按关键列判重，保留首条 |
| "把'销售额'为负的数标红" | 条件格式 | 设条件格式（值<0 红色） |
| "把'姓名'列里的空格都去掉" | 清洗 | `TRIM`/替换去除首尾空格 |
| "统一'是/否'写成 TRUE/FALSE" | 标准化 | 映射替换 |

## 四、查与排

| 自然语言 | 操作意图 | 怎么做 |
|---|---|---|
| "找出金额大于 1 万的行" | 筛选 | 条件筛选并列出命中行 |
| "按销售额从高到低排" | 排序 | 按列降序重排 |
| "这个月比上月涨了多少" | 环比 | 按月份分组，算差值/比率 |

## 五、出与联

| 自然语言 | 操作意图 | 怎么做 |
|---|---|---|
| "把这张表做成图表" | 可视化 | 生成柱状/折线图（或导出后制图） |
| "和上周那张表并一起" | 合并 | 按表头对齐纵向/横向拼接 |
| "导出成 CSV 给我" | 导出 | 存为 `.csv` 交付 |

## 执行注意

- **先确认后改**：涉及删除行、覆盖值、改格式前，先说清"我会改 X 列 / 删 N 行"，再动手。
- **留痕**：改完回给用户"旧值→新值"的要点，方便核对（复杂改动可配合 `doc-revise-diff` 的 diff 思路）。
- **不丢原表**：输出新文件（如 `数据表-v2.xlsx`），保留原始。
- **示例数据要标**：用户没给全数据时，用示例行并标注"示例，请替换"。
