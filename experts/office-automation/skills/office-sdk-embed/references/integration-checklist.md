# 内部工具嵌办公能力 · 集成清单（integration-checklist）

给内部系统（后台、CRM、知识库、低代码平台）嵌入在线表格 / 文档 / 幻灯片编辑能力时，逐项确认。对应 dream-num/univer 的"面向开发者的 SDK"思路。

## 一、授权与合规（最先确认）

- [ ] **功能授权逐项看**：univer 不同模块（Sheets / Docs / Slides / 协同 / 公式引擎等）授权可能不同，先到官方核对你要用的功能是否在授权范围内。
- [ ] 自托管 vs 云服务：确认数据落在本司服务器还是第三方，符合公司数据安全/出境要求。
- [ ] 开源协议与商业使用：确认所选包的开源协议是否允许公司内部商用，必要时走采购/授权流程。

## 二、技术接入

- [ ] 选型：要表格编辑 → Sheets 预设；要文档 → Docs 预设；要演示 → Slides 预设；按需组合。
- [ ] 依赖与构建：确认前端框架（React/Vue/原生）兼容性、包体积对首屏的影响（按需引入预设）。
- [ ] 容器与样式：挂载容器尺寸、CSS 引入路径、主题（浅/深）与内部系统一致。
- [ ] 数据打通：用 `getData()/load()` 做序列化与还原；自动存草稿、冲突处理策略。
- [ ] 鉴权：编辑权限与当前登录用户/角色绑定，敏感 sheet 只读或隐藏。

## 三、运行与运维

- [ ] 性能：大表格的渲染与公式计算性能压测；虚拟滚动、分块加载。
- [ ] 协同：多人同时编辑是否需要协同服务，确认部署与授权。
- [ ] 监控：编辑器报错、序列化失败、存储超时的可观测与告警。
- [ ] 版本：锁定 univer 版本，升级前在沙箱回归，避免 API 漂移（API 迭代较快）。

## 四、与「办妥」其他技能的衔接

- `task-to-file` 产出的 .xlsx / .docx，可导入到嵌入的编辑器里继续协同编辑。
- `doc-triage` 整理的清单，可放进嵌入表格做检索与看板。
- `excel-nl-edit` 的"自然语言改表"可在编辑器内接一层指令解析，调用 univer API 落地。

> 本清单为通用检查项；具体以 univer 官方文档与贵司安全/采购规范为准。
