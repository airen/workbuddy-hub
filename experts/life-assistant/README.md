# 生活小助手（life-assistant）

管生活里那些"明明该管、却总懒得管"的琐碎小事——今天吃什么、钱花哪了、东西放哪了、上次练了多重。按你给的五个开源项目内化出五件趁手工具，交付即能用的离线网页，数据全存本地。

> 灵感来源：Jiayu-zheng1/EveryDay_Food、zhangge11/meal-plan-generator、lexical-yoda/ExpenseTracker、asdteke/HomeInventory、tonybenoy/treening。本包不要求你装那五个项目，而是把它们各自最实用的能力做成本地小工具，随用随取。

## 关于这位专家

**当当**，生活小助手。不谈大道理，只把生活琐事一件件接住、办妥。

- **数据全留本地**：所有工具都是离线 HTML，数据存浏览器 `localStorage`，不用联网、不用账号、不要 API key
- **交付即用**：要长期用的就给你生成一个双击打开的网页，要马上知道答案的就直接在对话里给
- **边界清楚**：只管家常事务，不做医疗/法律/理财的专业判断

## 五件工具

| 生活小事 | 技能 | 交付 |
|---|---|---|
| 今天吃什么 | `recipe-by-ingredient` | 按冰箱食材推荐中文菜谱 + 缺料采购清单 |
| 一周吃什么 | `weekly-meal-planner` | 可下载周食谱（含天数/预算/库存） |
| 钱花哪了 | `expense-tracker` | 本地记账本，按账户/分类看开销图，可导出 |
| 东西放哪了 | `home-inventory` | 家当清单：照片/房间/位置/保修/发票，可检索 |
| 练了多重 | `workout-log` | 训练记录：组数次数重量，对照上次，组间休息计时 |

## 典型用法

```
冰箱里有鸡蛋、番茄、青椒和一块豆腐，今晚做什么菜？顺便给我一张采购清单
按我家三口人、每周 300 预算、现有库存，帮我排下这一周的食谱
帮我做个能记账、看开销图、数据存本地的记账本
搬家前帮我把家电保修和发票都登记一下
上次卧推举了多少？帮我记这次训练并对照上次
```

## 使用提醒

- **备份**：数据存在浏览器本地，换设备/清缓存前用工具内"导出"存一份文件
- **范围**：只管家常事务；健康诊断、投资标的、法律纠纷请找对应专业人士
- **离线**：所有工具双击即开，无需联网
