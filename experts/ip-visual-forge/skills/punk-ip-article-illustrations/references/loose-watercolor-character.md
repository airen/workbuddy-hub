# 松散线描水彩角色设定卡

## 目标

把用户上传的人物参考图转译为可供连续插画、小剧场和多场景复用的角色设定卡。它不是普通单张插画：先固定人物身份、外形、服装与气质，再让后续画面只改变动作和场景。

人物参考图只提供角色身份与实际穿着，不提供摄影背景、光影、文字、水印或其他人物。只描述可观察特征，不推断敏感属性或私人信息。

## 固定身份提取

提炼并保持：

- 脸型、五官比例、发型、发际线、发色和肤色。
- 眼镜、首饰与其他实际存在的配件及佩戴位置。
- 上衣、裤子、鞋子或脚部状态的版型、颜色、主要图案和结构。
- 身体比例、体型轮廓、年龄感和整体气质。

图案、字样和 Logo 可适度概括，但应保留主要位置关系和辨识特征。所有视图必须穿同一套服装、同款鞋并保留相同关键配件。

## 设定卡版式

- 使用横向角色卡或清楚的设定卡排版，背景为延伸到四边的纯白页面。
- 至少包含五个完整全身视图：正面、侧面、背面、3/4 视角和一个代表性自然动作。
- 人物之间留出清晰间距，不裁切、不贴边，留白明显。
- 动作优先选择最能代表人物气质的自然动作，如站立准备、拿物、指向、思考或运动准备；不得因动作变化而变脸或改变体型。
- 画面允许时可增加半身头像、轻微表情变化或手部持物状态，但不得造成拥挤。
- 每个视图下方可放小而克制的标签：`正面 / 侧面 / 背面 / 3/4 / 动作`。不添加大标题、长说明、配色板或复杂场景。

## 风格转译

- 用细而松弛、略微抖动的手绘线条勾勒轮廓，允许轻微断续和不完全闭合。
- 五官和服装细节适度概括，但保留一眼可认的身份特征。
- 使用轻薄、稀疏、克制的水彩或水粉平涂表现皮肤、头发、服装与鞋子。
- 允许局部留白、轻微出界和色块错位，呈现自然手绘感。
- 使用低饱和、统一、克制的颜色；不保留照片质感或真实摄影光影。
- 不做照片级写实、强烈明暗、厚重体积、精致 3D、动漫厚涂或商业海报风。
- 整体自然、松弛、清爽、有人味，像杂志中的固定角色设定图。

## 角色设定卡提示骨架

把方括号替换为从参考图观察到的具体特征：

```text
请根据上传的人物参考图，生成一张“松散线描水彩插画风格”的人物角色设定卡，用于后续连续人物插画、小剧场和多场景复用。

角色名称：[角色名]
固定身份：[脸型、五官比例、发型、发际线、肤色、眼镜与配件、上装、下装、鞋子或脚部状态、身体比例、年龄感与整体气质]

参考图只用于确定角色身份和实际穿着。必须保留全部核心识别点，让人一眼看出是同一个角色；不要复制照片背景、摄影光影、文字、水印或其他人物。

将人物统一转译为松散线描水彩插画：细而松弛、略微抖动、允许断续和不完全闭合的线条；五官和服装适度概括但不丢失辨识度；轻薄、稀疏、克制的水彩或水粉平涂；允许局部留白、轻微出界和色块错位。颜色低饱和、统一、克制。不要照片级写实、强烈明暗、厚重 3D、动漫厚涂或商业海报风。

使用横向设定卡排版和延伸到四边的纯白页面。依次完整呈现五个全身视图：正面、侧面、背面、3/4 视角、代表性自然动作。人物之间间距清楚，不裁切、不贴边。所有视图保持相同脸型、发型、身体比例、固定服装、鞋子和配件，不得换衣或丢失关键配件。

动作采用[自然动作]，只改变姿态、方向、视线和轻微表情，不改变身份或体型。视图下方使用小而克制的标签“正面 / 侧面 / 背面 / 3/4 / 动作”。画面允许时可在侧边补充少量头像或表情特写，但整体保持简洁和明显留白。
```

## 干净人物参考图

设定卡完成后，再生成同一角色的独立全身参考图：

- 单人物、自然站姿、正面或轻微 3/4 视角。
- 透明背景优先；不支持透明时使用延伸到四边的纯白背景。
- 保持同样的松散线条、轻薄水彩、身份、服装、鞋子、配件和身体比例。
- 不包含标题、标签、边框、多视图、说明文字、配色板或其他人物。

## 检查

- 五个视图是否确实为同一角色，且都完整不裁切。
- 脸型、五官比例、发型、发际线、肤色、体型和年龄感是否稳定。
- 服装、鞋子、图案、眼镜与配件位置是否一致。
- 是否为纯白页面、松散线描和轻薄水彩，而非写实、3D 或厚涂。
- 动作视图是否自然并保持同一身份。
- 是否删除了照片背景、摄影光影、水印、无关文字和多余场景。
