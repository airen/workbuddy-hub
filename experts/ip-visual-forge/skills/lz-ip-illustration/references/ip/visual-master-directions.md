# Visual Master Directions

Use this protocol after the brief-first interview has passed the visual-master gate and the user has confirmed the summary.

## Purpose

Visual master directions are not random style drafts. They are guided strategic options for a reusable IP system. Each direction should represent a different long-term brand and production strategy.

This stage generates lightweight primary visual candidates for user selection. Do not generate full character sheets here.

Default presentation should be one multi-direction comparison sheet, not several unrelated single images. The user should be able to compare directions side by side in one glance.

## Inputs

Use the confirmed brief:

- character subject
- content domain
- visual style
- primary scenes
- IP type
- audience
- personality

If any visual-master gate field is still unclear, stop and return to `references/ip/brief-first-interview.md`.

## Direction Axes

Build directions by varying a small number of meaningful axes. Choose the axes that matter most for the brief.

### Authority Axis

- expert: more structured, precise, professional
- coach: step-by-step guidance, approachable, instructional
- companion: warm, low-pressure, emotionally supportive
- critic/diagnostician: sharp, analytical, problem-finding

### Scene Participation Axis

- explainer: points, labels, teaches, presents
- operator: moves cards, adjusts machines, tests workflows
- diagnostician: inspects, marks errors, repairs problems
- guide: navigates routes, leads readers through process
- builder: assembles structures, stacks layers, connects modules

### Visual Density Axis

- minimal: character-first, sparse props, strong whitespace
- workspace: desk, board, cards, practical tools
- system-local: simplified machines, pipelines, modular systems
- story-panel: small narrative scenes, light comic framing

### Brand Signal Axis

- outfit-led: signature clothing carries recognition
- prop-led: recurring tools or cards carry recognition
- shape-led: body silhouette and facial shape carry recognition
- palette-led: stable color system carries recognition
- motif-led: repeated visual motif, such as cards, map, board, or modules

### Emotional Tone Axis

- calm and premium
- warm and friendly
- playful and clever
- focused and practical
- absurd but useful

## Required Direction Spread

For 3 directions, cover at least:

1. one expert/structured direction
2. one coach/approachable direction
3. one operator or diagnostician direction

For 4-6 directions, add only if they create real strategic difference:

- a more minimal high-recognition direction
- a more scene-rich explainer direction
- a sharper diagnostic/problem-solving direction

Do not create extra directions just to reach six.

## Direction Card Format

For each direction, output:

- Direction name.
- Strategic angle: what long-term brand strategy this direction represents.
- Character appearance: stable body, face, outfit, and silhouette.
- Signature outfit or object.
- Palette.
- Temperament.
- Scene participation mode: how the IP acts inside article illustrations.
- Best-fit content scenarios.
- Risks or limitations.
- Difference from other directions.

## Candidate Image Format

When generating images for the directions, default to one comparison sheet containing all directions. Each direction should occupy its own clearly separated region in the sheet. If the environment or user explicitly requires separate images, use one lightweight primary visual candidate per direction instead.

For each direction region:

- one main character pose
- simple clean background
- 1-2 signature props at most
- no full turnarounds
- no expression grid
- no color palette row
- no detailed character sheet layout

The comparison sheet should help the user choose a long-term direction. It should not try to lock the final IP system.

The sheet should:

- use visible separation between directions
- include a short direction title for each region
- keep titles lightweight rather than explanatory paragraphs
- preserve roughly equal visual weight across directions so the user is comparing strategy, not just layout emphasis

## Anti-Patterns

Avoid:

- six random outfits
- six color swaps
- six unrelated art styles when the user already chose a visual style
- several separate direction images when one comparison sheet would communicate the trade-off more clearly
- full character sheets before the user chooses a direction
- one "cute", one "cool", one "tech", one "premium" without explaining production implications
- directions that cannot support article inline scene illustrations
- decorative mascot directions where the IP does not act inside the scene

## Selection Guidance

After presenting directions, ask the user to choose one direction or combine parts of two directions.

If the user wants to combine, identify:

- primary direction to preserve identity
- secondary traits to borrow
- traits that should not be mixed because they weaken stability

Then proceed to deep refinement.
