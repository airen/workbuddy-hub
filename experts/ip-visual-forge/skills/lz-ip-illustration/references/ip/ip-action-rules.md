# Inline Article-Scene IP Action Rules

Scope: apply these rules only to inline article illustrations and lightweight animated article scenes. Do not apply them to article covers or Xiaohongshu/Green Book cards: covers use their declared `narrative actor`, `scene guide`, or `brand anchor` deployment mode, and cards use their content-first participation rule.

For inline article scenes, the IP must be part of the explanation, not a decorative mascot.

## Hard Rule

If removing the IP leaves the image's core meaning fully intact, the image fails.

## Valid Participation

The IP may:

- perform the central task
- trigger the transformation
- diagnose the problem
- move work through a process
- compare two alternatives
- label or organize structure
- repair a broken system
- carry the reader along a route
- embody the described state
- create the visible cause of change

## Invalid Participation

Avoid:

- IP standing in a corner smiling
- IP holding a title card only
- IP pasted beside an otherwise complete diagram
- IP acting as a logo or watermark
- IP with no physical relation to the article concept
- IP replaced by any generic character without changing the scene


## One Primary Action Rule

For single-scene article illustrations, the IP must perform one primary conceptual action only. The image may include supporting gestures, marks, props, or reactions, but they must not become a second explanatory event.

Good:

- The IP circles one broken connection so the reader sees the root cause.
- The IP inserts one identity layer card so three routes connect.
- The IP compares two modules by moving one piece across a boundary.

Fails:

- The IP diagnoses a fault, repairs the route, points to three outputs, and teaches the conclusion in the same scene.
- The IP performs several independent verbs on several unrelated objects.
- The scene still contains multiple explanatory events after the action sentence is written.

If multiple actions are necessary, split them into separate illustrations, mini-comic panels, or a Xiaohongshu/Green Book sequence.

## Action Selection

Before each prompt, write one sentence:

`The IP is actively [verb] [object] so the reader understands [cognitive anchor].`

If this sentence is weak, revise the scene before generating.
