# Rule-Bound Crude Doodle Preset Validation Protocol

Use this protocol to validate **Rule-Bound Crude Doodle** before changing its status from candidate to production-approved.

## Required Validation Set

1. **Portrait visual master** — establishes silhouette, thick marker grammar, overshot/double contours, lopsided face, uneven eye height, rough action-driven hands or simple irregular fingers, limb inconsistency, minimum-necessary blunt props, and limited functional palette.
2. **Landscape explanation/orchestration scene** — proves a clear causal relationship can be shown without cleaning up the intended roughness.
3. **Landscape diagnosis/transformation scene** — proves the same error grammar and anti-cute tone survive a different action and composition.

## Required Records

Before generation, archive the temporary test brief with all crude-error locks, visual-master prompt, one prompt per scene, reference-image path/optimization notes if used, and intended aspect ratios.

After generation, archive accepted images, decode/dimension checks, a contact sheet, and `qa-notes.md` that separates automated file checks from human visual approval.

## Human Acceptance Gate

Approve only if all are true:

- all three images visibly use the full repeatable crude grammar rather than a polished hand-drawn approximation;
- the intended marker tendencies are evident without reading as a mechanical checklist: uneven line weight, selective overshot endings and double contours, lopsided head, uneven eyes, rough action-driven hands or simple irregular fingers, limb inconsistency, and minimum-necessary object complexity;
- the character identity and primary action remain readable;
- the tone is anti-cute and anti-polished, never random or unreadable;
- the preset works for more than an engineering topic;
- downstream reference transmission is verified when image-to-image identity continuity is claimed.

The prior Freeform Doodle validation archive is superseded and cannot be reused to promote this preset.
