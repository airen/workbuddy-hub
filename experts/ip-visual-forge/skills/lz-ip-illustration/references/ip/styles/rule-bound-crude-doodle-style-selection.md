# Rule-Bound Crude Doodle Styles: Selection and Validation

Use this guide for reusable IP rendering styles defined by repeatable intentional crudeness: a stable grammar of marker-line errors, facial/body asymmetry, blunt props, and clear action silhouettes.

Read `references/ip/styles/style-selection.md` first. A rendering preset is a locked component of the IP visual system, not an article-by-article effect.

## Rendering Family

### Rule-Bound Crude Doodle

A modern expressive doodle system that looks intentionally rough and untrained while remaining clear, causal, and recognisable. It can illustrate technical, product, educational, opinion, lifestyle, or narrative content. A technical topic is not required.

It is not:

- the structured, explanation-first Hand-drawn sketchnote technical draft preset;
- the softened, tasteful editorial “freeform doodle” direction;
- random scribbling, careless whiteboard output, or generic poor-quality drawing;
- a cute cartoon, elastic-action gag system, or named-franchise-adjacent style.

## Available Presets

## Production Status

Rule-Bound Crude Doodle is a **production-approved preset**. Independent source-faithful validation passed on 2026-07-15 with explicit human visual approval. Validation archive: `references/ip/styles/validation-runs/rule-bound-crude-doodle-20260715/`.

## Test Pattern

1. Create one temporary test IP and portrait visual master using the full crude-error grammar.
2. Use it for one action-led landscape explanation/orchestration scene.
3. Use it for one landscape diagnosis, transformation, or before/after scene.
4. Archive prompts, images, dimensions, decode checks, and `qa-notes.md`.
5. Verify visible stability of thick uneven lines, overshot ends, double contours, lopsided face, uneven eye height, rough action-driven hands or simple irregular fingers, limb inconsistency, minimum-necessary object grammar, and anti-cute tone across outputs.
6. Request human approval before promotion.

The retired `freeform-doodle-illustration-20260715` archive records an adjacent softened direction only; it is not evidence for this preset.
