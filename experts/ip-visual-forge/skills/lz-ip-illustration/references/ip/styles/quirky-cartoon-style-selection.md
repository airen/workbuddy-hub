# Quirky Cartoon Rendering Presets: Selection and Validation

Use this guide only for **quirky cartoon style families** in reusable IP systems. These styles are parallel to Chinese nostalgic styles and Japanese manga / animation styles.

For the global style index, read `references/ip/styles/style-selection.md`.
For Japanese manga / animation styles, read `references/ip/styles/japanese-manga-style-selection.md`.
For Chinese nostalgic styles, read `references/ip/styles/lianhuanhua-style-selection.md`.

A rendering preset is a **locked component of the IP visual system**, not an article-by-article filter. Do not imitate named characters, studios, mascots, series, logos, or proprietary cartoon universes.

## Rendering Families

- **Modern color rubber-hose tech cartoon family**: original-character elastic body comedy for workflow tangles, runaway tools, connector repair, bug pests, and visible process recovery; never a named vintage cartoon imitation, pure black-and-white nostalgia filter, or creepy mascot.

Future candidates in this family may include heta-uma weird manga, UPA-inspired mid-century modern oddball cartoon, newspaper gag cartoon, lowbrow/pop-surreal technical satire, or other small quirky humor systems. Keep each as an independently validated locked preset.

## Preset-Specific Test Pattern

Every new quirky cartoon preset must pass independently. Do not reuse another preset's reference image, prompt block, or acceptance result.

General validation shape:

1. Create an independent temporary IP selected to stress the preset's strengths.
2. Generate one portrait visual master and archive its prompt beside it.
3. Generate the preset-required action/expression sheet when the style depends on reusable acting.
4. Use the visual master as an image-to-image identity reference for two landscape article scenes:
   - one orchestration / explanation scene;
   - one diagnosis / repair / transformation scene.
5. Archive all prompts, images, dimensions, and a `qa-notes.md` record.
6. Require human visual approval before marking the preset passed.
7. Keep the test IP temporary unless the user separately approves it as a production IP.

For **Modern color rubber-hose tech cartoon**, add one required elastic action sheet: neutral explaining, stretched grab, recoil, tangled, pulling knot straight, catching bug pest, springing back, presenting restored route.
