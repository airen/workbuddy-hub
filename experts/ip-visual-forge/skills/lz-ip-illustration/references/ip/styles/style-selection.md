# Locked Rendering Style Selection

Use this file as the **top-level index** for reusable IP rendering styles. A rendering style is a locked component of the IP visual system, not an article-by-article filter.

## Style Families

| Family | Use for | Selection guide | Validation protocol |
|---|---|---|---|
| Chinese nostalgic narrative styles | Chinese lianhuanhua, textbook illustration, freehand ink-wash technical narrative, New Year picture, and other nostalgic Chinese narrative systems | `references/ip/styles/lianhuanhua-style-selection.md` | `references/ip/styles/lianhuanhua-preset-validation.md` |
| Japanese manga / animation styles | Classic children’s manga-animation and gag-reaction manga-animation; future Japanese gag, heta-uma, or manga-animation families | `references/ip/styles/japanese-manga-style-selection.md` | `references/ip/styles/japanese-manga-preset-validation.md` |
| Quirky cartoon styles | Rubber-hose, heta-uma, UPA-like oddball cartoon, newspaper gag, lowbrow/pop-surreal technical satire, and other exaggerated humor systems | `references/ip/styles/quirky-cartoon-style-selection.md` | `references/ip/styles/quirky-cartoon-preset-validation.md` |
| Modern explanatory styles | Sketchnote, technical draft, contemporary workflow explanation, and non-nostalgic non-folk systems | currently listed in this index; split when more styles are added | preset-specific validation notes |

## Production Presets

### Chinese Nostalgic Narrative Styles

- Traditional Chinese baimiao realistic lianhuanhua
- Pen-and-ink realistic lianhuanhua
- Gongbi line-and-color realistic lianhuanhua
- Woodcut-print realistic lianhuanhua
- Late-20th-century Chinese realistic watercolor-and-gouache textbook illustration
- Mianzhu woodblock New Year picture
- Freehand Ink-Wash Technical Narrative / 写意水墨技术叙事

Chinese shadow puppetry is retained only as an optional **article-scene treatment**, not a reusable primary-IP rendering preset: its side-profile, articulated-cutout grammar and constrained facial range make unrelated IPs converge visually. It must not appear in new-IP style selection.

Read `references/ip/styles/lianhuanhua-style-selection.md` before using any of these.

### Rule-Bound Crude Doodle Styles

- Rule-Bound Crude Doodle

This is a production-approved, content-neutral rule-bound crude doodle system, not an engineering-only style. Read `references/ip/styles/rule-bound-crude-doodle-style-selection.md`, `rule-bound-crude-doodle.md`, and `rule-bound-crude-doodle-preset-validation.md` before creating or revising an IP with this preset. Validation archive: `references/ip/styles/validation-runs/rule-bound-crude-doodle-20260715/`. Keep it separate from lianhuanhua, folk craft, and manga-animation families.

## Routing Rule

When a user names a specific style, read:

1. this top-level index;
2. the matching family selection guide;
3. the preset file itself;
4. the matching validation protocol if creating, modifying, or promoting a preset.

Do not add Japanese, Western cartoon, sketchnote, or modern explanatory styles to the Chinese nostalgic style guide. Do not add Chinese nostalgic styles to the Japanese manga guide. Keep rubber-hose, heta-uma, UPA-like, and other oddball cartoon systems in the quirky cartoon guide unless a later split is justified.
