# Named-Work Style Research Guardrail

When a user cites a well-known work to identify a visual family, treat it as research evidence—not as the name of a production preset and not as a request to copy protected expression.

## Procedure

1. Separate transferable design rules from protected identifiers.
   - Transferable: shape grammar, line/fill relationship, palette roles, shadow treatment, compositional reading path, and narrative mechanics.
   - Do not transfer: named characters, signature props, distinctive costumes, logos, named settings, artist/studio imitation, or prompt wording that asks for a specific work’s “style.”
2. Treat a materially different rendering system as a **parallel locked preset**, never an unannounced add-on to the currently selected preset.
3. Define its selection boundaries, best-fit article roles, identity locks, and style-specific avoid list before generation.
4. Independently validate it with a temporary test IP: portrait visual master, explanation/orchestration landscape, and diagnosis/repair landscape. Use the accepted visual master as an image reference downstream when supported; save prompt records and verify archived image decoding.
5. Require user visual acceptance before marking the preset passed. Keep the test IP temporary unless separately approved as a production IP.

## Example: Classic Japanese Children’s Manga-Animation

The transferable system is original rounded geometric character design, clean stable dark contours, limited flat-color roles, restrained cel shadows, and an everyday problem → physical action → visible result reading path. It must not be called by a named franchise’s style name in production prompts. Prevent drift toward direct franchise imitation, generic glossy modern anime, chibi/kawaii mascots, manga-page conventions, magical signature gadgets, or passive figures beside icon clutter.
