# Scene Methods and Composition Patterns

Use this file to choose how article content becomes an illustration scene. Do not force every image into metaphor.

## Content-to-Scene Methods

### Concrete Task

Turn the idea into a task the IP can physically perform.

Use for: workflows, operations, prompt editing, content production, tool use.

IP actions: operate, carry, connect, sort, assemble, cut, place, test.

### Structure Mapping

Turn conceptual relationships into a spatial structure.

Use for: frameworks, categories, hierarchies, system parts, prompt components.

IP actions: label, stack, arrange, connect, separate, group, annotate.

### Before-After Comparison

Show transformation between weak and improved versions.

Use for: optimization, rewriting, diagnosis, upgrade, iteration.

IP actions: compare, replace, repair, point, move pieces from left to right.

### Problem Diagnosis

Turn the problem into an object or scene being inspected.

Use for: mistakes, failure cases, hidden causes, quality checks.

IP actions: inspect, magnify, mark, measure, remove, repair.

### Route or Journey

Turn a process into a path, map, checkpoint sequence, or obstacle course.

Use for: growth path, decision path, learning route, project lifecycle.

IP actions: navigate, walk, push, climb, choose, cross, arrive.

### System Mechanism

Show one local part of a larger system.

Use for: causal chains, pipelines, feedback loops, model behavior, publishing systems.

IP actions: tune, enter, connect, open panels, adjust valves, trace signals.

### State Embodiment

Turn an abstract state into a physical situation.

Use for: overload, confusion, hesitation, momentum, bottleneck, uncertainty.

IP actions: untangle, hold, balance, resist, organize, escape.

### Conceptual Metaphor

Use physical metaphor for an abstract judgment.

Use for: abstract claims, counterintuitive insights, mental models.

IP actions: transform, pull, climb, dig, open, bridge, repair.

## Composition Patterns

- Workflow: steps across the frame with the IP moving work forward.
- Breakdown: one object split into named modules with the IP dissecting or sorting.
- Before-after: two sides with the IP comparing, repairing, or transferring.
- Diagnosis board: problematic object with marks, notes, and IP inspection.
- System local view: a machine, pipeline, or board section where the IP is operating.
- Layer stack: horizontal or vertical layers with the IP organizing levels.
- Route map: path with checkpoints and the IP traveling through them.
- Mini comic: 2-4 panels showing a small transformation.
- Status scene: the IP physically experiencing or resolving a state.

Choose one primary pattern per image.
