# Xiaohongshu Density and IP Participation

Use this with `xhs-visual-editorial-system.md`. The following are decision candidates, not preset card layouts. AI selects composition from each card's information relation.

| Card job | Common information relation | Candidate grammars | Budget | IP scale / participation |
|---|---|---|---:|---|
| feed cover | pain/benefit/contrast | sparse proposition, comparison, visual metaphor | 1-2 | 10-20%; guide / brand / emotion |
| overview | taxonomy/hierarchy | mindmap, relation map, quadrant, balanced modules | 3-4 | 10-20%; guide / comparison |
| method | progression/spatial task/repeated step | flow, route, spatial map, list, action scene | 3-5 | 8-18%; actor only if useful |
| proof | alternatives/state change | comparison, balanced modules, state scene | 2-4 | 10-20%; comparison / guide |
| summary / CTA | principles/one conclusion | sparse proposition, list, balanced modules | 1-3 | 12-25%; closer / guide / brand |

IP may be actor, guide, brand anchor, emotion anchor, or comparison anchor. Small IP is intentional brand continuity, not a mandatory causal actor.

Text limit: labels <=10 Chinese characters; no local overlay, paragraph wall, or tiny table.
