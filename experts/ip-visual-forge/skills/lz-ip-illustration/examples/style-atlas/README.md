# Style Atlas

This directory contains the README rendering-style benchmark images.

- Scope: 18 production rendering styles.
- Candidate styles do not receive README samples until their independent validation passes.
- Every image uses the same original, unbranded **Signal Relay Recovery** scenario so differences are attributable primarily to rendering and composition grammar.
- Prompts, output metadata, technical checks, and batch state are preserved beside the images.

See `../../docs/style-atlas-plan.md` for the full scene contract, batch plan, and README update gate.
