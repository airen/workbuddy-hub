# Comic — Three-Node Relay Repair (Annotated)

```text
16:9 横幅文章内复杂配图，不是封面。原创、无品牌的引导角色沿一条浅对角接力路径，在三个职责明确的工作站间移动：左侧发现问题，中间定位故障，右侧验证恢复。角色携带连接件，在画面中央亲手把断开的路径接回；动作、工作站和路径形成发现、定位、接回、验证的连续因果。

必须生成且仅生成以下五个清晰、短小、准确的中文标签，并作为场景内实体标识：左侧工作站吊牌“发现”；中间工作站页签“定位”；中央断开的连接处标签“断点”；角色手中连接件的小标签“接回”；右侧工作站结果铭牌“验证”。文字紧贴实体，不遮挡脸、手或接回动作。无标题、无其他可读文字、无 logo、无水印、无对话框。

原创漫画插画：果断轮廓、富节奏的动作姿态、强焦点层级、简化色彩与一条连续可读的因果序列。允许局部前后变化，只要不变成密集分镜页。避免模仿具体漫画、动画风、超级英雄奇观、密集对白、光滑 3D、照片写实或被动角色。
```
