# 3D Toy — Three-Node Relay Repair (Annotated)

```text
16:9 横幅文章内复杂配图，不是封面。原创、无品牌的小型实用引导角色，以有体积的玩具化形象沿一条浅对角接力路径，在三个职责明确的触感工作站之间移动：左侧发现问题，中间定位故障，右侧验证恢复。角色携带连接件，在画面中央亲手把断开的路径接回；工作站、连接件与人物姿势共同形成“发现 → 定位 → 接回 → 验证”的连续因果。

必须生成且仅生成以下五个清晰、短小、准确的中文标签，并作为场景内的实体标识：左侧工作站吊牌“发现”；中间工作站页签“定位”；中央断开的连接处标签“断点”；角色手中连接件的小标签“接回”；右侧工作站结果铭牌“验证”。文字必须贴在各自实体上，不遮挡角色脸、手或接回动作。无标题、无其他可读文字、无 logo、无水印。

3D 玩具风：圆润简化的制造形体、柔和受控的棚拍光、哑光触感材质、清晰空间舞台、有限和谐调色、可读的手和接回动作；路径、断点和验证必须高于装饰。亲和立体但不能变成可爱的静态摆件。避免高光塑料、空洞产品棚拍、照片写实、毛绒玩具、密集 UI、游戏资产质感、命名作品或角色模仿。
```
