# Pixel Art — Three-Node Relay Repair (Annotated)

```text
16:9 横幅文章内复杂配图，不是封面。原创、无品牌的引导角色沿一条浅对角接力路径，在三个职责明确的像素工作站间移动：左侧发现问题，中间定位故障，右侧验证恢复。角色携带连接件，在画面中央亲手把断开的像素路径接回；工作站、断点、动作与确认状态形成连续因果。

必须生成且仅生成以下五个清晰、短小、准确的中文标签，并作为场景内实体标识：左侧工作站吊牌“发现”；中间工作站页签“定位”；中央断开的连接处标签“断点”；角色手中连接件的小标签“接回”；右侧工作站结果铭牌“验证”。标签必须由清晰像素字构成、贴近实体、不遮挡脸、手或接回动作。无标题、无其他可读文字、无 logo、无水印。

像素艺术：刻意清晰的像素簇、有限协调调色板、网格感阶梯轮廓、可读角色与物体、选择性像素高光，路径/故障/接回/验证在缩略图仍清楚。要像复古交互系统隐喻，而非模糊低分辨率。避免平滑矢量曲线、抗锯齿绘画、3D、照片写实、密集 HUD/UI 或命名游戏模仿。
```
