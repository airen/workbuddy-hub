# 0.3.29 Xiaohongshu Feed-Cover Hook Smoke Test

**Goal:** Verify that the Xiaohongshu pipeline extracts and selects an in-image feed-cover hook during article analysis, without creating or copying a published SEO title.

## Source Article (test fixture)

Parents repeatedly remind primary-school children to get dressed, pack their bags, and start homework. The article proposes a paper habit card: the child chooses and ticks visible daily tasks, turning repeated verbal reminders into a self-managed routine. Evidence boundary: it can reduce prompting friction; it does not promise that every child immediately becomes self-disciplined.

## Article Analysis

- Target reader: parent of a primary-school child who is exhausted by daily reminders.
- Article-backed content promise: replace repeated verbal reminders with a visible, child-ticked task card to reduce prompting friction.
- Feed-cover decision: in-image text only; no published SEO title is supplied, created, copied, or evaluated.

## Candidate In-Image Cover Hooks

| Type | Candidate | Assessment |
|---|---|---|
| pain | 每天都在催，孩子还是慢？ | Immediate but the mechanism is absent. |
| contrast | 催10次，不如自己勾1次 | Makes the old/new behavioral contrast visible and is specific. |
| benefit | 把催促，换成孩子自己完成 | Clear benefit but weaker thumbnail tension. |
| counterintuitive | 孩子拖拉，不一定是不自律 | Strong reframe but needs more explanation. |
| curiosity | 一张卡，少掉每天的催促 | Mentions the object but is less decisive. |

## Selected Cover Hook

- **H1:** 催10次，不如自己勾1次
- **Type / strength:** contrast / 5
- **Why it wins:** It makes the reader's current pain and the article's mechanism visible in one short contrast. The nearest alternative (pain) stops a scroll but does not explain why this post differs from generic parenting advice.
- **Support / visual proof:** `小学生纸质自律卡`; a child actively ticks a paper task card opposite a parent no longer following behind.
- **One-second understanding:** This is a concrete tool for replacing reminders with child self-checking.
- **Truthfulness check:** The claim is framed as a practical contrast, not a guarantee; it stays within the article's evidence boundary.

## Card-1 Composition Decision

- Reader takeaway: A visible self-tick card is a better daily prompt than repeated reminders.
- Information relation: two alternatives / before-vs-after behavior.
- Candidate grammars: comparison, sparse proposition, action scene.
- **Selected grammar:** comparison.
- **Why this is clearest:** A left/right reminder-vs-self-tick contrast makes the hook's `催` and `自己勾` terms visible. A sparse proposition lacks mechanism proof; a single action scene weakens the direct contrast.

## Result

**PASS** — the pipeline generated five article-backed in-image hook candidates, selected one with a rationale, supplied visual proof, selected a relation-matched composition, and did not use an SEO/published title.
