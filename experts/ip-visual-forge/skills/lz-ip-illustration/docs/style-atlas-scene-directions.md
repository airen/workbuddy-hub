# Style Atlas — Article Illustration Scene Directions

Purpose: choose one complex, text-bearing article-inline-illustration scene before generating production style samples. Every option uses one original, unbranded guide character and permits short Chinese text only as physical scene labels — never as a cover headline or post-production overlay.

## Direction A — 一条链路，五步排障

**Article point:** 排障不是看到异常就重启，而是沿链路定位真正断点。

**Scene:** A guide begins at a handheld alert device, follows a visible route across the illustration, passes through three distinct system elements, stops at a broken connection, physically repairs it, and sees the route reach a confirmation node. The reading order is left → center → right.

**Exact labels and carriers:**

| Label | Carrier | Meaning |
|---|---|---|
| 异常 | alert tab attached to source device | detection |
| 追踪 | small route flag | trace |
| 断点 | tag tied to the detached connection | fault |
| 修复 | short tag on the active repair tool/hand | intervention |
| 已恢复 | final node plaque | verification |

**Strength:** strongest shared causal structure across all 18 styles; works as a real technical article illustration, not just a generic workflow diagram.

**Risk:** can become a linear schematic if the IP action and system elements are not given enough spatial drama.

## Direction B — 混乱输入，收敛为一条可执行路径

**Article point:** 工作流卡住时，先把分散输入收敛为一个下一步，而不是同时处理所有问题。

**Scene:** A guide stands amid four differently shaped incoming fragments. It sorts, discards, and joins only the necessary fragments into one visible execution path, then moves a final task token into a completed channel. The reading order is scattered edges → center sorting action → one clean outgoing route.

**Exact labels and carriers:**

| Label | Carrier | Meaning |
|---|---|---|
| 输入 | loose incoming fragment tab | source |
| 噪声 | crossed-out scrap | discard |
| 关键 | selected component tag | priority |
| 下一步 | route flag leaving the guide | execution |
| 完成 | final output marker | verification |

**Strength:** richer composition and stronger before/after contrast; useful for product, AI workflow, writing, and management articles.

**Risk:** some styles may render the sorting logic as a static collage unless the guide’s hands and route are emphatically causal.

## Direction C — 三个节点，各有职责，接力完成修复

**Article point:** 多步骤协作的关键不是堆更多工具，而是让每个节点只承担自己的职责。

**Scene:** A guide moves along a triangular or shallow diagonal relay route linking three clearly different work stations. One station finds an issue, one isolates the break, and one confirms the restored output. The guide carries the repair object between them and physically completes the connection at the central fault.

**Exact labels and carriers:**

| Label | Carrier | Meaning |
|---|---|---|
| 发现 | first station tag | detect |
| 定位 | second station tab | isolate |
| 断点 | central broken link marker | fault |
| 接回 | repair-object tag | reconnect |
| 验证 | final station plate | confirm |

**Strength:** most complex system relationship; demonstrates composition, action continuity, and small-label integration well.

**Risk:** high information density and a three-station structure may be too difficult for highly simplified styles such as pixel art or crude doodle.

## Recommendation

Use **Direction A** as the default atlas scene. It has one active IP, a clear route, a tangible repair, five short labels, and enough structure to distinguish all rendering systems without forcing weak styles into a dense multi-node architecture.

Direction B is the best alternative if the README should emphasize broader knowledge-work and AI/workflow articles rather than technical troubleshooting.

Direction C is intentionally held as a later stress-test scene, not the first cross-style README atlas benchmark.
