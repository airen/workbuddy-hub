# 老张 IP 个人视觉文章配图系统

> 用 Hermes Skill 为个人 IP 建立稳定、可复用的视觉身份，并应用到文章封面、文章场景配图与小红书图文卡片。

[English README](README.en.md)

## 项目简介

一次性的配图可以好看，却难以沉淀成持续可识别的个人品牌。本项目将个人 IP 的视觉定义、动作设计、提示词规范、图像生成及不同内容载体的工作流整合为一个可复用的 Skill。

它强调四件事：

- **先建立 IP，再规模化产出**：锁定人物身份、标志服装与道具、色彩、渲染语言和可变边界。
- **让 IP 参与叙事**：人物必须解释、拆解、诊断、修复、构建或引导，而不是仅作为装饰出现在画面中。
- **针对不同载体使用不同流程**：封面、文章内图和小红书卡片分别服务于传播承诺、认知解释和手机端滑读节奏。
- **保留可复现性**：每次生成均保存提示词、规划、图片和 QA 记录，方便回看、复用与版本迭代。

当前项目已包含示例 IP：`wenren-agent`（文人 Agent）。

## 能力范围

| 场景 | 主要产物 |
| --- | --- |
| 创建或重构个人 IP | IP 档案、视觉规范、提示词包、动作库、主视觉参考图 |
| 文章封面 / 社媒首图 | 封面 brief、多个创意方向、最终提示词、封面图与 QA |
| 文章内场景配图 | 内容分析、shot list、逐张提示词、配图与 QA |
| 小红书 / 轮播图文卡片 | 帖子 brief、系列视觉系统、卡片计划、卡片图与 QA |
| 实际图像生成 | 工具选择、参考图约束、输出归档与技术验证 |

## 安装与使用

### 在 Hermes 中安装

在 Hermes 对话中使用斜杠命令：

```text
/learn
```

然后选择或导入本项目中的 `lz-ip-illustration` skill，即可将它安装到当前 Hermes profile。安装后，请开启一个新会话或重新加载 skill，再开始使用。

### 选择任务入口

- **创建新的个人 IP**：从自然语言 brief 开始，完成访谈、视觉方向探索与身份锁定。
- **制作文章封面**：从文章标题、摘要、大纲或正文中提炼传播承诺和视觉钩子。
- **制作文章插图**：从文章中提取高价值认知锚点，规划并生成场景化配图。
- **制作小红书卡片**：将文章或主题转成一组手机端易读、能推动滑动的卡片。

使用时，skill 会先检查当前项目是否已有可用 IP；没有 IP 时会进入 IP 创建流程，而不会擅自使用示例资产。

## 工作流概览

```text
用户需求
   │
   ▼
检查 / 选择现有 IP
   │
   ├─ 没有 IP ──► brief-first 访谈 ──► 主视觉方向探索
   │                                      │
   │                                      ▼
   │                              精修、确认与身份锁定
   │                                      │
   │                                      ▼
   │                                  写入 IP 资产
   │
   └─ 已有 IP ──► 选择封面 / 文章场景 / 小红书卡片工作流
                        │
                        ▼
             规划方向、shot list 或 card plan
                        │
                        ▼
                保存提示词 → 生成 → QA → 归档
```

## 核心原则

1. **身份稳定优先**：脸部、体态、标志服装、关键道具、色彩和渲染方式不能在不同场景中漂移。
2. **角色必须造成变化**：若删除 IP 后画面仍能完整表达核心意思，该场景不合格。
3. **单图只服务一个认知锚点**：不把整篇文章的所有概念塞进一张图。
4. **封面不是内文配图**：封面需具备准确传播承诺、缩略图可读性、视觉钩子和标题安全区。
5. **卡片不是封面的切片**：每张卡应有独立阅读节拍与一个明确的视觉锚点。
6. **先保存提示词再生图**：提示词是可复现记录；重新生成必须采用版本化文件名，避免静默覆盖。

## 风格预设

所有风格预设都是 **锁定型渲染系统**，不是可随意切换的一次性滤镜。选定后，应随 IP 一起固定在视觉规范与提示词包中，并用已确认的主视觉参考图约束后续场景。

### 已验证的生产用预设

当前 Skill 提供多种**已独立验证**的生产用预设，覆盖怀旧中国叙事、日系漫画/动画、quirky cartoon 与现代说明/涂鸦等风格家族。它们都有明确的视觉边界，可作为 IP 的长期渲染系统；选定后不应在文章之间随意混用。完整路由以 [`references/ip/styles/style-selection.md`](references/ip/styles/style-selection.md) 为准。**手绘草稿信息图与规则化粗糙涂鸦均属于现代风格，不归入怀旧中国风。**

`custom` 不属于生产用预设：它只是收集用户自定义方向时的输入选项。自定义方向需要先明确视觉边界、完成独立验证并获得确认，才可以成为新的锁定渲染系统。

| **像素艺术** | 网格化轮廓、有限调色板、离散像素块与复古交互感 | 游戏化流程、状态切换、工具/系统隐喻 | 不要用低分辨率掩盖信息；保持角色、动作和文字在目标尺寸可读 |
| **经典日式儿童漫画动画** | 原创的圆润几何角色、干净轮廓、有限平涂与轻量赛璐璐阴影 | 日常问题、测试、比较、排序、轻量技术解释 | 不是对任何动画、工作室、角色或标志道具的模仿；避免现代华丽日漫、Q 版和魔法道具 |

| **手绘草稿信息图** | 白底或浅灰纸面、黑灰手绘线、可见草稿结构线、纸面推演痕迹、少量黄色/浅蓝/浅绿批注；整体像视觉笔记或低保真信息图 | 技术文章里的概念拆解、流程对比、诊断路径、方法论卡片和知识海报 | 属于“其它风格”，不是怀旧中国风、连环画、民俗工艺或教材怀旧；也不是潦草涂鸦、密集白板截图或正式精修插画 |
| **规则化粗糙涂鸦** | 粗马克笔、不均匀线重、超出端点、双描、歪头与不齐双眼、固定笨拙手套手；粗糙规则稳定但动作清晰 | 有独立态度的个人品牌封面、诊断/修复/转化场景、观点与 maker 风格内容 | 不是“精致手账涂鸦”、手绘草稿信息图、可爱漫画或随机乱画；必须反可爱、反精致，且保持人物与因果可读 |

### 如何选择

- 想要**清雅、理性、线条留白**：选白描写实连环画。
- 想要**技术结构、拆解与诊断感**：选钢笔写实连环画。
- 想要**细腻、秩序和稳定色彩身份**：选工笔线描设色连环画。
- 想要**力度、转折、修复和强叙事剪影**：选木刻版画写实连环画。
- 想要**温暖、日常、亲和的教育感**：选写实水彩/水粉教材插画。
- 想要**节庆、更新、祝福与民间活力**：选绵竹木版年画。
- 想要**舞台感、因果揭示和传统手工质感**：选中国皮影。
- 想要**清晰、高效、图解化的知识表达**：选扁平插画。
- 想要**推演感、技术方法论和纸面思考过程**：选手绘技术草图。
- 想要**白底手画视觉笔记、低保真信息图和草稿感知识海报**：选手绘草稿信息图。
- 想要**专业叙事、可信人物与更丰富的空间材质**：选半写实插画。
- 想要**亲和、轻松和立体的产品/概念表达**：选 3D 玩具。
- 想要**温暖手作感和柔和情绪**：选黏土风。
- 想要**冲突、变化或短序列叙事**：选漫画。
- 想要**游戏化状态与复古交互隐喻**：选像素艺术。
- 想要**轻松、直观、日常化的问题—行动—结果叙事**：选经典日式儿童漫画动画。
- 想要**粗粝、独立、反精致，但动作与因果一眼清楚**：选规则化粗糙涂鸦。

新增风格前必须独立验证；相近预设已经通过验证，并不代表新预设可以直接投入生产。
