# Shot List

Default count: 3-5 shots unless the article only supports fewer, or the user explicitly requests more.

Show this table to the user for confirmation before generating images.

Action rule: one single-scene illustration has one core structure and one primary IP action. If multiple actions are required, split into multiple shots or mini-comic panels.

Text rule: prefer no labels when the scene can explain itself. If labels are needed, they must be generated as integrated in-image text, usually 5-10 Chinese characters, placed on physical carriers such as tags, tabs, module cards, route signs, sticky notes, callout flags, or diagram nodes. Local text overlay/compositing is forbidden.
