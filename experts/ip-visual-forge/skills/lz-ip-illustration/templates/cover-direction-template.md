## Candidate Directions

For each direction, select an IP deployment mode deliberately:

- `narrative actor`: the IP causes, reveals, confronts, repairs, chooses, transforms, or navigates the key event.
- `scene guide`: the IP orients, emotionally interprets, or guides attention within a motif that already carries the proposition.
- `brand anchor`: the proposition works without the IP; a small IP presenter/observer reinforces author and series recognition without competing with the main visual.

Use one expression mode: `scene`, `metaphor`, `conceptual`, `minimal`, `hero`, or constrained `typography`.

Use one text mode: `none`, `integrated-title-only`, or `integrated-title-and-short-subtitle`. Text-rich cover copy and local overlays are forbidden.

Use one mood: `subtle`, `balanced`, or `bold`.

Contextual color emphasis may adjust only the balance, value, and situational use of colors already defined in `visual-spec.md`. Rendering and identity palette are locked; do not introduce a conflicting style or new dominant palette.

Delete unused rows. Add a fourth direction only when it is genuinely distinct.
