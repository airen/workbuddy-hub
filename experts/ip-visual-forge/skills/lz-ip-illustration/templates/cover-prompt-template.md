# Cover Image Prompt

```text
Create a [platform and aspect ratio] article cover image.

Stable IP system — locked:
[insert fixed identity, outfit, primary visual master, palette, rendering constraints, and signature traits from visual-spec.md]
Do not change the IP rendering system or introduce a conflicting dominant palette.

Article cover brief:
- Communication proposition: [one accurate visual promise]
- Reader tension: [one problem, desire, uncertainty, or conflict]
- Promised payoff: [one supported result or understanding]
- Content boundary: [what the image must not imply]

Primary visual hook:
[conflict, transformation, obstacle, reveal, choice, scale, mechanism, or identity]

Cover motif:
[describe one physical scene or visual relationship with one dominant event]

IP deployment:
- Mode: [narrative actor / scene guide / brand anchor]
- Purpose: [why this degree of IP participation is right for this cover]
- Scale and placement: [major subject / near motif / small intentional edge or lower-corner anchor]
- Role, posture or action: [one strong verb for narrative actor; a guidance gesture, gaze, or theme-responsive small prop for scene guide or brand anchor]
- Emotion: [one dominant readable state]

Mode rule:
- Narrative actor: the IP actively [strong verb] [visible object or opposing force]; removing the IP must break the central visual idea.
- Scene guide: the IP improves reader orientation or emotional interpretation without competing with the motif; it need not cause the event.
- Brand anchor: the primary proposition works without the IP; the small presenter/observer strengthens series recognition and must not obstruct the headline, hook, or thumbnail hierarchy.

Visual treatment:
- Cover expression mode: [scene / metaphor / conceptual / minimal / hero / constrained typography]
- Text mode: [none / integrated-title-only / integrated-title-and-short-subtitle]
- Mood: [subtle / balanced / bold]
- Contextual color emphasis: [only how existing IP colors shift in balance, value, or situational use]
- Rendering: locked from visual-spec.md; do not replace it with flat-vector, 3D, pixel, or another incompatible system

Composition:
- [camera distance and spatial hierarchy]
- one dominant subject or visual event; no article-summary collage
- strong thumbnail silhouette and focal contrast
- ensure IP scale and placement follow the selected deployment mode
- no local text overlay and no post-production title compositing

Text policy:
[no text / integrated title lettering requested]
If integrated title lettering is requested:
- exact title text: [short title]
- exact subtitle text: [optional short subtitle]
- typography must be part of the generated visual composition as integrated cover typography, not added later
- title must not cover the IP face, meaningful gesture, laptop, book, central motif, or primary hook
- reject garbled, deformed, misspelled, pseudo-Chinese, or detached text

Objects:
- Primary object or opposing force: [object]
- Optional secondary object: [object or none]

Avoid:
identity drift, incompatible rendering or palette replacement, undeclared decorative IP placement, obstructive small-IP sticker, multiple competing scenes, article-summary collage, dense labels, tiny UI, unsupported claims, local text overlay, post-production title compositing, random icons, excessive props
```
