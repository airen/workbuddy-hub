# 🎨 自媒体 IP 配图生成器 | IP Image Generator

> 从一个模糊的角色概念出发，生成完整的 IP 角色设计全案。

## ✨ 这是什么

一个 Cola/Claude Skill，帮自媒体人用 AI 生图工具（即梦/Lovart）完成 IP 角色的全流程设计：

- 🎯 **角色主视觉**：一句话描述 → 直接出图
- 🌍 **场景延展**：旅游/工作/生活，各种场景一键生成
- 😊 **表情包系统**：9张基础款 + 扩展表情库
- 📦 **品牌全案**：配色/物料/周边/官网全套提示词
- 🤝 **多角色同框**：支持多张参考图同时生成

## 🚀 特性

- **10种画风**：软萌3D / Q版卡通 / 日系漫画 / 扁平插画 / 像素风 / 法式矢量 / 厚涂涂鸦 / 粘土陶瓷 / 写实拟人 / 宝可梦卡牌
- **塔塔默认模式**：3D粘土渲染 + 超广角俯拍 + 夸张透视，从实战中提炼的出图公式
- **双版本输出**：白底抠图版（做封面/贴纸）+ 场景背景版（做图文/传播）
- **智能参考图**：有参考图时不描述外貌，角色一致性更好
- **中文提示词**：全部中文，不混英文，复制即用
- **无CLI也能用**：没装即梦CLI？直接给你提示词，去网页版粘贴生图

## 📋 使用方式

### 最快路径（3步出图）

1. 发参考图 + 说场景（如"这个角色在旅游"）
2. 自动选默认风格（3D粘土）
3. 出图：白底版 + 场景版 + 提示词

### 完整路径（IP全案）

1. 环境检测（有CLI？有参考图？）
2. 选风格（10种可选，默认3D粘土）
3. 角色设定表（配色/比例/服装）
4. 表情包系统（9-24张）
5. 品牌物料（Logo/周边/官网）
6. 批量生图

## 📦 安装

将 `SKILL.md` 放入你的 Cola Skills 目录：

```
~/.cola/mods/default/skills/ip-character-designer/SKILL.md
```

- **即梦 CLI**：`dreamina` 命令行工具（有则直接生图，无则输出提示词）
