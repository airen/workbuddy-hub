这个文档的目的，是让角色在未来生成的插图中保持稳定。档案要说明哪些特征必须一致，哪些可以变化，哪些绝对不能出现。

## 表情动作包前置条件

生成任何单张表情动作参考图之前，必须先满足：

- 已经有用户确认过的三视图。
- 三视图文件作为图像参考输入，而不是只靠 `IP_DNA.md` 文字描述。
- 8 张里的每一张、每一次生成，都必须使用同一张已确认三视图作为图像参考输入，不能只在第一张或第一轮参考。
- 表情动作包数量固定为 8 张，不多不少。
- 8 张必须分别生成和输出为独立单张图片，不能先生成合集、联系表、九宫格、拼贴图或贴纸大图再切分。
- 8 张必须保持同一个背景颜色、同一个角色比例、同一套线条和配色。
- 表情动作图只改变表情、动作和道具，不重新设计角色。
- 如果没有三视图或三视图未确认，必须先回到三视图阶段，不能继续生成表情动作包。

## 首轮分析输出格式

给用户展示第一版草案时，使用这个格式：

```markdown
## 保留的身份锚点
- ...

## 被简化掉的照片细节
- ...

## 需要你确认的地方
- ...

## 第一张正面全身图提示词
...

## 后续三视图提示词
...

## 下一步
下一步我建议：先确认身份锚点，然后生成正面全身确认图。
请你确认：这些身份锚点是否准确？如果不准确，请指出 1-3 个必须修改的地方。
可选方向：
1. 身份锚点准确，继续生成正面全身确认图
2. 先修改身份锚点
3. 补充一张全身照后再判断
```

每次输出都必须带 `下一步` 部分。不要只输出草案或提示词后停住。

## 参考图提示词规则

正面全身确认图：

```text
生成一张正面全身角色确认图，角色居中站立，纯正面视角，从头到脚完整身体可见，必须包含下半身、鞋子/爪子/底部结构。即使原始参考图是头像、半身照或大半身照，最终也必须补全为完整全身角色，不能输出头像、半身或大半身。风格为简约扁平手绘漫画风，暖米白纯色背景，粗一点的深棕手绘描边，低饱和扁平色块，轮廓清晰，不要复杂背景，不要场景化，不要海报感，除可选的小角色名外不要放文字标签。必须保留这个 IP 的身份锚点：<身份锚点>。如果下半身、鞋子或底部结构在原图中不可见，请根据已有服装、比例和风格做保守补全，不要做夸张设计，并在后续说明中标注为需要用户确认。这是一张角色确认图，不是封面，不是剧情插图。最终图必须用图像生成或图像编辑路线，不要用 HTML、SVG、网页截图或幻灯片截图。
```

三视图设定图：

```text
生成同一个 IP 的干净三视图设定图：正面、侧面、背面，三个视图等高排列在暖米白背景上。风格为简约扁平手绘漫画风，粗深棕描边，低饱和扁平色块。必须保持稳定的角色轮廓、头部/发型/身体结构、服装、配饰和颜色锚点。不要额外姿势，不要场景，不要复杂装饰，不要海报感。只允许添加短标签：正面、侧面、背面。
```

表情动作参考图：

```text
生成同一个 IP 的单张表情/动作参考图，必须以上传的三视图作为同一个 IP 的角色参考；8 张里的每一张、每一次生成，都要实际使用同一张已确认三视图作为图像参考输入，不能只在第一张或第一轮参考。严格保持头身比例、整体轮廓、脸部特征、眼睛规则、服装、配饰、颜色锚点和线条风格一致；只改变本张图的表情、动作和道具。这是一张独立单张图片，不是合集的一格，不要联系表、九宫格、拼贴图、贴纸合集、分镜页或任何需要后期切分的大图。只有一个角色，暖米白简约背景，背景颜色必须与其他 7 张一致，粗手绘描边，低饱和扁平色块。必须保留 `IP_DNA.md` 中的所有锁定特征，包括脸部、眼睛、服装、配饰、体型比例和颜色锚点。动作：<一个动作>。情绪：<一个情绪>。可选道具：<一个道具>。不要额外角色，不要复杂背景，不要海报感。
```

## 拒绝规则

出现以下情况时，拒绝或重生成：

- 第一张正面确认图不是完整全身，而是头像、半身或大半身。
- 角色不再像来源中的身份锚点。
- 未经用户确认，出现了从其他 IP 借来的特征。
- 脸部或眼睛规则漂移。
- 服装或标志性配饰发生变化。
- 身体结构看起来混乱或不合理。
- 图像变成海报、封面或场景图，而不是干净参考图。
- 最终图来自 HTML、SVG、canvas、网页截图或幻灯片截图。
- 生成表情动作图时没有使用前一步已确认的三视图作为参考图。
- 只在第一张表情动作图使用了三视图，后续单张没有继续使用同一张三视图作为图像参考。
- 表情动作图看起来像重新设计的角色，而不是沿用三视图中的同一个 IP。
- 表情动作包不是正好 8 张。
- 表情动作包被做成合集、联系表、九宫格、拼贴图、贴纸大图，或需要后期切分。
- 8 张表情动作图的背景颜色、角色比例、线条粗细或配色明显不一致。

## 阶段结束提问模板

正面全身确认图完成后：

```text
下一步我建议：如果这张正面全身图通过，就继续生成三视图。
请你确认：这张角色确认图是否是完整全身，并且可以作为当前 IP 的基础形象？
可选方向：
1. 通过，继续生成三视图
2. 不通过，先修改具体细节
3. 补充一张全身照后重新生成
```

三视图完成后：

```text
下一步我建议：如果三视图通过，就把这张三视图作为后续所有表情动作图的角色参考，再继续生成 8 张独立单张表情动作参考图。
请你确认：三视图里的正面、侧面、背面是否一致，并允许我把它作为表情动作包的固定参考图吗？
可选方向：
1. 通过，使用当前三视图作为参考继续生成 8 张独立单张表情动作包
2. 不通过，先修正三视图
3. 补充伴随角色三视图
```

表情动作包完成后：

```text
下一步我建议：把当前 IP 档案整理成可交给下游漫画信息图技能使用的档案包。
请你确认：现在是直接打包，还是替换不合格的单张表情图？
可选方向：
1. 直接打包交接
2. 替换不合格的单张表情图，仍然保持总数 8 张
3. 增加伴随角色
```

最终档案包完成后：

```text
下一步我建议：用这个 IP 档案试跑一篇文章插图，验证角色稳定性。
请你确认：下一步要做什么？
可选方向：
1. 接入下游漫画信息图技能试跑文章
2. 继续优化当前 IP 档案
3. 为另一个新 IP 建档
```
