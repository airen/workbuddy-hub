# 小红书种草打法工具包

把产品/品牌做成可投放的笔记矩阵，四步闭环：诊断 → 策略 → 执行 → 复盘。

## 何时用本技能

- 要写种草笔记、定内容方向、设计达人配比
- 要规划投放排期与预算分配
- 要判断某条内容是否触碰平台红线（限流词、未报备商单）
- 要复盘投放数据、归因爆款因素

不适用于：已经排好产线的图文排版（那是 `media-content-team` 的活）。

## 四个交付物（对应 references/）

| 文件 | 交付什么 | 什么时候读 |
|---|---|---|
| `references/note-templates.md` | 爆款笔记结构模板：标题公式、封面规范、正文四段式、标签配比 | 写笔记前 |
| `references/launch-schedule.md` | 三阶段投放排期表：KOC/KOL 层级、篇数、预算 | 定投放计划时 |
| `references/compliance-rules.md` | 平台合规红线：蒲公英报备、限流词、真实感要求 | **发布前必读** |
| `references/review-metrics.md` | 数据复盘：核心指标与爆款归因 | 投完复盘时 |

## 工作流程

1. **先诊断再动手**：分析品牌现有声量（搜索量、笔记数、评论情感）→ 研究竞品打法 → 明确目标人群画像
2. **定策略**：确定内容方向与核心卖点 → 搭达人矩阵（头部造势 + 腰部种草 + 素人铺量）→ 规划时间线与预算
3. **写内容**：按 `note-templates.md` 的标题公式与正文四段式产出；达人合作则产出 brief 并审核初稿
4. **过合规**：逐条对照 `compliance-rules.md`——医疗/金融等特殊行业需额外审核；达人合作必须走蒲公英报备
5. **排投放**：按 `launch-schedule.md` 三阶段铺量，预热期 KOC 铺、集中期 KOL 打、长尾期持续补素人
6. **复盘**：追踪曝光量、互动率、收藏率、搜索增量；归因爆款因素并沉淀成可复用公式

## 硬规则

- **合规优先于效果**：不用违禁词与敏感词、不刷量不买赞、达人合作必须蒲公英报备——踩线会导致限流甚至账号降权，比不发更糟
- **真实感是平台核心调性**：种草内容必须基于真实体验，不夸大不虚构；图片不过度修饰；测评要客观，适当提缺点反而更可信
- **配比遵循 20/10 原则**：发布节奏保持算法活跃度但不过度刷屏，发布后 2 小时内积极互动拉初始曝光
- **只出方案不代发**：本技能产出笔记、brief 与排期表，不执行发布动作
