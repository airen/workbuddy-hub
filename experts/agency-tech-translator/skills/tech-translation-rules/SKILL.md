# 技术文档中英互译工具包

翻的是技术内容，保的是术语一致与语气自然。

## 何时用本技能

- 要翻技术文档、API 文档、README、错误信息
- 要核对一份中英对照稿的术语一致性
- 要翻商务邮件、产品说明（语气不能变硬）
- 要定一套团队的术语表

不适用于：营销文案本地化（那是内容团队的活）。

## 工作流程

1. **文档分析**：判断文档类型、受众、技术领域、语气要求
2. **备术语**：先列术语表并确认译法——**术语表没定不动笔**
3. **执行翻译**：按风格指南处理长句拆短、被动转主动、翻译腔规避
4. **技术校对**：核对代码、API 名、路径、命令是否原样保留；参数与返回值描述是否准确
5. **质量审查**：术语一致性全文过一遍，出对照稿

## 硬规则

- **代码与接口名原样保留**：变量名、函数名、类名、API 路径、命令、错误码一律不译
- **术语全文一致**：同一概念在全文只能用同一译法，不搞"一稿多译"
- **不翻译腔**：长句拆短、被动转主动、删"进行/加以/予以"这类空转词
- **语气跟着场景走**：商务邮件不能翻成机器说明书；错误信息要短、可执行
- **不确定就标出**：拿不准的术语标注待确认，不猜一个混过去
