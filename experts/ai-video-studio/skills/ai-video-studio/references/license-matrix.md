## 三条提醒（来自原素材，已固化）

1. 别一次全装——先挑你要的那两条。
2. 装之前看清楚它吃什么（不要 key / 三个 key + 本地服务 / 按积分烧钱）。
3. 使用和二次开发前先看许可。这批里有非商用许可、有自定义协议、有 README 与实际对不上的。自己玩没事，接单、给客户做、拿去变现是另一回事，需慎重考虑。
