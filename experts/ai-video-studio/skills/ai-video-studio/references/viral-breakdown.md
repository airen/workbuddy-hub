# 爆款拆解（无 skill 可装，但套路可拆）

清单之外有两个号没开源 skill，但值得停下来看它们怎么做的。说明同一件事：**爆款的底层是一套能重复的套路——先有人把套路跑通，才有后面这些 skill 把它固化下来。**

---

## 一、古风武侠英语剧（月涨粉 5 万）

把英语单词塞进 80 年代邵氏武侠的壳里，一句台词一个词。

- **例子**：`pig out` =「狼吞虎咽」，就拍一个人站在猪圈边上——画面和字面意思拧着，才记得住。
- **结构（固定得像零件）**：10 秒 4 个镜头，每个 2.5 秒——出场、反转、揭晓、尴尬收尾。
- **做旧那层**：胶片颗粒 + 褪色 + 老歌底噪，顺手盖掉 AI 生成的小瑕疵。
- **做法（三步）**：豆包出脚本 → Seedance 2.0 Fast 出片 → 剪映配双语字幕。熟了以后一条 5–10 分钟。
- **变现**：单词卡、教材带货、打卡营；同一套壳还能搬去 TikTok 教中文。

**可复用套路**：固定镜头模板（4 镜头 × 2.5s）+ 字面义与画面反差 + 做旧掩盖 AI 瑕疵 + 壳可跨平台搬运。

## 二、AI 治愈号「小蘑菇秃秃」（五个月吸粉 200 万）

一个圆乎乎的角色，在木色厨房里做应季甜点，配白噪音。

- **卖的不是信息，是情绪**：前几秒先给「软、萌、治愈」，据称完播率能到 45% 以上。
- **做法**：先用**三视图定妆图**把角色定死 → 导演模式提示词拆 8 个镜头、**不要人手人脸** → 图生视频 → 进剪映把 BGM 压到 20%，让 ASMR 扛住大半听感。
- **变现（更软）**：家居品牌植入、挂小黄车卖木质餐具、IP 授权做表情包；同样能搬去 TikTok 和 YouTube Shorts。

**可复用套路**：三视图定妆图锁定 IP → 无手无人脸的镜头拆分 → 用环境音（ASMR）压过 BGM → 情绪先于信息 → 软变现（植入 / 小黄车 / IP 授权）。

## 给用户的可操作建议

当你想做类似号、但找不到对口 skill 时：

1. 先把上面两个号的「可复用套路」拆成自己的固定模板（镜头数、时长、角色定妆、做旧方式、声音配比）。
2. 用 WorkBuddy 的写作 / 绘图能力把**脚本、分镜、定妆图提示词**先写出来（本专家 `ai-video-studio` 可承接这层上游）。
3. 出片交给通用视频技能（如 Seedance / 即梦 / ImageGen + 图生视频）或上面目录里的对口 skill。
4. 套路跑通、数据验证后，再决定要不要把它**固化成你自己的 skill**——按原素材建议，安装后结合你的审美重新定制，才是最符合你要求的 skill。
