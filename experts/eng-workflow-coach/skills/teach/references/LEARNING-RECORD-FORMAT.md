# 学习记录格式（Learning Record Format）

学习记录存放在 `./learning-records/`，使用连续编号：`0001-slug.md`、`0002-slug.md` 等。按需创建目录：只在写下第一条记录时才创建。

它们是教学版的 ADR：记录那些不那么显然的教训、关键洞见，以及用户自述的已有知识，用来指引未来的会话。它们被用来计算最近发展区（zone of proximal development）。

## 模板

```md
# {学到或确立的东西的简短标题}

{1–3 句话：学到了什么（或确立了哪些已有知识），以及为什么它对未来的会话重要。}
```

这就是全部格式。一条学习记录可以只有一段话。价值在于记录**这件事**现在已知，以及**为什么**它改变了接下来该教什么，而不在于把各个小节填满。

## 可选小节

只在它们能带来真正价值时才包含。大多数记录都不需要它们。

- **Status** frontmatter（`active | superseded by LR-NNNN`）：当早期的理解后来被证明是错的并被替换时，很有用。
- **Evidence**：用户是如何表现出这份理解的（回答了一个问题、完成了一项练习、引用了过往经验）。当这个结论可能被重新审视时有用。
- **Implications**：这为未来的会话解锁了什么或排除了什么。当它不那么显然时值得记录。

## 编号

扫描 `./learning-records/`，找到现有的最大编号，加一。

## 什么时候写一条学习记录

当以下任意一条成立时写一条：

1. **用户表现出对某件非平凡事物的真正理解**：不只是接触过，而是有证据表明他能正确使用这个概念。这为接下来该教什么设定了新的下限。
2. **用户透露了已有知识**：「我已经知道 X 了。」把它记下来，免得未来的会话重复教它。同时记录他声称的**深度**。
3. **一个误解被纠正**：用户之前相信某个错误的东西，现在明白了为什么错。这些是高价值的：它们能预示相关主题上未来的绊脚石。
4. **任务书因学习而发生移动**：用户发现自己在乎的东西和原先以为的不一样。交叉链接到 [[MISSION.md]] 并更新它。

### 什么**不算**

- 仅仅被覆盖过的材料。覆盖不等于学习。等证据。
- 任何已经以术语定义的形式简洁记录在 [[GLOSSARY.md]] 里的东西。不要重复。
- 逐次会话的活动日志。学习记录不是日记：它们是决策级别的洞见。

## 取代（Supersession）

当后来的记录与更早的记录矛盾时（用户的理解加深或纠正了），把旧记录标记为 `Status: superseded by LR-NNNN`，而不是删掉它。理解如何演变的历史本身就是有用的信号。
