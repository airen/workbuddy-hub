# 阶段边界（Phase boundaries）

一个**阶段（phase）**是会话里的一块工作：访谈、实施、QA。它的定义故意模糊：当你心想*「好，这件事做完了」*时，一个阶段就结束了。

**阶段边界（phase boundary）**是两个阶段之间的空隙，而这个决策只属于那里。阶段中途没有决策可做：要么继续，要么把剩下的工作拆成子代理（用 Agent 工具）。在阶段中途做 compact（压缩上下文）会让代理丢失线索。

## 五个选项

| 选项 | 它做什么 |
| --- | --- |
| **继续（Continue）** | 留在会话里。完全不切换上下文。 |
| **`/clear`（清空）** | 清空上下文窗口，从零开始。 |
| **`handoff`** | 写出一个可携带的 markdown 文件，用它把会话播种到任何地方。 |
| **子代理（用 Agent 工具）** | 把任务送到它自己的上下文窗口，拿一份报告回来。 |
| **`/compact`（压缩）** | 压缩当前上下文，并用摘要给一个全新会话播种。 |

## 决策树

在边界上从上往下走。第一个**是**获胜。

**1. 你能在这个会话里继续吗？** 有两件事让答案成为「是」：下一个阶段需要这个阶段作为**一手来源（primary source）**，或者你剩下的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k token）还够下一个阶段装得下。访谈 → 实施就是标准的「是」：实施想要的是推理的原文，而不是它的摘要。继续不花成本、不丢东西，所以先把它之外的一切排除掉。

**2. 这些上下文跟接下来要做的事无关吗？** 这个会话里的一切（探索、决策、死路）都是可丢弃的吗？如果是，就 **`/clear`（清空）**。它是棋盘上最便宜的一步：不花时间，还回整个窗口。`/clear` 也不是终结性的：旧会话仍可恢复。

把这一步做错的代价是单向的。清掉一个*相关*的上下文，你就丢掉了你造出的东西背后的**为什么（why）**，而再多的「把 diff 读回来」也换不回它。

**3. 你需要移交吗？** `handoff` 的用途很窄。只有当你处于以下情形时才需要它：

- 换到一个**新的 harness**（Claude → Codex），
- 搬到**新目录**或新仓库，
- 把工作发给一位**同事**，
- 或者**在阶段中途**分叉出一个支线任务、又不打乱你手头在做的事。

这份清单就是全部条款。`handoff` 买到的是**可携带性**：一个能旅行的文件。如果没有东西在旅行，你就不需要它。

**4. 这个任务能 AFK 完成吗？** 它的范围收得够紧，能在你离开键盘、无人操舵的情况下跑吗？那就把它送到一个**子代理（用 Agent 工具）**，让这个会话原封不动。自动化评审是标准场景：代理读 diff 并汇报，它做这件事时不需要你。

**5. 否则，就 `/compact`（压缩）。** 相关的上下文、同一个 harness、同一个目录，而你需要留在回路里：这就是这棵树落点的地方，而且它经常落在这里。给它传一条指令（`/compact we're going to QA this area`），让摘要保住下一个阶段需要的东西。

`/compact` 是**默认选项，不是第一伸手去够的那个**。它坐在底部，是因为它上面的四个问题都更便宜或更精确。人们从它开始的失败模式，是一个全新会话对一个被摘要压平的决策自信地判断错误。

## 一手来源与二手来源

除了**继续**之外的每一步，都把一份**一手来源（primary source）**变成一份**二手来源（secondary source）**：实际发生过的那个会话，被它的摘要取代。这笔交易永远是同一种形状：

| 来源 | 信息 | 噪声 | 活动空间 |
| --- | --- | --- | --- |
| 一手（继续） | 完整 | 多 | 小 |
| 二手（`/compact`、`handoff`） | 有损 | 少 | 大 |

这就是为什么问题 1 排在第一位。只有当「留下」的代价超过它节省的，你才付这份有损的账。

## 这些是判断性取舍

这些问题不是客观的：每一个里面都有品味，同一个边界在不同日子可能走两个方向。它的价值在于**按顺序**问它们，在边界上问，而不是在活儿做到一半时问。
