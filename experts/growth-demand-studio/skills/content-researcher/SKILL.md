# 内容研究与长文撰写

先研究素材，再按你的表达习惯起草长内容。**每个关键说法都要有出处。**

## 适用场景

- 要写一篇有分量的博客 / 通讯 / SEO 文章
- 把短内容（如一条推文的观点）扩展成长文
- 需要 SEO 内容，但不能是空话堆砌
- 想让 AI 写出来的东西像自己写的

## 输入

- 主题与目标读者
- 已有的素材（一手经历、数据、链接）
- 参考的文风样本（几段你自己写的东西）
- 篇幅与平台要求

## 执行步骤

### 步骤 1 — 先学语气，再动笔

读用户提供的样本，提炼出可执行的特征：

- 句子长度（短句为主还是长句多）
- 用什么人称，是否用"我"
- 怎么给例子（讲故事还是列数据）
- 怎么转折（"但是""不过""问题是"）
- 有没有口头禅或固定结构

写成一张**风格卡片**，写作时对照。不学语气就写，产出一定是"AI 味"。

### 步骤 2 — 收集证据，分级

按可信度排：

| 级别 | 来源 | 用法 |
|---|---|---|
| 一手 | 自己的经历、后台数据、原始记录 | 优先使用 |
| 官方 | 官方文档、公告、财报 | 可直接引用 |
| 权威第三方 | 研究报告、统计机构 | 引用需注明时间与口径 |
| 二手转述 | 别人文章里的说法 | **必须回溯到原始出处**，否则不用 |

近期信息（价格、版本、排名、新闻、平台规则）**必须联网核验**，不凭记忆。

### 步骤 3 — 区分事实、判断、推断

写的时候在心里分三类，并在文中体现：

- **事实**：可核实，给来源
- **判断**：有理由，说明理由
- **推断**：不确定，明确说"这可能是……，待验证"

不把推断写成结论。

### 步骤 4 — 搭结构

长文常用结构：

```
开头：一个具体场景或反常识的判断（不要"随着…的发展"）
主体：3～5 个分论点，每个都有证据 + 例子
转折：这个说法什么时候不成立
结尾：读者能带走的具体动作
```

**"什么时候不成立"这一节不能省。**没有它，文章就是推销。

### 步骤 5 — 写并自检

写完按这张表自查：

- [ ] 每个关键数字有来源吗
- [ ] 事实 / 判断 / 推断标清了吗
- [ ] 语气符合风格卡片吗
- [ ] 有没有"随着…的发展""综上所述"这类空话
- [ ] 有没有编造的例子、用户评价或体验
- [ ] 读者能带走什么具体动作

### 步骤 6 — 附来源清单

文末列出参考来源，可点击。**拿不到证据的部分单独列"待核实"，不混进正文当事实。**

## 输出

- 成稿（按目标篇幅）
- 来源清单（可点击）
- 事实 / 判断 / 推断的标注说明
- 待核实项列表

## 反模式

- **不学语气就写**：产出一眼 AI
- **用二手转述当证据**：错会被一起转述
- **把推断写成结论**：读者会当事实引用
- **编造例子与用户评价**：这是硬红线
- **只写优点不写局限**：可信度反而下降
- **没有来源清单**：无法核实，也无法维护
