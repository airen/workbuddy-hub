# 转化与营销手册

覆盖转化率优化（CRO）、文案和邮件流程的一套打法。

> 不写"提升转化率"这种话。每个动作都要对应漏斗里的**具体一步**和**可衡量的变化**。

## 适用场景

- 落地页有流量但不转化
- 需要搭建邮件序列（欢迎、激活、召回）
- 注册后流失严重
- 增长动作太多，需要排优先级

## 输入

- 当前漏斗数据（各环节转化率，有的话）
- 产品与目标用户
- 已有的页面 / 邮件内容
- 可动用的资源（能否改页面、能否做 A/B）

## 执行步骤

### 步骤 1 — 先定位漏在哪一环

把漏斗拆开，找出转化率最低的那一环：

```
访问 → 理解价值 → 产生兴趣 → 开始行动（注册/加购）→ 完成 → 留存/复购
```

**不定位就优化，等于在所有环节上平均用力。**先补数据，数据没有就先埋点或用最小手段估一个。

### 步骤 2 — 按环节选打法

| 环节 | 常见打法 | 衡量指标 |
|---|---|---|
| 理解价值 | 首屏一句话主张、社会证明 | 跳出率、首屏停留 |
| 产生兴趣 | 卖点具体化、场景演示 | 滚动深度、点击分布 |
| 开始行动 | 降低起步成本（免注册试用、减少表单字段） | 注册转化率 |
| 完成 | 减少步骤、明确的错误提示 | 完成率 |
| 留存复购 | 激活邮件、关键行为引导 | 次留、复购率 |

### 步骤 3 — 改落地页

- 首屏一句话说清"是什么、给谁、带来什么结果"
- **一个主行动**，不并列两个大按钮
- 表单字段能少一个就少一个（每多一个字段都掉一层转化）
- 社会证明必须真实：没有客户名就用真实数据，没有数据就删掉这一块
- 移动端单独检查：拇指区域、输入框类型、按钮大小

### 步骤 4 — 搭邮件序列

按生命周期分序列，每序列 3～5 封：

| 序列 | 目标 | 触发 |
|---|---|---|
| 欢迎 | 让新用户完成第一个关键行为 | 注册后 |
| 激活 | 让沉默用户回来完成关键行为 | 注册后 N 天未激活 |
| 召回 | 唤回流失用户 | 长期未活跃 |

每封邮件只求一个动作。写清：发给谁、什么时机、主题、正文要点、唯一 CTA。

### 步骤 5 — 排优先级

按 **影响面 × 实施成本** 排序，先做低成本高影响的：

1. 首屏主张改写（成本极低）
2. 表单字段精简（成本低）
3. 邮件序列补上（成本中）
4. 页面重构（成本高，最后做）

### 步骤 6 — 设衡量方式

每个动作写清楚：看哪个指标、多长时间、达到什么算有效。**不能衡量的动作不做。**

## 输出

- 漏斗诊断：哪一环最弱，依据是什么
- 改进清单（按优先级，每项含预期指标）
- 落地页改动说明（首屏、表单、社会证明）
- 邮件序列（触发、主题、要点、CTA）
- 衡量方式与观察周期

## 反模式

- **不定位就全面优化**：力气分散，看不出效果
- **编造社会证明**：假客户名和数据在成交环节会露馅
- **两个主行动按钮**：用户会两个都不点
- **邮件塞多个 CTA**：打开率转化为零
- **不做移动端检查**：多数流量在移动端
- **动作不可衡量**：无法判断该继续还是停
