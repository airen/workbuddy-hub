# 起名与域名检查

提出名字，同时检查对应域名是否可用。**名字和域名一起定，不要分两步。**

## 适用场景

- 新产品 / 新项目要起名
- 名字想好了，要确认域名
- 需要一批备选，逐个筛
- 要检查商标与社媒账号名的一致性

## 输入

- 产品是什么（一句话）
- 目标市场与语言（中文 / 英文 / 双语）
- 偏好：后缀（.com / .cn / .io）、长度、风格（造词 / 组合词 / 描述性）

## 执行步骤

### 步骤 1 — 先定命名方向

| 方向 | 例子思路 | 特点 |
|---|---|---|
| 描述性 | 直接说做什么 | 好懂，域名难拿 |
| 组合词 | 两个常见词拼起来 | 折中，最常用 |
| 造词 | 自造音节 | 域名好拿，需要解释成本 |
| 隐喻 | 借一个意象 | 有记忆点，可能不好懂 |

### 步骤 2 — 批量出候选

一次出 10～15 个候选，按方向分组。**不要只出三个还都差不多。**

每个候选标注：读音难度、是否有歧义（尤其在目标市场的其他语言里）、大概长度。

### 步骤 3 — 查域名可用性

对每个候选检查：

- 主后缀（如 .com）是否可注册
- 备选后缀（.cn / .io / .co）价格与可用性
- 是否被占但正在出售（价格通常很高，直接排除）

**可用性以实际查询为准，不凭印象。**查不到就说查不到，不要猜。

### 步骤 4 — 查一致性

同一个名字在主要社媒平台、应用商店的账号名是否可用。名字定了但账号名被占，是常见的后续麻烦。

### 步骤 5 — 商标与风险提醒

- 提醒进行商标检索（本技能不做法律判断）
- 避开与已知品牌近似的名字
- 目标市场语言里是否有负面含义

### 步骤 6 — 出推荐

给 3 个推荐，各说明：为什么适合、域名情况、风险点。

## 输出

- 候选清单（含方向分组与说明）
- 域名可用性查询结果（以实际查询为准）
- 社媒账号名一致性
- 3 个推荐与各自风险
- 商标检索提醒

## 反模式

- **先定名字再查域名**：名字喜欢但域名被占，被迫改成奇怪的拼写
- **可用性凭印象**：域名状态变化快，必须实查
- **只查 .com**：备选用不上等于没有备选
- **忽略社媒账号名**：后期改名成本极高
- **不做商标提醒**：这是法律风险，必须提示（但不替代专业检索）
- **只出三个候选**：筛选空间不足

## 参考

- 域名与价格随时变动，交付时必须标注查询时间与"以注册商实时结果为准"。
