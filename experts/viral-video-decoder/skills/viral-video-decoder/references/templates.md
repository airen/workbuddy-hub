- 拆解深度：<lite / standard / deep>

## 一、结构层（Hypit SVML 摘要）

- 关键 Role Cue：< >

## B. 可复用套路模板（核心交付物）
```markdown
# <套路名> 模板
- 适用平台：< >
- 适用选题：< >
- 固定结构：<镜头数 × 单镜时长，如 4 镜 × 2.5s>
- 开场钩子句式：< >
- 情绪节拍：<平 → 起 → 落 → 反转>
- 视觉配方：<景别 / 色调 / 做旧 / 母题>
- 声音配比：<BGM % / ASMR / 人声>
- 字幕策略：<落点词 / 金句秒数>
- 变现 / 传播：<挂车 / 植入 / IP / 接梗>
- 变体提示：<可换的主题 / 平台>
```

## C. SVML → 模板 映射示例（古风武侠英语剧，公开案例）
- Segment：10s = 4 镜 × 2.5s（出场 / 反转 / 揭晓 / 尴尬收尾）→ 模板固定「4 镜 × 2.5s」。
- Role Cue：一人一镜一单词，画面与字面反差 → 模板「字面义 × 画面反差」。
- 视觉：胶片颗粒 + 褪色 + 老歌底噪做旧 → 模板「做旧掩盖 AI 瑕疵」。
- 平台：同一壳可搬 TikTok 教中文 → 模板「壳可跨平台」。

> 案例仅作映射示范，方法论来自本项目与 MIT 项目；实际拆解以当前视频产物为准。

## D. 交付节奏建议
1. 先给「结构层摘要 + 八维分析」→ 让用户确认理解无误。
2. 再给「可复用套路模板」→ 让用户直接拿去用。
3. 最后问是否要做变体 / 回流 Hypit 出片。
