# 研究证据协议

本技能是「深度研究专家团」的共用方法论。任一角色——采集、清洗、归档、核验、撰稿——在动手前都应该按本协议的口径做事，否则各环节的产出无法互相对齐。

## 一、四条不可协商的底线

1. **无来源不成事实**：任何被当作事实陈述的内容，必须能指回一个真实可点击的出处。
2. **溯源信息不可丢**：URL + 抓取时间 + 原文位置，三者缺一即视为该条材料作废。
3. **强度与措辞必须匹配**：A 级才说「证实」，B 级说「倾向于」，C 级说「有来源称」，D 级不用。
4. **说不清就说说不清**：证据不足时，写「证据不足」并说明缺什么，禁止用听起来合理的话顶上。

## 二、证据强度四级

详细判定与边界案例见 `@references/evidence-grading.md`。

| 等级 | 定义 | 可用措辞 | 能否单独支撑结论 |
|------|------|---------|----------------|
| **A 强** | 一手原始来源：官方公告、原始数据、法规原文、当事人原话、原始论文 | 「已证实」「数据显示」 | ✅ 可以 |
| **B 中** | 权威二手来源转述一手内容，且能定位一手出处 | 「倾向于」「据 X 报道」 | ⚠️ 需配 A 级或明确标注 |
| **C 弱** | 三手来源（聚合、百科、自媒体、匿名爆料）、无出处、孤证 | 「有来源称」「有说法」 | ❌ 仅作线索 |
| **D 不可用** | 断链、无法验证、明显曲解原文、来源不可靠 | 不引用 | ❌ 剔除 |

**降级规则**（满足任一条即降一级）：
- 时间戳已过期而问题要求现状
- 关键限定条件被抹去（如原文「特定条件下」）
- 只有单一来源且无独立印证
- 口径与本研究不一致（如"用户数"定义不同）

## 三、来源类型可信度速查

完整矩阵见 `@references/source-credibility.md`。

| 来源类型 | 起步等级 | 说明 |
|---------|---------|------|
| 官方公告 / 法规原文 / 标准文档 | A | 注意核对是否已被新版替代 |
| 原始数据集 / 一手调研 / 原始论文 | A | 检查采样方法与样本量 |
| 当事人公开原话（有原始视频/文字记录） | A | 警惕剪辑与摘录失真 |
| 主流媒体原创报道（含采访与具名来源） | B | 需回溯其引用的原始出处 |
| 行业研究报告（署名机构、可查方法） | B | 警惕利益相关方的选择性口径 |
| 媒体转述其他媒体的报道 | C | 追到源头才能升级 |
| 百科 / 聚合站 / 内容农场 | C | 只用于找线索，不可作为论据 |
| 自媒体 / 匿名爆料 / 截图传播 | C | 除非有可验证的原始记录 |
| 无出处的「据说」「业内普遍认为」 | D | 剔除 |
| 404 / 无法打开的页面 | D | 有存档副本可重新评估 |

## 四、引用格式规范

**正文引用（Markdown）**：

```markdown
[论断文字] [E-001]

- **证据**：「[逐字摘录，≤200 字]」
- **来源**：[可点击的完整 URL]（发布于 YYYY-MM-DD，抓取于 YYYY-MM-DD）
- **强度**：A / B / C
- **口径说明**：[若与本研究口径不同，在此说明取值与理由]
```

**硬性要求**：
- URL 必须是**完整、可直接点击**的，不写「见某网站」「来源：网络」
- 摘录必须**逐字**，允许用「…」省略，不允许润色后加引号
- 概括的内容不放进引号，并明确标为「概括」
- 同一论断有多个来源时，主来源在前，旁证在后
- 引用附件/文档时给出页码或章节号（如 `p.37 §3.2`）

## 五、三类难处理材料

| 情况 | 处理方式 |
|------|---------|
| **断链 / 404** | 查网络存档副本；无副本则降为 D 级并剔除，在未解决项里说明 |
| **时效过期** | 保留但标「截至 YYYY-MM 的数据」；若问题要求现状，降级并注明需找更新来源 |
| **口径冲突** | 不同来源对同一指标定义不同时，并列呈现并说明分歧，**禁止直接并算** |

## 六、提交前自查清单

交付报告或证据台账前，逐条打勾：

- [ ] 每条结论都有 `[E-0xx]` 引用，没有「裸论断」
- [ ] 所有引用 URL 都是完整可点击的
- [ ] 逐字摘录与原文对照过，没有断章取义
- [ ] 措辞强度与证据等级匹配（没有把 C 级写成「研究表明」）
- [ ] 已主动搜索过反面证据，并在报告中呈现
- [ ] 过期数据已标注时间范围
- [ ] 口径冲突已说明，没有把不同定义的数字并列
- [ ] 未解决项单列成章，写清了「缺什么、影响什么、下一步查什么」
- [ ] 没有引用无法验证或已失效的来源
- [ ] 报告中的每条判断都能在溯源附录里找到对应出处

## 八、常见坑

1. **只找支持自己的材料**：这是研究事故，不是研究。每个子问题都要主动搜反方。
2. **把二手当一手**：媒体说「据官方数据」，真正的证据在官方那里，要去点开。
3. **数字堆砌但不知口径**：三个来源三个数，先问它们各自在数什么。
4. **摘录润色**：为了让句子通顺而改原文，就是曲解。
5. **拿孤证下结论**：单一来源需降级处理，除非它本身就是权威一手。
6. **结论强度拔高**：越是想让报告好看，越容易把「可能」写成「必然」。
