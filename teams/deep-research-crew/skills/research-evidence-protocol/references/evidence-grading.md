# 证据强度分级细则

## 分级判定流程

对每一条材料，按顺序问四个问题，取**最低**的一档：

```
Q1 这条材料是原始来源吗？
   ├─ 是（官方/一手数据/原文/当事人原话）→ 候选 A
   └─ 否（转述、聚合、二手）→ 候选 B 或 C，跳到 Q3

Q2 原始来源当前可访问、且是最新版本吗？
   ├─ 是 → 保持 A
   └─ 否（链接失效/已被新版替代）→ 降一级

Q3 转述者是否具备独立核实能力？（具名采访、可查方法、有编辑责任）
   ├─ 是 → 候选 B
   └─ 否 → 候选 C

Q4 它引用的原始出处能定位到吗？
   ├─ 能定位且与转述一致 → 保持 B
   └─ 定位不到 / 与转述不一致 → 降为 C
```

最后叠加**降级规则**（见 SKILL.md 第二节），得出最终等级。

---

## A 级：可单独支撑结论

**特征**：材料本身就是事实的发生现场。

| 类型 | 示例 | 核验要点 |
|------|------|---------|
| 官方公告 / 通知 | 政府部门发布的政策原文 | 确认是官网原文而非媒体转述；核对生效日期 |
| 法规 / 标准原文 | 国家标准全文、法律法规条文 | 确认版本号是否为现行版本 |
| 原始数据 | 官方统计库、企业财报原始披露、平台公开 API 返回值 | 记录抓取时间；确认统计口径 |
| 原始论文 | 期刊全文、预印本 | 核对样本量、发表状态（是否已被撤稿） |
| 当事人原话 | 有完整视频/录音/文字记录的公开表态 | 警惕剪辑；优先找完整版 |
| 一手调研 | 自己或委托方按可查方法做的调查 | 方法必须可复现 |

**A 级的常见伪影**：
- 「官网转载的媒体报道」→ 不是 A，是 B
- 「企业新闻稿中的数据」→ 是 A 但属利益相关方数据，需在口径说明里标注
- 「截图」→ 不是 A，截图本身可伪造，需找到原始发布位置

---

## B 级：可作旁证，需配 A 级或显式标注

**特征**：有核实能力的中间人转述了一手内容，且能追到源头。

| 类型 | 示例 | 核验要点 |
|------|------|---------|
| 主流媒体原创报道 | 含具名信源、记者署名的报道 | 回溯它引用的原始文件/数据 |
| 行业研究报告 | 署名机构、公开方法论 | 检查是否利益相关方；看样本是否代表目标人群 |
| 第三方数据服务商 | 有明确采集方法的榜单/指数 | 检查采样范围与更新频率 |
| 权威人物公开评述 | 专家具名分析（非原始数据） | 这是观点不是事实，措辞需用「认为」 |

**升级路径**：找到转述内容的一手出处 → 该条可升级为 A，原转述保留为旁证。

---

## C 级：仅作线索

**特征**：经过两次以上转手，或无法核实。

- 媒体转述其他媒体的报道（且都定位不到原始出处）
- 百科、聚合站、内容农场
- 自媒体文章、匿名爆料、社群传播的截图
- 单一来源且无任何独立印证的数据
- 时间不明的材料

**使用限制**：可用于「值得进一步查证的方向」，不得单独作为结论依据。报告中必须用「有来源称」而非「研究表明」。

---

## D 级：必须剔除

- 链接失效（404、域名过期）且无存档副本
- 内容与引用的论断明显不符（曲解、断章取义）
- 来源不可靠且无任何可验证特征
- 抄袭/洗稿内容农场，原始出处不可考
- 已被官方辟谣但仍在传播的说法（可引用其「已被辟谣」这一事实，但不能引用其原始说法）

---

## 容易判错的边界案例

| 场景 | 正确判级 | 理由 |
|------|---------|------|
| 某公司官网新闻稿称「市场占有率第一」 | A 级材料，但不可直接引用为行业事实 | 来源是一手，但属利益相关方主张，需第三方印证 |
| 主流媒体报道「据知情人士透露」 | C | 无具名、无法核实 |
| 论文预印本（未经同行评审） | B | 方法可见但结论未定稿，需注明未评审 |
| 政府部门发布的解读文章（非文件原文） | B | 是官方解读，但不是条文本身 |
| 电商平台显示的销量数字 | B 级偏 A，但需注明口径 | 平台一手数据，但"销量"定义与统计方式需说明 |
| 已过期的年度统计（问题问的是现状） | 降级 + 标注时间 | 数据本身可信，但对当前问题失去支撑力 |
| 有网络存档的失效页面 | C（原 A 则降为 B） | 内容可核但无法验证其是否被后续修改 |

## 分级结果怎么写

台账里每条至少给出：

```
等级：B
理由：主流财经媒体（具名记者）报道，引用了企业 Q3 财报原文，
      财报链接可访问；本条目为媒体转述，可按财报原文升级为 A。
限制：媒体对"会员数"采用的是"累计注册"口径，与本研究"月活"口径不同。
```

**只写等级不写理由，等于没分级。**
