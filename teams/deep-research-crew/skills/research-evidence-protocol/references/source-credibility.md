# 来源可信度矩阵

用于在采集与核验阶段快速判断一类来源的起步等级与需要额外核实的点。

## 按来源类型的起步等级

| 来源类型 | 起步等级 | 必须额外核实 |
|---------|---------|------------|
| 政府 / 监管部门官网 | A | 是否为现行版本；是否已被新规替代 |
| 国际组织官方文件 | A | 版本与年份；是否草案 |
| 法律法规数据库 | A | 现行有效性；地方与中央的差异 |
| 企业官方财报 / 招股书 | A | 会计口径；审计意见是否为保留意见 |
| 企业新闻稿 / 官方博客 | A（利益相关） | 不能单独作为行业事实，需第三方印证 |
| 官方统计数据库 | A | 统计口径；是否为初步数 |
| 同行评审论文 | A | 是否已撤稿；样本量与结论适用范围 |
| 预印本 | B | 未经同行评审，须注明 |
| 一手访谈 / 原始记录 | A | 记录完整性；是否经剪辑 |
| 主流媒体原创报道 | B | 是否具名信源；回溯其引用的一手材料 |
| 通讯社通稿 | B | 通稿可能被各媒体改写，优先用原始通稿 |
| 行业研究机构报告 | B | 出资方；方法论；样本代表性 |
| 咨询公司白皮书 | B（利益相关） | 常服务于自身业务，注意口径选择 |
| 第三方监测/榜单平台 | B | 采样范围；更新频率；是否含广告位 |
| 大学出版社 / 教科书 | B | 内容可能滞后于最新研究 |
| 百科类站点 | C | 只能用于找线索；务必查其引用来源 |
| 聚合 / 内容农场 | C | 常见洗稿，原始出处不可考 |
| 自媒体文章 | C | 无编辑责任；须回溯原始事实 |
| 匿名爆料 / 社群截图 | C | 截图可伪造，需找到原始发布位置 |
| 论坛 / 问答社区 | C | 个人经验不具代表性 |
| 电商商品页参数 | B | 商家自填，可能存在夸大 |
| AI 生成内容 | D | 不可作为来源；若必须提及须明确标注为 AI 生成 |
| 无出处的「据说」「业内普遍认为」 | D | 无法核实 |
| 链接失效且无存档 | D | 有网络存档可重新评估 |

## 三条通用加权规则

1. **离事实越近，等级越高**：原始文件 > 转述原始文件 > 转述转述。
2. **利益相关性越高，越需要旁证**：由结果受益方发布的、关于自身优势的数据，不能单独使用。
3. **可复现性越强，等级越高**：能说明方法、能自己算一遍的材料，比只给结论的材料更硬。

## 时间维度规则

| 材料类型 | 有效期经验值 |
|---------|------------|
| 政策法规 | 以是否被修订为准，不看时间 |
| 价格 / 库存 / 版本号 | 数天到数周 |
| 市场规模数据 | 通常 1 年，超期需标注 |
| 技术参数 | 以是否改版为准 |
| 人口 / 宏观统计 | 通常 1–2 年，需注明统计年度 |
| 学术共识 | 较长，但需检查是否有新研究推翻 |

> 判断"过期"的标准不是"发布了多久"，而是**"问题问的是不是现状、而这条材料还是不是现状"**。

## 口径陷阱清单

采集与核验时，遇到下列指标名必须问一句"怎么定义的"：

- 用户数：注册 / 活跃 / 月活 / 累计
- 销量：下单量 / 出货量 / 成交额 / GMV
- 价格：标价 / 到手价 / 含税价 / 促销价 / 批发价
- 增长率：同比 / 环比 / 复合年增长
- 收入：营收 / 净收入 / 营业利润 / 经调整后利润
- 市场份额：按金额 / 按数量 / 按区域

**发现口径冲突时：并列呈现 + 说明分歧，禁止直接比较或相加。**
