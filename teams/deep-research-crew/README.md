## 功能

把「这件事到底是真的吗？」拆成一条可执行、可回退的调查流水线：

```
拆路线 → 上网找 → 洗干净 → 拆文档 → 建索引 → 逐条核 → 写成稿
```

四条预设 Workflow：

- **A 完整深度研究**：Phase 0 定路线 → 并行采集 → 清洗 → 归档 → 溯源核验 →（缺口则回退补采，最多 2 轮）→ 撰稿 → 主编终审
- **B 单一命题真伪核验**：轻量快线，只给「证实 / 证伪 / 证据不足」的裁决
- **C 知识库沉淀**：批量网页与 PDF 收成可查证据库，不写报告
- **D 单成员直调**：只问单一维度时直接找对应角色

五道质量门禁：路线门 → 溯源门 → 台账门 → 披露门 → 交付门。关键缺口必须显式披露，禁止含糊过关。

自带技能 `research-evidence-protocol`：A/B/C/D 四级证据强度、来源可信度矩阵、引用格式规范、提交前自查清单、证据台账与报告模板。

## 使用示例

- 帮我查清一件事：这件事到底是真的吗？
- 围绕这个话题做一份带来源链接的深度研究报告，每条结论都要能回看原文
- 这堆网页和 PDF 太乱了，帮我采集、洗净、归档成可查的证据库，再据此写结论
