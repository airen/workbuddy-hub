# 四轴比对清单

## 零、比对条件（先对齐）

- [ ] 视口尺寸一致
- [ ] 设备像素比一致
- [ ] 初始数据一致
- [ ] 登录态一致
- [ ] 两边都加载完成后才开始
- [ ] 记录上述条件

条件不一致 → 先对齐，不比对。

## 一、视觉

- [ ] 整体布局：区块位置、对齐方式
- [ ] 间距：外边距、内边距
- [ ] 字体：字号、字重、行高、字族
- [ ] 颜色：背景、文字、边框、悬停/禁用等状态色
- [ ] 图标与图片：尺寸、位置、比例
- [ ] 层级：遮挡关系、z-index
- [ ] 响应式：若有断点，在各断点各比一次

## 二、交互

- [ ] 正常路径：操作 → 请求 → 界面变化
- [ ] 空状态
- [ ] 加载态（有无 loading 反馈、时长量级）
- [ ] 错误态（请求失败、超时、4xx/5xx）
- [ ] 边界输入：空值、超长、特殊字符、emoji
- [ ] 快速重复操作（防抖/节流行为）
- [ ] 键盘操作（Tab 顺序、Enter 提交）
- [ ] 焦点管理（弹窗打开/关闭后的焦点）

## 三、网络

- [ ] 请求数量
- [ ] 请求顺序
- [ ] URL 与路径
- [ ] 方法
- [ ] 状态码
- [ ] 响应结构 / 字段形状
- [ ] 触发时机（相对操作的时序）
- [ ] 多发 / 少发 / 形状不同的请求，逐条记录

## 四、IPC（仅 Electron 目标）

- [ ] IPC 通道名
- [ ] 消息形状（参数、返回值）
- [ ] preload 暴露的 API 面
- [ ] 主进程行为与副作用（文件、系统调用）
- [ ] 进程边界行为（窗口、托盘、快捷键）

## 分级速查

| 级别 | 判定 |
|---|---|
| 阻断 | 核心功能不可用 / 数据错误 / 关键交互行为不一致 / 请求语义错误 |
| 重要 | 次要功能偏差 / 明显视觉错位 / 错误处理缺失 / 多发少发非关键请求 |
| 次要 | 细微样式差异 / 文案措辞 / 非关键排序 |

## 不可比的常见情形

- 参考站依赖服务端私有逻辑（排序、推荐）
- 参考站返回随机/时效数据
- 参考站依赖第三方登录或付费服务
- 参考站接口有反爬或签名校验

以上情形标"不可比"并说明原因，不硬凑"一致/不一致"结论。
