# 切片自测清单

每个切片提交前过一遍。没有证据的切片不进入下一个。

## 功能

- [ ] 该切片的交互按蓝图规格工作
- [ ] 请求路径、方法、载荷形状与数据契约一致
- [ ] 响应字段被正确消费

## 状态

- [ ] 加载态有反馈
- [ ] 空态有正确表现
- [ ] 错误态有正确表现（含请求失败、超时、4xx/5xx）

## 边界

- [ ] 空输入
- [ ] 超长输入
- [ ] 特殊字符（引号、逗号、换行、emoji）
- [ ] 快速重复操作

## 对照参考

- [ ] 走一遍参考站在该场景下的行为，结果一致
- [ ] 若不一致，是已知假设偏差还是缺陷？缺陷立即修，假设偏差记入差异报告

## 证据

- [ ] 关键状态截图
- [ ] 控制台 / 网络输出
- [ ] 测试结果（若有）

## 提交

- [ ] 一个切片一个提交
- [ ] 提交说明能独立读懂
- [ ] 未混入蓝图外的改动

## 素材

- [ ] 未使用参考站受版权保护的图片 / 字体 / 图标 / 文案
- [ ] 新引入的素材来源可追溯
