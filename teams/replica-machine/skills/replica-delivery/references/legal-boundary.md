# 授权与合规边界

复刻他人网站/应用涉及版权、商标与授权问题。这份文件是团队的**硬门禁**依据：判断不了就先停下问用户。

## 一、开工前必须确认的

| 项 | 说明 |
|---|---|
| 授权依据 | 自有项目 / 已获书面授权 / 目标本身是开源或公开许可 |
| 用途 | 学习研究 / 内部工具 / 对外产品 |
| 分发范围 | 仅自己 / 团队内部 / 对外发布 |
| 涉及资产 | 是否包含目标方的图片、字体、图标、文案、商标 |

**四项任一不清楚 → 停下问用户，不启动。**

## 二、可以做 vs 不可以做

### 通常可以

- 研究目标站**公开可观察的行为**（页面结构、脚本、网络请求），用于学习与实现参考。
- 复刻**功能与交互模式**（功能本身通常不受版权保护）。
- 使用**开源/授权素材**替代目标方的专有素材。
- 复刻自有项目或已获授权的目标。

### 不可以

- 照抄目标方**受版权保护的素材**：图片、插画、字体、图标、文案。
- 使用目标方的**商标、Logo、品牌标识**冒充或造成混淆。
- 绕过**付费墙、登录限制、反爬机制**获取内容。
- 将复刻品用于**冒充、欺诈或商业分发**。
- 复刻目标方**明确禁止**被复制的部分（如许可协议禁止）。

## 三、REA 的合规口径

> REA 为合法的逆向工程研究、分析和重建提供工具。使用者有责任取得所需授权并遵守适用法律。项目不支持非法或未经授权的使用。

补充：REA 在本机分析目标，但**工具结果会交给智能体**，其模型提供方有自己的数据政策。涉及敏感目标时先与用户确认。

## 四、素材替换原则

复刻时对每个素材资产：

1. 判断它是不是目标方**独有且受版权保护**。
2. 是 → 用自制或授权等价物**替换**。
3. 否（通用图标、开源字体、公共素材）→ 可用等价授权版本。
4. 逐项记入交付报告的**被替换素材清单**。

## 五、发现越界时怎么办

1. **立即停下**当前阶段的工作。
2. **明确告知用户**：哪里越界、风险是什么。
3. **给出替代方案**：缩小范围 / 替换素材 / 取得授权后再继续。
4. 用户确认授权后，再恢复流程。

**不"先做了再说"。**

## 六、交付时必须写明的

- 本次复刻的**授权依据**
- **被替换的素材清单**（原素材 → 替换方案）
- 若存在**不可比/无法复刻**的部分，说明原因
