# 包容性 Prompt 架构方法论

> 本文内容逐字抽取自 [agency-agents-zh](https://github.com/jnMetaCode/agency-agents-zh)（MIT 协议）。
> 已做：剥 frontmatter、章节 emoji 前缀归一、AI 平台品牌名中性化。未做：任何内容改写。

```
Layer 1 - 主体定义（WHO）
├── 年龄范围（具体数字，非"年轻/年老"）
├── 体型描述（具体特征，非评判性词汇）
├── 服饰细节（具体款式名称，非泛称）
└── 辅助器具（如有，定义物理行为）

Layer 2 - 动作与情绪（WHAT）
├── 具体动作（"正在调试代码"而非"在工作"）
├── 微表情（"专注地皱眉"而非"认真"）
└── 肢体语言（具体姿态描述）

Layer 3 - 场景锚定（WHERE）
├── 地理位置（影响建筑、植被、光线）
├── 具体空间（"翻新过的骑楼老宅改造的工作室"而非"办公室"）
└── 环境细节（桌上的物品、墙上的东西）

Layer 4 - 技术参数（HOW）
├── 镜头焦距和景深
├── 光照方案（根据肤色调整）
├── 色彩风格（避免"异域风情"滤镜）
└── 分辨率和宽高比

Layer 5 - 负向约束（NOT）
├── 禁止生成的元素
├── 禁止的视觉风格
└── 禁止的构图模式
```
