### 主体描述层

- **主体**：主要拍摄对象的详细描述（人物、物品、场景）
- **主体细节**：具体属性、表情、姿态、质感、材质
- **主体交互**：和环境或其他元素的关系
- **比例关系**：大小关系和空间位置

### 环境与场景层

- **场景类型**：影棚、户外、城市、自然、室内、抽象
- **环境细节**：具体元素、纹理、天气、时间
- **背景处理**：清晰、虚化、渐变、叙事性、极简
- **大气条件**：雾、雨、尘、霾、通透

### 光线设定层

- **光源**：自然光（黄金时段、阴天、直射阳光）或人工光（柔光箱、轮廓光、霓虹灯）
- **光线方向**：正面、侧面、逆光、顶光、伦勃朗光、蝶形光、分割光
- **光质**：硬光/柔光、漫射、镜面反射、体积光、戏剧性
- **色温**：暖调、冷调、中性、混合光源

### 技术摄影层

- **机位**：平视、仰拍、俯拍、鸟瞰、虫眼
- **焦距效果**：广角畸变、长焦压缩、标准视角
- **景深**：浅景深（人像）、大景深（风光）、选择性对焦
- **曝光风格**：高调、低调、均衡、HDR、剪影

### 风格与美学层

- **摄影类型**：人像、时尚、编辑、商业、纪实、艺术
- **年代风格**：复古、当代、怀旧、未来感、经典
- **后期处理**：胶片模拟、调色、对比度处理、颗粒感
- **参考摄影师**：风格影响（Annie Leibovitz、Peter Lindbergh 等）

## 不同类型的提示词模板

### 人像摄影

```
[主体描述：年龄、族裔、表情、着装] |
[姿态和肢体语言] |
[背景处理] |
[布光方案：主光、补光、轮廓光、发丝光] |
[机位：85mm 镜头，f/1.4，平视] |
[风格：编辑/时尚/商务/艺术] |
[色彩基调和氛围] |
[参考摄影师风格]
```

### 产品摄影

```
[产品描述：材质和细节] |
[台面/背景描述] |
[布光：柔光箱位置、反光板、渐变] |
[机位：微距/标准，角度，距离] |
[主图/场景图/细节图/比例参照] |
[品牌美学对齐] |
[后期：干净/情绪化/鲜艳]
```

### 风光摄影

```
[地点和地质特征] |
[时间段和大气条件] |
[天气和天空处理] |
[前景、中景、背景元素] |
[机位：广角，大景深，全景] |
[光质和方向] |
[色彩：自然/增强/戏剧性] |
[风格：纪实/艺术/空灵]
```

### 时尚摄影

```
[模特描述和表情] |
[服装细节和造型] |
[发型和妆容方向] |
[场地/场景设计] |
[姿态：编辑/商业/先锋] |
[布光：戏剧性/柔和/混合] |
[画面动感：静态/动态] |
[杂志/广告美学参考]
```
