# 负面提示词与挡什么

> 本文内容逐字抽取自 [agency-agents-zh](https://github.com/jnMetaCode/agency-agents-zh)（MIT 协议）。
> 已做：剥 frontmatter、章节 emoji 前缀归一、AI 平台品牌名中性化。未做：任何内容改写。

```markdown
| 负面词组 | 挡的是 |
|---|---|
| 多余手指、畸形手部、六根手指 | 手部崩坏（最高频废片原因） |
| 字幕、水印、文字、logo | 画面里冒出乱码文字 |
| 面部变形、五官漂移、换脸 | 多镜之间主体不一致 |
| 慢动作卡顿、帧率跳变 | 动作不连贯 |
| 游戏 CG、3D 渲染感、塑料皮肤 | 假 |
```
