# 内容工厂专家团（Content Factory Team）

> 一条能反复跑的内容生产线。把「收集素材 → 建立灵感库 → 制定计划 → 创作内容 → 看效果 → 放大好的、舍弃差的 → 持续循环」拆成 9 个角色接力，让「内容不是想出来的，而是整理出来的」。

## 这是什么

把内容创作的完整闭环打包成 9 个角色：

- **主理人 岳掌舵**（内容总控）：编排调度、四个确认闸、发布授权与终审
- **葛拾贝**（素材采集师）：七类来源采集，来源与日期留痕
- **储有方**（灵感库管家）：灵感库结构化归档与检索
- **甄有策**（选题策略师）：受众/目标匹配、选题立项与优先级
- **乔定档**（内容排期师）：每周内容日历与发布节奏
- **陆生花**（内容创作师）：核心内容创作（钩子/信息点/证据/行动引导）
- **易百变**（多平台改编师）：一稿多平台改写
- **明有据**（数据复盘师）：指标录入、复盘、保留/测试/停止判断
- **许再生**（内容复用师）：优质内容系列化、拆分与重新包装

## 这个专家团适合谁

- 总感觉「没内容可发」，灵感来了又抓不住，想**把内容生产流程化**
- 同时做公众号 / 小红书 / 抖音 / B站 / X 等多平台，需要**一稿多平台改写**
- 有一堆素材散落在各处，需要**一个能检索、有状态的灵感库**
- 想建立「发布 → 看数据 → 放大好的 / 舍弃差的」的**持续循环**，而不是发完就忘

## 内容从哪来（七类素材来源）

你做得好的内容 · 你过去的内容 · 同行在做什么 · 客户案例/真实故事 · 其他平台的内容 · 你自己的经验和思考 · 日常对话和行业动态。

**核心逻辑**：收集灵感 → 建立灵感库 → 制定计划 → 创作内容 → 看效果 → 好的放大，不好的舍弃 → 持续循环。

## 标准工作流（SOP）

| Phase | 环节 | 参与成员 | 确认闸 |
|-------|------|---------|--------|
| 1 | 素材入库 | 葛拾贝 → 储有方 | 闸 ①：确认入库范围 |
| 2 | 选题与排期 | 甄有策 → 乔定档 | 闸 ②：确认选题方向/平台/时间 |
| 3 | 创作与改编 | 陆生花 → 易百变 | 闸 ③：终稿确认 |
| 4 | 审核与发布 | 主理人把关 | 闸 ④：**发布授权（默认不自动发布）** |
| 5 | 复盘与回流 | 明有据 →（好）许再生 /（差）回流甄有策 | — |

预设 Workflow：A 从零搭产线 · B 单篇内容全流程 · C 数据复盘与复用。

## 怎么用

1. 装上后，对主理人（岳掌舵）说一句话需求，他会判断该落在哪个环节并派活
2. 中途会设 **4 个确认闸**：入库范围、选题方向、终稿、发布授权
3. **发布授权是硬闸**：没有你明确的一句话授权，本团不会执行任何发布动作
4. 用 `present_files` 收交付物（素材卡 / 灵感库 / 日历 / 稿子 / 复盘报告）

## ⚠️ 说明

- **头像是占位图**：当前 `avatars/` 下全部为仓库默认头像副本，正式上架前建议替换为统一画风的角色头像（512×512，PNG/JPG，≤500KB）
- **数据需真实来源**：复盘环节的指标需要接入真实数据来源或由人工录入，缺数据时如实说明，不编造
- **复用不等于重复**：跨平台改写与内容复用必须做实质调整，不做机械复制

## 安装（本地）

```bash

python3 scripts/sync_my_experts.py

# 2. 重启 WorkBuddy AI，在「专家 → 我的专家」里可见「内容工厂专家团」
```

## 打包（上架）

```bash
python3 scripts/verify_upload_ready.py teams/content-creation-team   # 上架前硬校验
python3 scripts/package.py teams/content-creation-team               # 产出 build/content-creation-team.zip
```
