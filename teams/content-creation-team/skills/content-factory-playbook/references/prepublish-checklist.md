# 发布前检查清单（人工审核）

发布前逐条核对，任何一条不过就不发布：

- [ ] 事实、数据和引用可核实
- [ ] 图片、音乐、文字等素材具备使用权限
- [ ] 没有泄露客户隐私或内部机密
- [ ] 没有夸大承诺或误导性表述
- [ ] 标题与正文一致
- [ ] 符合目标平台的格式和发布规范
- [ ] 发布账号、时间和链接正确
- [ ] 需要时由人工确认后再发布

## 硬约束

- **任何发布动作都需要用户单独明确授权**，内容工厂默认从不自动发布
- 涉及「效果」「收益」「涨粉」等数字必须可核验，无法核实的标注「待核实」
- 采集自外部的素材保留来源与日期，不直接照搬他人作品
