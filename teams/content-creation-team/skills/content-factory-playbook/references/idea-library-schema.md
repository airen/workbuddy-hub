# 内容灵感库字段模板

| 字段 | 说明 |
|------|------|
| `id` | 唯一编号 |
| `title` | 灵感标题 |
| `summary` | 核心观点或内容摘要 |
| `source_url` | 原始来源链接 |
| `source_type` | 自有内容 / 竞品 / 客户案例 / 社区讨论 / 新闻 / 个人经验 |
| `audience` | 目标受众 |
| `pain_point` | 受众问题或需求 |
| `content_angle` | 可采用的切入角度 |
| `platform` | 适用平台 |
| `content_format` | 图文 / 视频 / 长文 / 直播等 |
| `business_goal` | 涨粉 / 互动 / 信任 / 获客 / 转化 |
| `priority` | 优先级 |
| `status` | 待筛选 / 待排期 / 制作中 / 已发布 / 已复盘 |
| `published_url` | 发布后的链接 |
| `performance_notes` | 数据与复盘结论 |
| `created_at` | 收集日期 |

## 状态流转

```
待筛选 → 待排期 → 制作中 → 已发布 → 已复盘
                                    ↘（复用）→ 待排期
```

- 新增条目默认 `status = 待筛选`
- 进入内容日历后置 `待排期`
- 成稿进入制作后置 `制作中`
- 发布后回填 `published_url` 并置 `已发布`
- 数据复盘完成后置 `已复盘`，并把结论写入 `performance_notes`
- 复盘判定「放大」的内容，复用产出作为新条目回到 `待排期`

## 记录原则

- 缺字段标「待补」，不要编造
- `source_url` 必填（个人经验类可标「口述/笔记」）
- 涉及客户隐私或内部机密的条目必须显式标注
