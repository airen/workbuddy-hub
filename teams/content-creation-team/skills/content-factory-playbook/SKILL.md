# 内容工厂操作手册

把「收集素材 → 建立灵感库 → 制定内容计划 → 创作 → 发布 → 复盘 → 复用」拆成可执行步骤，供内容工厂专家团各环节专家共用同一套口径。

核心逻辑：**收集灵感 → 建立灵感库 → 制定计划 → 创作内容 → 看效果 → 好的放大，不好的舍弃 → 持续循环**。

## 什么时候用

- 搭建或梳理一条可复用的内容生产流程
- 整理素材、建立或维护内容灵感库
- 制定选题策略与每周内容日历
- 一稿多平台改写
- 发布前逐条检查
- 设定指标并做数据复盘

## 使用要点

1. **先收集，再筛选，永远有得发**：素材不必马上做成内容，先进灵感库
2. **每个选题要有内容目标**（涨粉/互动/信任/线索/转化），没有目标不立项
3. **复用不等于重复发布**：结合平台特点、内容时效和受众反馈做实质调整
4. **发布前必须人工审核**：事实、权限、隐私、夸大、平台规范逐条过
5. **指标规划不等于自动取数**：真实复盘需要接入数据来源或由人工录入，缺数据不编造
