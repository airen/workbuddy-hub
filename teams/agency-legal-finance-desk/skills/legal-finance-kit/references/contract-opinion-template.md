## 合同风险评估矩阵

```markdown
# 合同风险评估矩阵

# 评估维度
| 维度 | 评分(1-5) | 风险说明 |
|------|----------|---------|
| 主体资信风险 |  | 对方的经营状况和履约能力 |
| 条款完备性 |  | 核心条款是否齐全 |
| 权利义务对等性 |  | 双方权利义务是否平衡 |
| 违约救济充分性 |  | 违约时的保护措施是否足够 |
| 争议解决合理性 |  | 争议解决方式是否有利 |
| 法律合规性 |  | 是否符合现行法律法规 |
| 商业可行性 |  | 条款是否具备执行可行性 |

# 综合评分：___/35
- 28-35：低风险，可签署
- 20-27：中风险，修改后签署
- <20：高风险，不建议签署或需重大修改
```
